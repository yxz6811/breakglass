# Quickstart: 开播前阅读

**Date**: 2026-10-02  
**Spec**: [spec.md](./spec.md)

实现完成前，行为步骤会失败。SC-003、SC-004、SC-005 在记录写出之前保持未通过，不得勾成验收完成。

## 准备

1. 在仓库根目录执行 `node --test tests/lesson-reading.test.js tests/lesson-ask.test.js tests/page-lesson.test.js`。
2. 全量确认执行 `node --test`。001 与 002 的现有测试仍须通过。
3. 网页从 `extension/` 目录启动静态服务，打开 `demo/index.html`。不要用 `file://`。
4. Chrome 加载未打包的 `extension/`。`extension/manifest.json` 的权限、主机权限和 CSP 不变。
5. `extension/assets/config.json` 不含阅读地址、模型名或密钥。`fallbackAfterMs` 仍是 1500，`visionAdapter` 仍是 `off`。
6. 准备一支验收片子，地址不得是 `breakglass-demo-9s.mp4`。预先准备的退回片子就是这个文件；文件缺失时，退回后的播放不记为通过。

## 1. 第一处（故事 1）

1. 打开验收片子。阅读自行开始，能看到正在读，能取消。
2. 确认采样不是从 0 秒逐帧前进，且送出的画面不超过 8 张。
3. 第一处通过后，片子暂停在该时间 ±0.2 秒内。
4. 破壁、拖动、重置、退出。来源是「这次阅读」，没有「识别结果」。
5. 注入一份 `frameSize` 与片子源尺寸不同的点。不出现曲线，也不出现预先准备片子上的那条抛物线。

## 2. 下一个（故事 2）

1. 停稳在第一处后读取 `video.currentTime`。
2. 下一处已存好时按下「下一个」。当前曲线先消失。落定前破壁控件不可用。落定后的 `currentTime` 大于按下前的时间，且落在下一处 ±0.2 秒内。
3. 下一处未存好时按下。`currentTime` 不变，曲线不变，能看到「还在读」。
4. 阅读结束后若没有更晚的点，按钮不可用，能看到「没有下一处」，`currentTime` 不变。
5. 在较晚处等待一处更早的结果回来。`currentTime` 不变，曲线不换。

本步要求的前后时间记录目前没有。做完之前，SC-003 保持未通过。

## 3. 退回（故事 3）

1. 在验收片子上断开外部阅读，或让 5 分钟内没有一处通过。
2. 片子回到 `breakglass-demo-9s.mp4`。验收片子上的点不再出现。
3. 在退回后的片子上，按它自己的目标时间破壁。来源是「预先准备的示例」。

## 4. 两个时间和 2%

1. 读出第一处出现的耗时。它单独存在，可以到 5 分钟。
2. 在结果已存好时重复破壁至少 20 次，记下每次从点击到覆盖层出现的毫秒数。P95 ≤ 100 才满足通过线。
3. 破壁后读取 `window.__breakglassAlignment`。`contentRect` 宽高为正，`maxRatio` ≤ 0.02，且 `measured` 为 true。
4. 确认上述样本没有写入 `fallback-visible`。

当前页面把 `maxRatio` 写成 `null`、`measured` 写成 `false`，20 次样本也不存在。因此本节保持未通过，即使 1 到 3 步的交互已经能走。

## 通过标准

- 故事 1、2 的交互和故事 3 的退回可以按上面的步骤核对。
- 验收片子 0 次使用 `breakglass-demo-9s.mp4` 作为阅读地址。
- 尺寸不符的点 0 次被画上，0 次被预制曲线替换。
- SC-003、SC-004、SC-005 在三组记录补齐前保持未通过。
