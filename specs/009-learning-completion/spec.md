# 009 学习功能补齐

用户在核对剩余规划后要求“完成”。本轮依据 Constitution 2.5.0 原则 XVI 完成可实现的产品功能；外部许可、实际供应商与学生实验必须有独立证据。

1. 学生能修改保存记录的标题、备注、疑问/易错类型和原因标签；原数学、来源和作答不可修改。编辑有修订冲突与删除代次保护。
2. 获准视频可按30秒片段渐进分析，当前位置优先，先完成的片段立即可查看，有停止、继续、覆盖缺口和私有缓存。600秒现有本地文件上限保留，不宣传无限长课。
3. 数学深化增加手工直线、圆、正弦、相似三角形和长方体的严格模板、确定性绘制、题目/判定/提示/变式。新增模板不是视觉模型已支持的识别对象。
4. 固定知识关系与先修诊断使用实际学生答案；诊断、提示、观看与正式复练分别展示，不作学习效果保证。
5. 登记素材可显式请求短音轨识别，FFmpeg与ASR服务均留空可配置；仅服务端登记原文件，固定裁剪≤30秒，临时PCM/WAV仅内存，上游取消与限额独立。无音轨、配置空或授权不符明确失败。整文件云上传仍为可选后续模式，不混入本轮。
6. 提供部署就绪检查、严格配置和生产运行入口；实际公网域名、TLS、地区/监护/跨境及许可证据未提供时不发布。实际模型、B站与真实学生实验不能用测试替身勾选。

UI沿用showcase暗色、青色与现有令牌，编辑在记录卡内，分段/音轨在视频工作台，知识图谱与手工数学在复练页；所有主按钮有实际行为，未知理解状态显示待验证。
