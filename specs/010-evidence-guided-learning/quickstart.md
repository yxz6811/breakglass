# 010 统一工作台开发运行

治理2.6.2；运行仅供本机开发。具体边界见[契约v1](contracts.md)，实际状态见[任务](tasks.md)。

## 启动

从仓库根目录运行Node.js≥22.9，分别保持两个终端运行：

```powershell
node scripts/learning-site.mjs
```

```powershell
node scripts/demo-workspace.mjs
```

打开[统一工作台](http://localhost:8765/extension/demo/index.html)。4174仍是唯一学习进程；已经运行时复用，不再起另一个账户handler。8765新前门替代旧纯静态预览；不要让两个服务占用同一端口。localhost与127.0.0.1是独立浏览器存储来源，选择一个固定使用。

模型留空可用预设、手工数学、实线图像、记录、两微课和账户。配置模型时只在本机`breakglass-reader/.env`设置既有字段，并使用如下学习服务启动方式（不要把密钥放浏览器或Git）：

```powershell
node --env-file-if-exists=breakglass-reader/.env scripts/learning-site.mjs
```

旧curve/geometry reader是独立127.0.0.1:8787服务，接口和预算保持原样；主工作台固定曲线地址为当前同源`/read`、几何为当前同源根地址，由前门转发到8787。当前素材登记允许并主动勾选旧reader识别后才可调用，不填写8787直连地址。持续视觉、片段、渐进、登记字幕和可选短音轨由4174原gateway负责，各入口主动开启。公网生产部署不能通过8765前门启动。

## 主路径

1. “视频与识别”选择本地文件或项目自制视频，查看来源登记、模型配置和分析范围；B站公开视频处理许可未知时不采集或上传。
2. “曲线实验”选择包内预设、定位第6秒后破壁，修改参数观察公式、SVG和空间实线同步。视频原题是`y=x²+1`；手工`k=0`是另一探索。
3. “几何实验”载入3–4–5视频、定位有效区间、核对直角后确认，改变AB等条件，观察确定性计算和空间实线。来源标为预设或学生手工。
4. 保存当前探索为新练习，原题不变。进入“理解复练”，可预测、写解释、练七种手工模板，以及两微课的完整例题、补步骤、表征/适用条件新题。
5. “理解与复练闭环”选择原题、明确用途。解释笔记和旧用途待确认记录不进队列。每道新题只提交一次，帮助保存成功后才展示；重开保留帮助，练下一题产生新ID。
6. 实际答错后自主确认/修正错因，生成有限分支新题。选择单类、主动、到期或有基础后混练；复练日期可改、可暂跳。选择“延后题型”不证明已经隔时测验。
7. 账号与访客范围分开，观看不代表数学掌握。网站迁移先导出、预览、勾选；导入历史仅供核对，不伪造实际提交、独立证据或延后效果。删除原题同时清除依赖。

包内曲线视频原尺寸3024×1898仅由精确SHA-256兼容，本地其他文件仍≤64MiB/600秒/1920×1080。帧采样、发送限额和素材许可没有放宽。实线图像只执行仓库确定性渲染，二维函数仍在二维数学平面；拖动或键盘调整观察视角、恢复二维正视，WebGL不可用时保留二维实线与原图。
