关键发现：现有抛物线视频第6秒是 `y=x²+1`；规划的 `y=x²` 必须作为明确的手工探索副本，不能冒充视频原题。另，BC的3位小数只是展示，作答精度仍按原有容差核对。已向主实现会话同步这些约束。

本工作未改 `tasks.md`、契约、治理或应用代码；任务总状态和最终合并由主实现会话依据实际证据汇总。真实模型、B站许可、地区发布、教师认可和学生收益均不因这些材料而通过。
