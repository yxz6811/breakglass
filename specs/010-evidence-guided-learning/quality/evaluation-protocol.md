顺序为：冻结版本及两微课 → 教师审校 → 技术主路径验收 → 经批准的可用性试用 → 修正并重新审校 → 冻结等时对照方案 → 经批准的学习试用 → 7 天延后新题 → 脱敏报告。可用性试用的参与者和题目不直接并入正式学习评价；中途改变教学内容、判题、提示或主要指标时应重新冻结，前后批次分别报告。

| 门槛 | 进入下一阶段需要的可核验证据 | 当前状态 |
| --- | --- | --- |
| 内容与素材 | 两微课 ID/版本、视频完整来源指纹/版本、获准用途、题目和答案版本、程序解算与教师审校结论 | 待实际核验 |

任何门槛未知均保留为“待核验”；先完成不依赖真人的资料、数学复核和技术验证。B 站许可、真实模型、地区发布与学习收益各自独立验收。默认候选试用采用自制/已授权微课、手工或预设条件及确定性数学，模型保持未配置；这能评价该受控学习流程，不能证明真实视觉识别收益。若后续评价真实 AI，必须先通过对应供应商/素材/质量验收并锁定模型、提示、配置和处理路径，不能在同一组中混用未记录的配置。

## 2. T014 教师审校工作表

教师先逐条看最终显示内容，再独立算题，最后在被测主 demo 检查实际反馈。只审文档不能证明界面与帮助事件正确；工程测试不能替代教师签审。每一条短解释、每一层提示、完整例题、补步骤、独立题、延后题、反例和失败提示均须有内容 ID 和版本，禁止用一行“整课通过”覆盖未检查条目。

### 两微课必须核对的数学锚点

下表取自 010 研究规划，仅用于定位审校，不替代完整微课、题库或教师审签。

| 微课/对象 | 必须检查的内容 | 拒绝通过的情形 |
| --- | --- | --- |
| 抛物线：短解释与条件 | `y=a(x−h)²+k` 中 `a≠0`；保持 `a,k` 固定时，增大 `h` 为向右平移，顶点 `(h,k)`；解释括号符号时用括号为零的位置核对 | 把 `x+3` 的顶点写成 `3`；改变 `a` 后仍称只是水平平移；把 `a=0` 当抛物线 |
| 抛物线：来源与单位 | 实际帧公式、手工条件和探索条件分别标明；坐标轴的单位或“纯坐标”说明一致，`h` 与 x 轴、`k` 与 y 轴单位一致，`a` 的量纲与两轴定义相符，不凭空增加 cm | 现有曲线视频说明第 6 秒为 `y=x²+1`，而微课规划从 `y=x²` 起步；未经核对就把后者称为该帧识别结果或原条件 |
| 抛物线：例题与补步骤 | 完整例题说明固定参数和推导；补步骤确实省略一个关键步骤，并标为辅助阶段；`y=2(x+3)²−1` 顶点为 `(-3,-1)` | 展开例题/补步骤后仍记作独立完成；已显示答案的题重开后清除帮助事实 |
| 抛物线：反例与迁移 | 对照左右平移、竖直变化和系数变化；至少一道表征转换/适用条件新题，不能只复制原式并换数字 | 把原答案记忆题称为远迁移；图示、公式、判题与当前条件不一致 |
| 直角三角形：短解释与条件 | 明确 `∠A=90°`，AB/AC 是正长度直角边，BC 为斜边；同单位后用 `BC²=AB²+AC²` | 未确认直角就套公式；边角色错绑；零/负长度或未处理的单位冲突仍算“成功” |
| 直角三角形：例题与相似对照 | AB=3cm、AC=4cm 得 BC=5cm；只把 AB 改为 6cm、AC 仍 4cm 得 `√52≈7.211cm`；两直角边同时变为 6cm、8cm 时 BC=10cm | 只改一边却宣称整图相似、斜边也翻倍；原题条件被探索覆盖 |
| 直角三角形：独立题与单位 | AB=10cm、AC=12cm 得 `√244≈15.620cm`；精确值、近似精度、容差与单位由题库和判题版本共同冻结 | 把舍入误差当概念错误；精确值/约定近似值判定冲突；长度与面积单位混淆 |
| 两课：反例、低置信与失败 | 未确认直角、缺条件、对象绑定不明或模型候选低置信时，引导核对/修改/退出；不给不存在的条件或无关预设 | “识别成功”掩盖失败；候选被当确定事实；失败后偷偷切成预设 |
| 两课：错因与自我解释 | 错因是候选，学生可确认、修正、选择“其他/不确定/暂不标记”；自我解释为学生来源、未自动评分的笔记 | 一次错答被称为能力确诊；强制接受原因；模型文本替学生确认；笔记被算独立正确 |

来源核对须同时查看[视频素材说明](../../../extension/assets/video/README.md)和最终微课版本。若使用手工 `y=x²` 基线，明确标为独立手工场景；若对应现有 `y=x²+1` 帧，保留该帧原条件并据此审校。不能靠编辑说明抹掉源差异。

### 审校的通过与返工规则

- 数学错误、条件/单位错绑、假识别成功、错因确诊、原题被覆写、辅助误标独立属于阻断项。相应微课停止进入学生试用；修正后由教师复审相关条目，工程复核判题与帮助事件。
- 语言含混、解释过长、按钮难找、反例不清等记为可用性问题；若影响条件理解、判题或退出，也按阻断项处理。其余问题明确修订范围并再检查最终显示版本。
- 两微课全部必要条目审完、阻断项清零、教师实际签审和工程证据齐备，才能提交 T014 的验收。本文准备完成不满足该条件；T014 保持未通过。

## 3. T021 第一阶段：先做可用性试用

目的为观察目标受众能否理解来源、找到操作、辨别独立/辅助、完成任务并退出；不估计提分。经 §1 批准后，按教学背景与设备使用情况覆盖目标任务；人数与分批停止规则由试用负责人提前登记，不用方便小样本声称代表全部学生。不得只招项目开发者来替代目标学生。

每位参与者使用同一冻结版本的两微课。主持人先说明可随时跳过、返回视频或退出，不评价个人能力；按以下任务卡逐项开始和结束，必要帮助只用统一脚本。可用性阶段可边操作边说想法；正式学习测验不采用该方式，以免增加组间教学干预。

| 任务卡 | 观察的动作与结果 | 可记录的最少证据 |
| --- | --- | --- |
| U1 来源与核对 | 主动载入获准素材，辨别预设/手工/候选；核对公式或直角、边长和单位 | 完成/未完成、误认类别、恢复次数、用时 |
| U2 预测与实验 | 先预测，再调参数；分清原条件与探索；两课分别比较平移、单边变化和相似缩放 | 是否找得到操作、条件误改、任务用时；预测不记正式错答 |
| U3 例题与帮助 | 找到短解释、完整例题、补步骤和逐层提示；直接看答案后能理解辅助标记 | 首次找到帮助的路径、层数、答案查看、主持人介入 |
| U4 新题与原因 | 在新题提交；辨别独立/辅助结果；确认、改选或暂不标错因 | 合法提交、结果类别、错因出口可达；不推断能力 |
| U5 保存与复练 | 辨别本机/账号范围；保存、重开、选择可作答新题；知道笔记未评分 | 实际读写是否成功、错误恢复、原题是否保持 |
| U6 控制与退出 | 继续视频、跳过学习、关闭动效、键盘进入/离开面板、停止分析并退出 | 阻断/遮挡/焦点问题、退出是否有效、必要技术错误 |

时间从主持人读完任务、参与者开始操作算起，到达到目标或宣布停止结束；同时记录总用时和技术等待，不删掉较慢参与者。暂停、技术重启和额外教学分别记原因及时长。主持人的导航说明也算“主持人介入”，不能把介入后的完成当自主完成。可以询问“这句话是什么意思”“你下一步会怎么做”，不提示数学答案或预设错因。

结束访谈只询问操作困难、提示依赖、想继续使用的原因及具体改进。使用意愿、满意度、观看时长不是学习成绩。默认不录屏、录音、脸部或原始聊天；如必要，先在审批中明确独立用途、最小采集、访问和删除，并只输出脱敏观察摘要。

本阶段输出问题清单与优先级。出现数学误导、无法停止、帮助漏记、身份/来源混淆或未经批准传输，立即暂停对应流程。修复后用新版本复查；未解决阻断项不得进入正式学习比较。可用性达标依据 §1/T003 事前冻结的技术阈值和任务完成标准，不在看结果后临时降低标准。

## 4. T021 第二阶段：等时对照学习设计

本协议建议的首个比较问题是：在同样获准视频、教学内容和总学习时间下，统一工作台的组织和操作是否支持更好的无辅助新题、7 天延后迁移及更低操作成本。它不单独识别某一种学习方法或真实 AI 的贡献。

| 条件 | 学习材料与可用辅助 | 可比较的边界 |
| --- | --- | --- |
| A：BreakGlass | 同一视频和两课内容；统一工作台内预测、图形、短解释、例题/补步骤、可选提示、笔记与练习 | 固定版本、默认状态、设备和模型状态；所有帮助如实记录 |
| B：正常视频 + 图形/笔记辅助 | 同一视频、同一审校内容与练习目标；提供可获得的二维图形、笔记以及相同例题/提示文本，按固定普通界面或材料路径访问 | 保持内容、答案可获得性和教师投入可比，不刻意提供较差视频或移除必要辅助 |
| C：可选现有工具组合 | 同视频 + 经批准使用的 GeoGebra/复习工具组合；工具版本、材料、训练、许可和条件另冻结 | 只有可公平配置与获得时才在招募前设立；未加入不能声称胜过该组合 |

若 A 比 B 多给例题、练习、即时反馈或教师帮助，必须在登记单说明比较的是“教学与工具组合”，不能把差异全部归因于统一界面。不得根据中途成绩才新增或移除 C。未审查的第三方账号、遥测或素材路径不进入试用。

### 分组、时间和主持人脚本

1. 用不同的短前测确认基本条件/策略理解；前测材料两组相同，不显示后测答案。记录学过内容的粗分类和前测分段即可，不收集学校、班级、精确年龄、姓名等不必要身份信息。
2. 首选平行分组，同一参与者的两课使用同一条件；按事前规定的前测分段分层随机分配，保留分配方法及可复核的非身份记录。不要让同一知识先后跨组体验来比较学习收益，以免把前一次练习带入后一组。
3. 若同一课堂交流会造成串扰，在招募前由方法审查者决定隔离安排或班级/小组分配；其样本量与分析也须考虑分配单位。两课顺序采用相同的平衡安排，不能让一组全部先做熟悉内容。
4. 每条微课的学习窗 `L_p / L_g`、立即测验窗 `Q_0`、延后测验窗 `Q_7` 和统一熟悉工具时间在可用性后、正式分组前填写并冻结；任一组相同。未填时不能启动正式比较。学习窗包括看视频、操作、提示、练习和笔记；提前结束可休息，不用剩余时间补充隐藏教学。
5. 各组用同一设备档次/网络条件、原视频、教学脚本和教师投入。中断/等待计时规则统一：记录墙钟时间及有效学习时间；技术中断后的补时规则事先冻结，两组一致，不事后只给 A 补时。
6. 学习期间允许各自条件内的帮助并记录。测验期间隐藏例题、答案、摘要、笔记、图形操作和 AI，使用统一独立题面；各组使用相同的非解题支持（如操作说明），严格区别导航帮助与数学帮助。
7. 主持人不得临场纠正数学或评价“你已经学会”。测验中参与者请求解题帮助时，可选择终止该题并进入辅助学习，该题标为辅助；参与者可随时退出，不强迫维持无辅助状态。

两组均不要求登录后才能继续视频。研究用事件与产品学习记录分别说明用途，禁止把课堂评价/排名混入自主试用。正式试用的接触、日程与延后测验由已批准负责方安排；本文不执行联系，也不创建提醒或自动化。

## 5. 独立新题、7 天迁移与题目等价

在正式分组前冻结题库、答案和人工解释量规，并限制访问；学习素材、例题、补步骤、前测、即时题、延后题必须有不同 ID，记录关系。新题不把同一答案或简单换数字包装成迁移。

| 测量时点 | 题目结构与目的 | 独立证据要求 |
| --- | --- | --- |
| 前测 | 两课基础条件与策略选择，使用独立题型版本 | 无反馈至前测结束；不混入学习后指标 |
| D0 立即新题 | 每课 4 题：2 题新的同类应用 + 2 题表征转换/适用条件；分别报告，合计 8 题 | 固定第一次有效提交；默认无提示/答案/笔记/AI；重做另记，不替换首答 |
| D7 延后迁移 | 每课 4 道未展示新题：至少含表征转换、条件适用/反例和易混策略选择；不能仅复刻 D0 | 目标为学习结束后第 7 天，同一时段；预定义容许窗为第 6–8 天，实际间隔单独报告；超窗另列探索性结果 |

4 题/课是协议拟定的固定结构，不是已经验证的测试信度。教师和方法审查者可在正式冻结前修改题数，但必须同时修改 `K_0/K_7`、时间、等价矩阵和登记版本；分组开始后禁止按结果改题数或删除难题。D7 为本次评估时点，不能将其解释为最优复习间隔。

抛物线题应覆盖括号符号、图形/式子/顶点的转换以及“哪些参数固定才称平移”；三角形题应覆盖单边变化与整体缩放、直角条件缺失和量的单位。各课的 D0/D7 题形式可变，但教师须在等价矩阵核对目标、步骤数、表征、运算负荷、读题量、单位、容差和答案提示。采用等价 A/B 题卷时，在两组内按同一方式平衡题卷及顺序，不能把更容易的题卷只分给 A。

D0 完成前不展示该测验答案；D0 后是否继续产品复练、获取反馈和其他课程学习需两组统一。首个受控比较建议 D0 至 D7 不额外安排本项目同概念练习，两组均保留正常学习；D7 询问并粗分类记录额外学习/串扰，不要求禁用日常教育。若目标是评价复习组合，则两组额外复习材料与时间也须匹配并提前冻结，报告为另一协议版本。

程序核对数值；教师按冻结量规人工评阅条件解释。解释是研究测量的人工评分，不能回写成应用自动评分或“确诊错因”。量规可用 `0=条件或推理不成立 / 1=指出相关条件但解释不完整 / 2=条件和推理一致`，教师须提供每题可接受答案与争议规则；不把自报信心代入分数。评分者只见脱敏答案与题号，未知组别；复核范围在分组前锁定，所有争议由教师裁决并保留版本。

## 6. 指标、分母、帮助、退出与缺失

### 预定义结果与分母

两项共同主要结果为 D0 无辅助新题和 D7 无辅助迁移。正式分析计划须处理两项主要结果及分微课比较的多重性，不能看到哪项较好就改称唯一主要结果。

| 指标 | 分子与分母 | 报告方式 |
| --- | --- | --- |
| 流程人数 | 已授权进入、已分组、开始学习、完成 D0、在窗 D7、超窗、退出、缺测的实际人数 | 按分组给完整流转；退出/帮助/成绩低不从分组人数中悄悄删除 |
| D0 独立证据分数 | 对有效测验参与者 `独立正确题数 / K_0`，当前拟定 `K_0=8` | 每人先计算、再按分组汇总；两课各自 4 题同时报告，不把题目当独立学生 |
| D7 独立迁移证据分数 | 对在窗有效参与者 `独立正确题数 / K_7`，当前拟定 `K_7=8` | 按原分组汇总；报告实际间隔和缺测人数；超窗不混入主要时点 |
| 条件解释 | 按冻结人工量规评分；分母为该量规规定的已分配解释题，缺失单列 | 次要结果；与程序正确性、未评分自我解释分开 |
| 提示依赖 | 学习阶段使用任一解题帮助的可作答上下文数 / 全部已开始可作答上下文数；另报层数、看答案和主持人解题介入 | 只计算合法题目上下文；例题、预测、纯笔记和跳过不造 attempt |
| 用时与操作成本 | 所有已开始任务的墙钟/有效用时、操作数、错误恢复、技术等待与主持人介入 | 次要结果；失败/未完成的用时保留，不能只报成功者或最快者 |
| 同类错误/意愿 | 首答错误类别按教师规则编码；意愿访谈给实际答复人数分母 | 次要或探索性结果；错因仍非能力确诊，不推断付费转化或市场优势 |

这里的独立证据分数衡量在规定窗口内完成独立新题的表现。已有效开始的题若超时、主动跳过、未提交或转用帮助，仍留在 `K` 中但不计入“独立正确”；另标实际状态，不能叫作数学错误。看到提示、答案、相关例题或发生解题介入后答对，是辅助正确；隐藏、重开、换面板不能把同次题变回独立。帮助事件缺失或无法核验时标“独立性未知”，不得推定为独立正确。

### 原始结果类别与缺失规则

研究记录至少区分 `独立正确 / 独立错误 / 辅助正确 / 辅助错误 / 未提交或超时 / 独立性未知 / 技术缺失 / 整次缺测 / 撤回后删除`，同时保存题目/判题/帮助版本及首次有效提交的引用。原始 attempt 不被分析标签覆盖；导入包重算只证明数学对错，不能提供历史独立性或时间证据。

- **正常测验中的跳过/超时/求助：**按上文固定 `K` 计算独立证据分数，状态分别报告；不从分母排除，不把辅助答对计为独立答对。
- **技术故障导致题面未呈现或提交证据丢失：**标技术缺失，不能自动填成学生错误或零知识。只按事前统一的补测规则处理；补测必须用未暴露的等价题并标记，不能用重答已见答案替换。未能补测则该次测验为不完整，报告已见题的描述性结果，不临时缩小 `K` 冒充完整分数。
- **整次 D0/D7 缺测、超窗或中途退出导致不完整：**保留原分组与流转数。主要汇总采用按原分组的可用完整结果，并明确这是可用结果分析，不称为完整意向分析；不能只保留遵从流程且表现良好的学生。报告各组缺失比例及可获得的粗分类原因，不要求参与者提供个人理由。
- **缺失敏感性：**在可获准分析人数范围内，按固定 `K` 把未知结果分别置于 0 与 1 计算组均值界限及最不利/最有利组差界限，与可用结果并列。该计算只作假设界限，不改写原始结果或把独立性未知者升级为独立正确。方法审查者在招募前批准是否采用其他估计方法及其假设；不能在结果出来后选择最有利的填补方法。界限不能消除失访或串扰偏倚。
- **撤回/删除：**立即停止参与及相关采集，按已批准的保留/删除范围处理产品记录和研究记录，清理关联派生数据；不得以分析需要拒绝退出。若资料须删除，不保留答案来估算缺失；只在批准允许时保留无身份的流转总数。删除范围未冻结则不启动真人试用。
- **额外学习、串扰、未按方案使用工具：**标记协议偏离，主要可用结果仍按原分组；事前规定的排除或按方案分析只作附加结果，逐项报告，不静默删掉不利样本。

正式报告同时给实际分母、组差、分布及由方法审查者批准的方法计算的不确定区间；不只报告百分比或显著性。小样本、缺失多、题卷等价未证实或串扰明显时，只作可行性/探索性解释，不宣称提分、普遍有效或适用于未研究群体。
