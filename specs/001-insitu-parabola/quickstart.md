# Quickstart: 原位抛物线破壁

实现完成后用本文验收。本文不包含实现代码。数据形状见 [data-model.md](./data-model.md)，契约见 [contracts/](./contracts/)。

## 前提

- Chrome 当前稳定版。
- Node.js ≥22.9，用于自动检查；CI 使用 Node.js 24。
- 全仓库 `node --test` 还需要当前测试进程的 PATH 中有 `ffmpeg`，用于既有 JPEG 解码和像素定位用例；扩展页面本身不需要它。
- 不需要安装 FastAPI、数据库或打包器。
- 正式通过故事 1 和故事 3 之前，团队需要放入演示视频、目标时间、抛物线定义和匹配的准备结果。只有工程夹具时，可以验证状态和几何，不能宣称已经对准真实视频。

## 启动

1. 在 Chrome 打开扩展管理页，启用开发者模式。
2. 加载 `extension/` 未打包目录。
3. 点击扩展按钮，打开扩展内演示页。
4. 确认页面可以离线播放视频。断开网络后重复主路径。

## 自动检查

在仓库根目录运行：

```bash
node --test
```

期望：几何、CurveResult 拒绝与放行、参数钳制、旧请求丢弃这些测试通过。失败时不得把手工演示记成已通过。

## 手工场景

### 1. 主路径

配置保持 `externalAttempt: off`。定位到目标时间，用按钮和 Alt+B 各唤醒一次。

期望：

- 90 秒内完成唤醒、拖动一个参数、重置和退出。
- 曲线与数字一起变化，参数不越界。
- 重置后交互层还在，数值回到初值。
- Esc、退出按钮和点击交互层外部都能退出，视频保持暂停。
- 来源始终是预先准备的示例。

### 2. 超时、失败和取消

按 [runtime-config.md](./contracts/runtime-config.md) 分别设置 `hang`、`invalid`，以及一份不匹配的准备结果。

期望：

- `hang` 在 1.5 秒后无需再点击就显示匹配曲线，并持续说明超时回退。从判定超时到曲线出现不超过 0.1 秒。随后到达的结果不改变曲线。
- 没有匹配准备结果时不显示成功，可以重试或退出。
- 等待中取消后回到暂停，迟到结果不再打开覆盖层。
- 连续 5 次退出再唤醒，或换帧再唤醒，旧结果不覆盖新画面。

### 3. 画幅

在 16:9、4:3、竖屏和带黑边四种视频框下唤醒，并在交互中改变一次窗口大小。

期望：曲线相对视频内容区域较短边的偏差不超过 2%。黑边不参与对齐。播放或离开目标时间后覆盖层消失。

### 4. 不可用页面

不把扩展注入到未写入验证记录的网站。演示页缺少视频或视频打不开时，入口不可用或给出说明，页面没有残留覆盖层。

## 记录

对齐和 0.1 秒测量要记下浏览器版本、机器、是否使用热缓存，以及事件的起点和终点。未实际运行的项目不要写成已通过。
