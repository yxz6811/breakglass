# Data Model: 几何实验自动阅读

日期：2026-10-06。字段以 [geometry-lesson-result.md](./contracts/geometry-lesson-result.md) 为准。

## 阅读过程

一次阅读绑在学习者当前选中的片子上。换片、地址变更或离开页面后，上一支的点作废。

| 字段 | 规则 |
| --- | --- |
| readingId | 当次非空字符串 |
| videoId | 当次内存绑定。不得使用 `fixture-parabola` |
| duration | 秒，有限且大于 0 |
| frameSize | 源像素宽高，均正整数 |
| phase | `reading`、`settled`、`cancelled`。失败时过程清空，片子留下 |
| points | 已通过检查的点，按 `time` 升序，最多 8 个，相邻至少 1 秒 |
| first | 最先通过检查的点，可以不是 `time` 最小的点 |
| shown | 当前破壁取出的点；未破壁为 null |

`phase = reading` 时仍可以已经有 `first` 并暂停在该点。后台继续完成时不得改 `shown` 和当前时间。

## 已存几何点

| 字段 | 规则 |
| --- | --- |
| id | 点的代号，与当次 readingId、videoId、time 一起核对 |
| time | 秒，有限，落在 `[0, duration]`，并且属于这次实际送出的采样时刻 |
| lessonLine | 一句说明，按码点最长 80。空则用图形自己的条件短句 |
| kind | `right-triangle`、`circle`、`segment` |
| unit | `unit`、`cm`、`m`。一个点只有一个单位 |
| placement | 源像素坐标，原点在画面左上，x 向右，y 向下。只用于摆放 |
| given | 画面标记给出的已知量，见下表 |
| derived | 程序计算的量。直角三角形只有斜边 |

### given

| kind | 必须有的已知量 |
| --- | --- |
| right-triangle | 直角顶点名称；恰好两条直角边，每条有名称、两个端点名称和正有限长度。两条边共享直角顶点 |
| circle | 圆心名称、圆心源像素、正有限半径 |
| segment | 两个端点的名称和源像素、正有限长度 |

顶点与端点的源像素必须落在 `frameSize` 内。两个端点不得重合。直角三角形的三个顶点名称必须互异。

### derived

直角三角形的斜边长度是两条直角边的 `Math.hypot`。它不从模型读入，也不写回 `given`。圆和线段没有额外派生长度；调节后的半径或长度仍放在当前条件里，初始 `given` 保持不变。

## 调节

当前调节从已破壁的点复制出一份工作条件。`given` 本身不变，直到重置把它重新复制出来。

| 操作 | 效果 |
| --- | --- |
| 改一条直角边 | 该边变为新的正有限长度，另一条边和直角顶点不变，斜边重算 |
| 改半径 | 圆心不变，半径变为新的正有限数 |
| 改线段长度 | 两端方向不变，长度变为新的正有限数 |
| 重置 | 工作条件回到该点的 `given`，斜边重算 |
| 退出 | `shown` 清空，工作条件丢弃，片子保持暂停 |

一次操作只包含上表中的一项。零、负数、非有限数或第二项修改同时出现时，工作条件不变。

## 状态迁移

1. 未选片：不阅读。
2. 选了自己的片子但地址为空：不送画面，提示填写地址。
3. 可播放且地址已填：进入 `reading`，送出 1 到 8 个采样。
4. 第一个合法点到达：暂停到该 `time`，`first` 指向它。停稳后可以破壁。
5. 破壁：`shown` 指向当前已停稳的点，进入调节。破壁不再发阅读。
6. 「下一个」：仅当存在 `time` 更大的已存点。先清空 `shown`，再定位；落定前不可破壁。
7. 取消：停止未完成采样。已存点保留，`phase` 变为 `cancelled`。
8. 整次没有合法点、断网或满 5 分钟仍没有点：清空过程，片子留下。

播放、换片、地址变更和媒体错误使进行中的请求作废。回到同一秒也不接受旧响应。

## 预先准备的示例

只有点击「选择预设」才装入。它有自己的片子、时间和条件，来源标记为预先准备的示例。它不产生 `origin: external` 的阅读点，也不计入 SC-001。
