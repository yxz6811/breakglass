## 1. 自动化

实施完成后再在仓库根目录执行：

```bash
node --test tests/geometry-lesson-reading.test.js tests/geometry-lesson-page.test.js
node --test breakglass-reader/tests/geometry-lesson.test.mjs
node --test tests/page-lesson.test.js tests/page-geometry.test.js tests/current-frame.test.js
```

前两行只覆盖 006。第三行确认曲线自动阅读、005 显式几何工作台和当前帧抛物线仍按原测试通过。模型使用不联网替身。通过这些命令不等于真实视频识别已经验收。

替身至少要证明：

- 自己的片子可播放且地址已填时才发送，最多 8 帧，暂停本身不发送。
- 最先通过的点会请求暂停；破壁不再发阅读。
- 直角边 3 和 4 得到斜边 5；只改一条为 6、另一条保持 4 时斜边为 `Math.hypot(6, 4)`。
- 圆只改半径，线段只改长度。
- 两个完整图形、缺条件、像素充长度、尺寸不符都被丢掉。
- 失败、空地址和超时后片子还在，预设不会自动装上。
- `/read` 与 `/geometry/read` 的现有用例仍然按原契约拒绝或通过。

## 2. 自己的视频

1. 启动既有本地 reader，确认密钥只在未提交的环境文件里。
2. 打开新的几何阅读页，不点「选择预设」。
3. 选择一支自己的固定机位或录屏课件，填写本机阅读地址。
4. 确认片子可播放后阅读自己开始，并能取消。
5. 第一处通过后，片子停在该时间附近。破壁层来自这一帧，文案是「这次几何阅读」。
6. 调节一项允许条件，核对程序算出的新结果。退出后视频还在。

预先准备的示例只在主动点击「选择预设」后出现，文案是「预先准备的示例」。
