# 008实施计划

先冻结[需求](spec.md)和[契约](contracts.md)，同步2.4.0宪法与AGENTS；复用现有Node服务、纯JS模块、暗色学习网站与数学验证器，不引入新运行依赖。

| 任务 | UI入口 | 实现位置 | 关键验证 |
| --- | --- | --- | --- |
| C001 账号配对服务 | 网站账户设置 / 插件设置 | breakglass-learning | 一次性、期限、CSRF、origin、会话撤销 |
| C002 插件同步 | 插件保存 / 设置账户页 | extension plugin与worker | 本机先存、队列隔离、删除epoch、明确重试 |
| C003 网站配对与刷新 | 账户设置 / 学习记录 | learning-site | 身份代次、无secret、可撤销、可见范围刷新 |
| C004 短片段视觉+字幕 | 本地视频工作台 | reader独立context、网站gateway | 许可指纹、30秒/8帧、服务选择字幕、不送音频 |
| C005 深度复练 | 理解复练 | 网站教学纯函数与UI | 预测、分步提示、数学一致、变式独立记录 |
| C006 集成和证据 | 全流程 | tests与opt-in浏览器脚本 | 实际HTTP/MV3/Edge，空配置和取消，明确替身 |
| C007 状态回写提交 | 任务/产品/UI/风险规划 | docs、specs | 不覆盖历史未验收，提交并推送指定分支 |

并行按目录分工；共享契约先确认，gateway和网站由主任务集成。所有正式发布条件继续遵守原则XII；不得在本机验收后直接勾选M3公网同步、M4真实学习效果或B站支持。
