## Requirement Completeness

- [x] 支持范围锁定为一个 ∠A = 90° 的直角三角形，AB、AC 为直角边，BC 为斜边。
- [x] 当前帧识别为暂停后的显式操作；帧身份、时间单位和旧结果失效规则明确。
- [x] 候选校对、确认前禁止交互、用户确认后的原题快照均有验收场景。
- [x] 明确像素距离不能作为真实长度，不能按截图外观猜数学条件。
- [x] 手动与自然语言共用模型、单边约束和计算结果；歧义与不支持请求不部分执行。
- [x] 三组可核对数值、误差口径和手动/自然语言一致性要求明确。
- [x] 恢复、理解题反馈、跳过状态和返回原视频原暂停时间均可验证。
- [x] 预设、手工与真实识别独立标识、独立验收，不以校对后结果冒充模型原始识别成功。
- [x] 10–15 份素材列为评估建议，未伪造素材或验收结果。
- [x] 真识别、安全配置和运行环境列为待实施计划冻结的依赖，未虚构已有能力。
