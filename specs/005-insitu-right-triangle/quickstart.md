# Quickstart: 当前帧直角三角形闭环

**Date**: 2026-10-03
**Status**: 005 实施后的验收步骤；本次规划尚未实现，不得把以下步骤或真实样本表记为已经通过。
**References**: [spec.md](./spec.md)、[plan.md](./plan.md)、[tasks.md](./tasks.md)、[场景与动作契约](./contracts/scene-actions.md)、[BreakGlass Constitution 1.7.0](../../docs/BreakGlass-constitution.md)。

验收区分预设/手动数学闭环与真实模型识别。现有抛物线自动化、样例或替身模型证明不了 005 真实视频识别；005 也不替 003 补齐真实像素、20 次热缓存或四画幅对齐记录。004 多曲线与问答保持独立。

## 0. 准备与现有命令

1. 完成 `tasks.md` 对应实现后再开始 005 交互验收。规划阶段没有几何页面入口、端点或已完成测试。
2. 在仓库根目录可运行已存在的 `node scripts/check.mjs`、`node --test`，记录实际结果。新测试文件出现后再使用其真实路径，不编造 `npm run geometry`、专用开发服务器或构建脚本。
3. Chrome 加载未打包的 `extension/`，按根 [README](../../README.md) 打开演示页。核对 manifest 权限、主机权限和 CSP；005 的计划不要求增加它们。若用静态服务，复用现有 README 的方式，不用 `file://`，确认视频服务支持 `Range` 和定位。
4. 本地模型服务按 [breakglass-reader README](../../breakglass-reader/README.md) 配置：Node >=22.9，密钥仅在该目录被忽略的 `.env`，不放进浏览器或仓库。进入 `breakglass-reader/` 后，现有 `npm start` 运行 `node --env-file-if-exists=.env src/main.mjs`。这是已有 reader 的启动方式；它在实现前不会提供 `/geometry/read` 或 `/geometry/ask`。
5. 005 实现后填写其独立几何服务地址，先用已有 `/health` 检查本地服务可达与模型配置状态。005 新端点是否可用按实际响应检查，不能用 `/health` 成功推断模型识别正确。
6. 准备一个明确标注为“预设演示”的 3-4-5 夹具、一支包含清晰直角三角形 ABC 的真实片子、条件不足/不支持的视频，以及可控制失败、超时、迟到响应的本地测试替身。替身不联网，不能记入真实识别准确率。
7. 测试前记录提交、Chrome 版本、设备、页面来源、模型与服务配置、截图时间、是否预设及网络状态，不记录密钥。

## 1. 预设或手动数学闭环

1. 明确进入“预设演示”或“手动输入”。确认 A 为直角顶点，AB=3、AC=4，单位为“单位长度”。来源持续为预设或手动，不显示真实识别成功。
2. 完成首次确认。模型图、条件文字和本地 BC=5 同步出现，原题快照为这个首次确认版本。
3. 数值输入将 AB 改为 6，保留 AC=4。BC 必须是 `√52≈7.2111025509`；显示可以舍入，计算状态不能被展示舍入覆盖。A 处始终保持直角。
4. 用鼠标操作实际实现的边长控制，再用键盘或数值输入完成同样操作。不能任意拖顶点破坏直角。
5. 发送“如果 AB 从 3 变成 6，BC 会怎样？”这类受支持问题。实际操作必须通过白名单执行；说明使用真正提交的 AB/AC/BC，不能只回答文字却不改图，也不能图已失败但宣称成功。
6. 在 AB=6、AC=4 的有效状态下，再进行一次独立操作，只改 AC=8 并固定 AB=6，确认 BC=10；每次成功单边修改使修订号增加 1。若一批要求同时修改 AB/AC，整批拒绝。
7. 点击“恢复原题”或发送受支持的恢复问题。AB=3、AC=4、BC=5，恢复首次确认的条件和来源，修订号递增而非倒退。
8. 退出画板或返回视频。返回同一视频的原暂停时间，实测偏差不超过 0.1 秒后继续播放；无残留覆盖层、监听器和未结束请求。若用户已换视频，不自动恢复或覆盖新的选择。

记录：来源、首次确认修订号、每步 AB/AC/BC、动作、修订号与截图。上述闭环通过只说明确定性数学、控制器和展示成立。

## 2. 一张真实暂停帧到可操作场景

1. 选择真实片子，暂停在一个清晰直角三角形题目帧。记录 `videoId`、`frameTime`（秒）、`videoWidth` / `videoHeight`。
2. 进入 005 并主动识别。确认页面明确说明单帧会发给本地服务及其模型；网络面板只出现这张 JPEG 和元数据，不扫其他帧、不上传整段视频。
3. 合法模型响应只显示为待校对候选。核对 A/B/C、直角标记、AB/AC 对应数值与单位；不能依据图上像素长度认定题目比例。
4. 故意把一处识别数值或标签校正后确认。来源保留原始取得方式并注明已校对，`editedByUser=true`；“原题”采用校正完成后的首次确认版本。
5. 修改 AB 或 AC，核对本地 BC 重算、直角约束和说明同步。修改后的模型图不能显示为与原视频仍 1:1 重合。
6. 恢复原题，确认回到已校正版本，不回到模型错误数值。
7. 返回原视频继续播放。记录返回时间与原暂停时间，偏差须不超过 0.1 秒；核对来源说明和请求清理。

单个正确模型样本不代表适用于任意视频。若不能读清条件，进入校对/手动模式；若当前帧不属于支持范围，给出明确提示，不能凭空生成可执行的三角形。

## 3. 拒绝、失败和迟到结果

| 注入或操作 | 必须观察到的结果 |
| --- | --- |
| 数值为 0、负数、字符串、boolean、`null` 或非有限值 | 候选或动作拒绝；当前有效图形和数值不变，字段附近有原因 |
| AB/AC 各自有限，但 BC 或绘图派生值溢出 | `derivedFinite` 拒绝，不出现 `NaN` / `Infinity` SVG |
| 当前单位为 cm，动作单位为 m | 整批拒绝，无自动单位换算 |
| 同批要求改 AB=6 和 AC=8，或一项合法、一项非法 | 首版不支持多边修改，整批拒绝；任何边和修订号均不改变 |
| 模型要求修改 BC、角度、添加对象或执行代码 | 拒绝未知动作，不执行“相近”操作 |
| 顶点画面坐标越界、源尺寸不符或帧标识不符 | 不进入可执行场景，不把预设三角形贴到错误帧上 |
| 识别时播放、换片、重新捕获、取消或退出 | 本地和上游取消，旧响应不能再打开画板 |
| 问答返回前人工改边或恢复原题 | 旧 `sceneRevision` 动作拒绝，用户最新修改不被覆盖 |
| 问答中又发新问题 | 旧 `actionRequestId` 失效，迟到结果不改图、不显示已执行 |
| 服务无模型、断网、上游失败、识别 30 秒/问答 10 秒开发预算耗尽 | 明确可恢复状态，保留用户视频及既有已确认场景；不静默改成预设 |
| 请求体超过 4 MiB | 413；不继续模型调用 |
| 不支持题目、多个三角形、直角位置或单位不确定 | 不声称识别成功，提供退出、重新选帧或人工输入入口 |

非有限值不属于合法 JSON，可用测试夹具或模块级调用验证；不能把浏览器未能发送非法 JSON 误记为执行器已拒绝。30 秒/10 秒是待真测冻结的开发预算，测试必须记录实际配置，不把它们写成已验证产品性能。

## 4. 响应式、键盘与原帧定位

1. 桌面和窄屏核对视频、条件校对、模型画板与提问入口可用，无横向溢出、遮挡或失去焦点。
2. 仅用键盘完成进入、校对、改边、提问、恢复与返回；焦点可见，状态文字可被辅助技术读取。错误不能只用颜色传达。
3. 使用 16:9、4:3、竖屏与带黑边的真实截图验证候选顶点映射。记录源像素、`contentRect` 和实际显示位置，区别源点定位误差与按条件生成的模型图。
4. 窗口大小变化、全屏或 DPR 变化后，原帧高亮仍映射到视频内容区；模型图保持等比，数值与直角不变。
5. ESC 或返回移除 005 自己的画板和监听器；全屏状态按浏览器实际行为测试，不能声称未测的扩展全屏已通过。

本节结果不自动算作 003 或抛物线 P0 的四画幅 2% 验收。需要量化 005 定位指标时按最终 plan 记录独立测量，不用截图观感代替数据。

## 5. 理解题与闭环记录

完成变更与恢复后，用户回答一个与本次操作一致的小问题，例如：“直角仍在 A，AC=4，AB 从 3 变为 6，为什么 BC 不会仍为 5？”或者“只改变 AB 时，哪些条件保持不变？”

将用户回答与操作记录分别保存为本次验收证据。可以判断答案是否符合本地已确定的勾股关系；不能仅凭看过动画、点过恢复或 AI 自称解释清楚就写“记忆加深、理解已提升”。理解题未回答或答错时，记录实际情况，允许回到画板再次演示。

## 7. 交付与回归门禁

- 先完成可离线验证的 3-4-5 数学、校对、原子动作、复原与来源标识，再接本地真实模型；不能把预设演示写成真实帧识别已完成。
- 全部测试与静态检查记录实际命令和结果；无真实模型、浏览器、ffmpeg 或扩展全屏条件时写明限制。
- 按 001/002/003 的既有 quickstart 执行受影响回归，确认 `/read`、开播前阅读、显式预设和 1500ms 不被改动。004 保持独立，不能把其多曲线问答任务算作 005 完成。
- 005 验收只能在实现与对应记录存在时标完成；真实样本表仍空、失败/迟到路径未测或用户确认环节缺失时保留未通过。
