# 007 网站本地视频、账号学习中心与粒子呈现

日期：2026-10-06。用户明确要求“执行任务开始写代码完成规划任务”，模型“留空可配置”。本次继续实现原规划M2/M3与粒子呈现，不部署公众服务，不采集B站未获许可材料。治理2.3.0，原则XI–XIV；旧001–006接口/预算/验收保持。

## 用户流程与实施范围

- 最新视觉要求：以仓库`site/showcase.html`/`showcase.css`与品牌SVG为依据，管理中心采用暗色/青色强调、桌面侧栏、窄屏横向导航和顶栏账号身份。概览/观看进度/疑问与易错/理解复练/设置为主要管理区域，视频工作台为次级入口。空账号只显示真实零值和空态，不放演示学习曲线；学习状态来自实际答案，观看位置不称掌握程度。
- 插件仍为主要入口；网站独立提供访客本地视频选择/拖入、解码预览、当前画面持续识别、局部摘要、手工数学条件、学习记录与结构场景回顾。
- 任意本地文件不自动获得AI上传许可。完整内容SHA256匹配服务端固定自制素材登记后才允许帧分析；未登记仅本地预览和学生输入的通用数学条件，不将版权勾选当放行。模型设置留空；实际配置由本机服务环境读取，浏览器不保存密钥，未配置明确失败。
- 文件限定MP4/WebM、64MiB、600秒、1920×1080；在浏览器解码，整文件不送服务器。来源local-file:file-SHA、视频版本/分析版本；换源/seek/hidden/退出/删除停止并丢弃旧响应，释放objectURL。重开必须重新选择并验证文件身份。
- 新身份服务与无状态reader分开。真正注册/登录、账户专属观看/疑问/个人易错/作答记录、明确导入访客记录、导出与删除在本机开发服务实现；不冒称已部署云账号或完成监护/跨境/目标地区发布。
- 复练是学生主动作答：直角三角形计算斜边、抛物线识别顶点；程序确定答案，记录独立/用提示/错误。疑问和通用AI提醒不自动称错题，不以点击/播放时间称掌握。
- 粒子只表达同一已确认二维数学对象，在三维视角中观察，所有数学z坐标为0；不伪装曲面或立体重建。固定本机shader、最多2048点/DPR2/1600画布，参数/视角改变时静态重绘，失败保留SVG。
