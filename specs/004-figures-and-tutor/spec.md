# Feature Specification: 更多图形与旁边提问

**Feature Branch**: `004-figures-and-tutor`

**Created**: 2026-10-03

**Status**: Draft

**Input**: User description: "做更多几何图形，不然太单调。旁边有个聊天机器人，可以向它提问：如果某个值是多少，图像怎么变化？答案是多少？它根据提问用真实数值重新绘图并解答，用来真正解决疑问。两种能力可以分给两个人；提问更难，也可以先只接现有抛物线。新图形先不要从视频里识别。"

## User Scenarios & Testing *(mandatory)*

两件事，两个人同时做。一人做图形，一人做提问。彼此不靠对方先做完才能开工。提问先对着现有抛物线验收；图形先自己能画、能改。两边合在一起时，提问对着当时画面上的那种图形作答。

### User Story 1 - 更多图形（一个人）

用户可以把当前图形换成直线、圆或正弦，也可以换回抛物线。每种图形都能改自己的系数，画面跟着变。这一件不包含提问区。

**Why this priority**: 现在只有抛物线，演示单调。这一件单独做完，用户就能换图形。

**Independent Test**: 不使用提问区。依次换成直线、圆、正弦和抛物线。每种至少修改一个系数，画面变成该图形在该系数下的样子。换走之后，上一种图形的系数不再留在画面上。

**Acceptance Scenarios**:

1. **Given** 已打开一条抛物线，**When** 用户选择直线、圆或正弦，**Then** 画面改为该图形，并出现该图形自己的系数，可以调节。
2. **Given** 当前是直线、圆或正弦，**When** 用户修改一个允许范围内的系数，**Then** 画面按新系数重画，该图形仍然可辨认。
3. **Given** 当前图形有一部分落在坐标窗口外，**When** 画面重画，**Then** 只画出窗口内的部分；窗口外的部分不沿边连成直线或直角。整段都在窗口外时，不画出假的一条边。
4. **Given** 用户从一种图形换到另一种，**When** 切换完成，**Then** 画面上只有新图形，旧图形的调节项不再作用于新图形。

---

### User Story 2 - 旁边提问（一个人）

画面旁边有一块提问区。用户用平时的说法问「如果某个值是多少，图像怎么变」或「答案是多少」。提问区按这句话改到那个数，或算出那个答案，然后画面用同一组数重画。回答里写的数就是画面上的数。问的是当时画面上的那种图形。

**Why this priority**: 用户要能靠提问看懂变化，而不是只靠自己拖滑块。这一件单独做完，现有抛物线上已经能解疑问。

**Independent Test**: 先只对现有抛物线。提问「把顶点高度改成 -1」后，画面上的顶点高度是 -1，回答里也写 -1。再问一个横坐标上的纵坐标，回答与画面上该点一致。另一人的直线、圆或正弦已在画面上时，用同样的问法核对：回答里的数就是该图形上的数。

**Acceptance Scenarios**:

1. **Given** 一条已打开的抛物线，**When** 用户问某个系数若改成允许范围内的一个数、图像会怎样，**Then** 画面改成这个数，回答说明变化，并且回答里的系数与画面上的系数相同。
2. **Given** 当前画面是抛物线、直线、圆或正弦，**When** 用户问某个横坐标对应的值是多少，**Then** 回答给出的数与画面上该点一致；若该点落在当前坐标窗口外，回答说明它在窗口外，并不把窗口外的一段画成直线或直角。
3. **Given** 当前图形已打开，**When** 用户的问题无法对应到这个图形的系数或读数，**Then** 图形和系数保持原样，回答说明这次没有改图。
4. **Given** 用户提出的数超出该系数允许的范围，**When** 提问被执行，**Then** 画面使用实际采用的那个数，回答写出这个实际采用的数，而不是用户原话里那个越界的数。
5. **Given** 当前图形不是抛物线，**When** 用户用抛物线才有的系数提问，**Then** 画面不变，回答说明当前图形不能这样改。
6. **Given** 用户刚换成另一种图形，**When** 接着提问，**Then** 提问作用在新图形上，不改回上一种图形。

---

### Edge Cases

- 提问区暂时没有得到解答时，当前图形保持不动，并说明这次没答上，可以再问。
- 同一句里要求改两个系数时，两个都在允许范围内则一起改，回答列出实际用上的每一项；其中一项无法执行则整句不改图，并说明没有改。
- 圆的问题若问到圆外或圆上一个具体点，回答按当前圆的系数计算；算不出唯一答案时不改图，并说明缺什么。
- 切换视频、退出破壁或换一种图形后，下一次提问只针对当时画面上的图形。
- 坐标窗口把图形裁掉一段时，回答不得把被裁掉的部分说成仍然画在边上。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 画面旁必须有一块提问区。用户能输入一句中文问题并送出。
- **FR-002**: 对当前抛物线，提问区必须能按用户给出的允许范围内系数重画，并说明相对提问前的变化。
- **FR-003**: 对当前图形，提问区必须能回答「某个横坐标上的值是多少」这一类读数问题。回答中的数必须与重画后的画面一致。
- **FR-004**: 数的来源必须是当前画面正在使用的图形。提问区不得另报一个与画面不同的数。
- **FR-005**: 问题无法执行、解答没有返回，或提出的系数当前图形并不存在时，必须保持图形和系数不变，并说明没有改。
- **FR-006**: 用户给出的系数超出允许范围时，必须采用实际画上的那个数，并在回答中写出该数。
- **FR-007**: 用户必须能在抛物线、直线、圆、正弦之间切换。同一时刻画面上只有一种图形。
- **FR-008**: 直线、圆、正弦各自必须能调节至少一个系数，调节后画面立即重画。
- **FR-009**: 图形落在坐标窗口外的部分不得画成贴边的直线或直角。整段都在窗口外时不得用一条边代替该图形。
- **FR-010**: 新图形不得靠从视频画面里识别得到。现有抛物线的预设演示和已有阅读结果保持原样。
- **FR-011**: 模型密钥和阅读地址不得出现在页面或仓库中。若解答的措辞来自外部能力，算式结果仍然必须与画面一致。
- **FR-012**: 本能力不得改变现有破壁的 1.5 秒保底，也不得把「只有预设抛物线的演示」的验收门槛抬高。

### Key Entities

- **图形**: 当前画出的一种：抛物线、直线、圆或正弦。包含它自己的系数、允许范围，以及坐标窗口里实际可见的部分。
- **提问**: 用户的一句话。意图是修改某个系数，或询问当前图形上的一个读数。
- **解答**: 一次提问的结果。包含是否改了图、实际采用的数、以及给用户看的说明。说明里的数必须能在当前图形上核对。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在已打开的抛物线上，用户一次提问即可把一个允许范围内的系数改到指定值。画面与回答中的该系数相同。
- **SC-002**: 用户询问一个横坐标上的读数时，回答与画面上该点的差不超过画面正在显示的最小刻度的一半。
- **SC-003**: 用户能完成抛物线、直线、圆、正弦四种图形的切换。每种至少成功修改一个系数，并看出图形已按该系数变化。
- **SC-004**: 对无法执行的提问，图形在提问前后保持一致，用户能从回答中知道没有改图。
- **SC-005**: 现有 9 秒预设抛物线仍能暂停、破壁、拖动、重置和退出。本规格的通过与否不改变这条演示是否已经可演示。

## Assumptions

- 两个人各拿一件，不另拆第三件。图形的人做故事 1，提问的人做故事 2。直线、圆、正弦的具体系数名称由图形的人定，但每种至少有一个用户能改的数，并且提问能点名这个数。
- 提问的人先用现有抛物线做完自己的验收。图形换上来之后，同一块提问区对着当时的图形作答，不再单开一项工作。
- 直线用斜率和截距理解；圆用圆心和半径理解；正弦用振幅、左右位置和上下位置理解。抛物线仍是现在的开口、左右和高低。
- 提问使用中文。不要求保存历史账号，也不要求换视频后还能翻旧对话。
- 新图形不进入视频识别，也不替换开播前阅读。阅读仍然只产生已有的抛物线结果。
- 允许范围与现有滑块相同：越界时用实际能画上的数，并在回答里说明。
