# Quickstart: 旁边提问

验收覆盖提问。直线、圆、正弦已经能在画面上切换，提问读的是当时画面上的那一种。

## 准备

- Chrome 当前稳定版，加载本仓库的 MV3 扩展。
- Node.js 20 或更新版本，仅用于 `node --test`。
- 打开扩展内演示页。预设视频仍是 `breakglass-demo-9s.mp4`。
- 不填写阅读地址。本切片不需要阅读服务，也不需要模型密钥。

## 自动检查

在仓库根目录：

```bash
node --test tests/tutor-numbers.test.js tests/tutor-parse.test.js tests/tutor-ask.test.js tests/page-tutor.test.js tests/page-integration.test.js
```

期望通过的行为：

- 「把顶点高度改成 -1」得到 k 的实际采用值 -1，回答含 -1。
- 「x 等于 1 时 y 是多少」在 a=1、h=0、k=1 时得到 2，且不改系数。
- 说出范围外的系数时，回答里的数是夹取后的数。
- 一句里有一个当前抛物线没有的系数时，所有系数保持原样。
- 纵坐标落在 `range` 外时，回答标明在窗口外，返回值仍是函数的真实 y。
- 「k 增加 0.5」「开口减小 0.2」从当前值加减；「增加到 2」仍是改成 2。
- 「向下平移 1 个单位」「右移 3」落到 k 或 h；没有平移规则的图形回答不能这样移。「往上一点」「向下移一个」不当成 1。
- 回答里系数的叫法与滑块标签逐字相同。
- 圆在 x = 0、x = 1、x = 3 时分别给出两个 y、一个 y、没有点。
- 直线上问「把顶点高度改成 -1」不改系数，图形仍是直线。
- 换图形后提问记录清空。

全量 `node --test` 仍应通过。若旧测试因本功能失败，只修正本功能引入的断言，不放宽预制抛物线、1.5 秒和来源的既有断言。

## 页面验收

1. 选择预设，暂停到可以破壁的位置，破壁。确认滑块和曲线出现，来源仍是预先准备的示例。
2. 在右侧控制栏提问「把顶点高度改成 -1」。曲线顶点下降，k 的滑块和数字变成 -1，回答里也是 -1。
3. 接着问「x 等于 0 时 y 是多少」。回答是 -1，滑块不再变化。
4. 问「把开口改成 5」。a 停在允许范围的上限 1.2，回答写出 1.2。
5. 问「把半径改成 3」。曲线和三个滑块都不变，回答说明没有改。
6. 把 k 拖回窗口上沿之外能到达的最低值，再问一个会落在坐标窗口下面的横坐标。回答给出真实纵坐标，并说明在窗口外。曲线在窗口边界结束，不沿底边连成一条横线。
7. 按重置。系数回到这次破壁的初值。再问一次，提问作用在重置后的数上。
8. 焦点放在提问框里按 Esc。草稿清空，覆盖层还在。焦点离开提问框后再按 Esc，覆盖层退出。
9. 退出后提问框、送出和示例都变灰，送不出去，记录清空，提示回到「先破壁，再问这条曲线」。
10. 再破壁一次，确认暂停、拖动、滑块、重置、退出和 Alt+B 仍可用。开发者工具网络面板里，这次提问没有新的请求。
11. 点一个示例。它只填进输入框并把焦点放进去，不替你送出。
12. 问「抛物线向右平移 1 个单位」。h 的滑块加 1，回答写出改前改后的值。

布局用设备尺寸模拟量了三档，均无横向溢出：

- 1280×800：控制栏在右栏，宽 310。往下滚到送出框可见时，片子仍整块在屏内。
- 1050：单栏，提问区在片子下方约 590px。改完要往上滚才看到曲线，滑块在这一档也是如此。
- 560：提问区宽 478，三个示例一行放下，输入框 428 加送出 42。

键盘与读屏：

- 提问区内的焦点顺序是记录区、三个示例、输入框、「问」，全页没有正数 `tabindex`。
- 焦点样式沿用全局 `:focus-visible`。
- 记录区是 `role=log`、`aria-live=polite`，名称「提问记录」；问与答用「你：」「答：」前缀区分。
- 提问区样式没有过渡或动画。

### 没有验证或只用替代方式验证的

- 真键盘 Enter：浏览器工具发的是合成按键，不会触发表单隐式提交。改用点「问」和 `form.requestSubmit()`，走的是同一个 submit 事件。
- 真鼠标拖控制点：工具拖动没有带动系数。改在页面里给控制点派发合成 PointerEvent，走的是页面自己的拖动处理。
- 自动播放：内置浏览器里选择预设后片子没有自己播，改用「定位到第 6 秒」。Chrome 里的自动播放这次没看。
- 读屏实际播报：只核对了无障碍树里的角色、名称和 live 区域，没有用 VoiceOver 听。
- 以扩展形式在 Chrome 稳定版里加载、网络面板截图：这次没做。
