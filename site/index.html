CHROME MV3 扩展 · 数学抛物线原位交互

把视频里的死内容，
变成能拖的活模型

网课里那条抛物线只能看：位置、开口、顶点都是死的。BreakGlass 在视频原位画出一条可拖动的曲线， 参数实时联动；来源全程标注，失败有可恢复路径，感知等待不超过 1.5 秒。

零权限 零网络请求 零运行时依赖 209 项自动化测试通过

问题

能看见，但动不了

看视频时

老师画出 y = a(x−h)² + k，镜头一过就没了。想验证「a 变大开口变窄」只能凭空想象，

参数是死的，曲线只是像素。

用 BreakGlass

把视频暂停在那一帧，按 Alt+B：曲线出现在画面原位，拖动控制点或用滑块改 a / h / k，曲线、顶点、数字三者同步。

参数是活的，曲线是模型。

功能

已经做到哪，还没做什么

P0 已实现

  • 视频原位绘制抛物线，贴合内容区域（含黑边与 letterbox）
  • 控制点拖动 + a/h/k 三个滑块，越界自动钳制
  • 重置保留交互层，Esc / 退出移除覆盖层且视频保持暂停
  • 1.5 秒超时自动回退到预制结果，并持续显示原因
  • 结果校验：白名单公式、有限值、范围、视频/时间/画幅/请求号逐项匹配
  • 液态玻璃顶栏、键盘焦点可见、禁用态给原因、错误态立即播报

P1 已实现 · 仅打包样例

  • 默认关闭的识别适配开关（visionAdapter: off）
  • 识别候选走同一套校验器，必须标注 evidence: packaged-sample
  • 可信程度可选：低于 0.5 拒绝，界面永不显示百分比
  • 缺证据、越界、帧不匹配等九类坏样例全部拒绝并可重试
  • 识别判定耗时单独记 vision-decision，不混入预制回退口径

样例是随扩展打包的工程夹具，不表示外部识别已接通。

未派发

  • 真实视觉识别服务与单帧上传
  • Python / Pyodide / WASM 代码执行
  • 账号、云端同步、数据库
  • 任意网站注入（当前只覆盖扩展内演示页）
  • 顶点拖动同时改 h、k（语义待定）

怎么跑

三步，不用装任何依赖

  1. 1

    拿到代码

    git clone https://github.com/yxz6811/breakglass

  2. 2

    加载扩展

    打开 chrome://extensions，开启「开发者模式」→「加载已解压的扩展程序」→ 选择仓库里的 extension/

  3. 3

    打开演示页

    点扩展图标，页面自动打开。暂停到目标时间后按 Alt+B；Esc 退出。

想先验证一遍？仓库里只有一条命令：

node --test209 项通过，不需要 npm install。

边界

我们没做什么，以及还没验什么

没有做

  • 不上传单帧，不接外部识别服务，不建后端
  • 不读取浏览历史，不注入任意网站
  • 不在浏览器里放密钥，不启用远程代码
  • 不把预制结果写成识别成功

还没验

  • 浏览器手工验收（本环境无可控浏览器会话）
  • 回退首帧 ≤100ms 的真实采样（目前只有假时钟断言）
  • 四画幅真机 2% 对齐记录
  • 正式演示视频与配套素材（仓库未提交）

未执行的步骤不会被写成「通过」。
