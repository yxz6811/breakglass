# 打包识别样例（工程夹具）

这里放**随扩展打包**的识别样例。它不是正式网课素材，也**不代表外部识别已经接通**。

## 文件

| 文件 | 用途 |
| --- | --- |
| `fixture-parabola.json` | `visionAdapter: "fixture"` 时被唤醒层读取的识别候选 |

## 必须知道的约束

1. **它不是外部服务返回的结果。** `evidence` 必须是 `packaged-sample`；界面据此显示「识别结果」与「随演示打包的识别样例，尚未接通外部识别。」
2. **`frameSize` 必须等于当前视频的源尺寸。** 识别路径**不做**画幅换算（预制路径才会按比例放进当前帧）。包内 9 秒片子若不是 1920×1080，演练前必须把这里的 `frameSize` 与 `region` 改成实际尺寸，否则会被判 `frame_mismatch` 并进入可恢复错误。
   - 例：实际片子是 3024×1898 时，`frameSize` 写 `{ "width": 3024, "height": 1898 }`，`region` 按 `×1.575`（宽）与 `×1.7574`（高）换算为 `{ "x": 756, "y": 387, "width": 1512, "height": 1090 }`。
3. **`time` 必须落在当前目标时间 ±0.2 秒内。** 演示页默认目标时间是 6 秒，所以这里写 `6`。
4. **`requestId` 由唤醒层在装订时替换**为本次唤醒的冻结编号；样例里的值只是占位。
5. **`fallback` 必须是 `null`。** 识别样例不得声明超时回退。
6. **`confidence` 可以不写。** 写了就必须是 0 到 1 的有限数，且不得低于 0.5；界面**不会**显示百分比。本样例故意不写。
7. **提交配置必须保持 `visionAdapter: "off"`。** 本样例只在演练时被读；演练结束要把配置改回 `off`。

## 不含什么

不含密钥、上传地址、模型名或真实个人信息。读取路径只有扩展包内的这个文件，不发任何网络请求。
