演示页只播放这一个文件（相对仓库根目录）：

`extension/assets/video/breakglass-demo-9s.mp4`

文件仍不存在时，舞台上显示「选择视频」，状态句是「先选择一个视频。文件留在这台浏览器里。」不会改成加载失败。

此路径只确定扩展包内的播放源。演示页把目标时间初值设为 6 秒，供这段 9 秒片子使用；会话仍跟随输入框里的当前值。它不新增 `videoId` 或 `CurveResult`，也不表示夹具 JSON 里的区域已经按这段片子的像素写好。

在团队提供视频、`videoId`、目标时间、源尺寸、曲线区域和配套 `CurveResult` 之前，工程夹具只能验证状态、校验和几何计算，不能作为真实视频对齐的验收证据。
