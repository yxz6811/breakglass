## 3. 从“返回图形”改进为“说明依据”

建议流程：当前许可与媒体代次核对 → 有界当前帧 → 有限公式候选 → 程序换算/检查 → 坐标标定与像素检查 → 学生校对确认 → 确定性实线互动 → 私人学习记录与统一证据视图。模型负责读取候选，数学与合法性由程序计算；不执行模型脚本、自由 HTML 或通用公式 eval。

### 3.1 公式换算与不确定性

首轮仍只增强完整抛物线与既有直角三角形识别，七种手工模板继续可用，不扩展成任意图形识别。抛物线候选分别支持有限的一般式 `y=ax²+bx+c` 和顶点式 `y=a(x−h)²+k`；程序按 `h=−b/(2a)`、`k=c−b²/(4a)` 转换。例：`1.1x²−1.1x−1` 应得到 h=0.5、k=−1.275。a=0、溢出、缺字段、未知表达式或互相矛盾的读数均不能进入抛物线绘制。

首轮新单帧识别只使用可读题面作为数学读数依据；登记上下文和学生输入可提供独立探索条件，须保留实际出处，不能补成“这一帧已识别正确”或原位定位证据。现有上下文路径不以字幕补足截图缺失的数学标注。仅凭无刻度曲线的外形不能唯一恢复数值系数；显示“看出形状，数值条件不足”，允许学生手工填写自己的数学条件。人工填写形成新的探索条件，不能升级为“视频已识别正确”。负例包括字幕遮挡、低分辨率、小负号/指数、参数滑块与图像不同步、多曲线、没有数值刻度和不完整题面。

### 3.2 原位定位单独验证

先保存原帧、JPEG 缩放、可选 ROI 和 `contentRect` 的坐标关系；ROI 只从已获准帧本地派生，不增加采集或上传次数。若使用裁剪，必须映射回完整原帧。允许 sx 与 sy 不同；独立确认原点、可辨刻度、目标曲线及可见范围。墨迹覆盖率和模型锚点自洽都不能独自证明真实单位或目标正确。

拟采用“数学依据 + 标定依据 + 独立像素检查”的组合。多条相近曲线或多个近似匹配不能只取最高分，须拒绝或请学生选对象；候选优劣差值先用自制标注样本校准，再冻结阈值。原位曲线继续执行旧 001/003 的短边归一化误差 ≤2% 要求，并补真实四画幅证据，不改成肉眼大致重合。005 几何当前是按条件重建的独立画板，不能把旧曲线 2% 阈值直接宣布为几何已通过；以后若增加几何原位顶点，需独立冻结阈值与验收。

公式可用但位置不足时，右侧显示独立数学画板、原公式和“位置待校对”，保留二维及空间实线观察，不把图强行贴到视频。人工标定记录“学生校对”，不是模型自动对齐的证据。修改参数后的探索图也不代表与原视频继续重合。

### 3.3 来源、确认与保存

新共享流程使用独立 sidecar 区分结构候选、数学核对、位置核对、学生确认与派生探索。sidecar 的具体字段在 [011 契约草案](../specs/011-recognition-reliability/contracts.md)中提出，实施前再冻结。旧 `/read`、`CurveResult` 的字段/枚举、`createWake`、既有来源兼容和唤醒预算保持；新增确认只作用于明确启用的新共享流程，旧独立页改动另作兼容决策。

保存保留候选来源、原条件和当前探索关系；学生输入、AI 候选、预设与程序新题分别标注。渲染成功不等于学生确认。撤销识别时中止网络与等待中的提交链，旧结果不能显示、自动确认或写入学习记录；已确认且许可允许保留的个人数学记录仍按既有删除规则处理。

## 4. 模型兼容、响应边界与速度

建立服务端有限能力配置，描述供应商入口、模型、温度策略、图像传输、输出模式及 profile 版本；密钥继续只在未提交的服务端环境中。曲线、几何和复用几何调用的持续/上下文/摘要等路径共用校验；ASR 单独配置。没有配置时不测试供应商健康、不自动挑模型，继续预览和手工学习。

外部温度错误说明固定参数可能不兼容，不能据此把全部模型改为 1。例如阿里云百炼 Moonshot 提供的 `kimi/kimi-k3` 入口规定 temperature=1、reasoning_effort=max，且图像只接受公网 URL，不接受 Base64；这些约束只适用于该文档入口，不能推及所有 Kimi 服务。本项目当前 JPEG data URL 与此入口不兼容时应提示“不支持当前图像传输”，选用许可与传输均兼容的入口；不得自动把学生帧发布为公网图片。[该入口官方说明](https://help.aliyun.com/zh/model-studio/kimi-api-by-moonshot-ai)

JSON mode 可以帮助获得可解析 JSON，JSON Schema 的支持依模型而异；两者不能证明公式或位置正确。服务仍校验有限字段、关系、单位和身份。[结构化输出官方说明](https://help.aliyun.com/en/model-studio/qwen-structured-output)

复用已有 64KiB 有界上游读取机制，覆盖旧曲线响应；真实可读流在 JSON 解析前限制累计字节，取消/超时立即停止读取。错误只保存有限阶段、类型、耗时和非秘密配置版本，不能记录密钥、Cookie、原始画面或完整供应商响应。profile、提示与标定算法版本进入缓存身份；保持账号/访客 scope、epoch、许可、有效期和复用前后校验。

先测解码、前门部署探测、排队、模型、像素搜索、返回和前端呈现，分别列 P50/P95、超时比例与取消效果。主工作台 2.30ms 的历史参数 DOM/同步绘图记录不能当作 AI 速度或实际像素呈现耗时。旧 1500ms 唤醒、300s 预读、单帧/几何 30s、问答 10s 和新路径限额各自保持；较慢模型只在符合相应冻结预算的路径启用，预算内不能完成则明确失败，不能用自动重试堆积调用。

采样优化先检查变化再决定是否编码，但低成本签名若漏掉小符号变化必须回退。请求始终单在途、只保留最新候选帧、取消停止、失败不自动开启新会话。并发优化先量事件循环与 RSS，再选择全局限额、有限调度或隔离像素计算；缓存快速返回也要先核对许可与身份。不得新增第二个学习服务、无界队列或以多次请求绕过额度。

## 7. 验证方法与结果口径

自制或明确许可样本覆盖一般式/顶点式、正负系数、非等比例坐标、偏移原点、网格干扰、多曲线、无刻度、裁剪/遮挡与小符号变化。原帧、标注、许可、源码、模型入口/profile、提示、标定版本和尺寸随证据登记；训练/阈值校准样本与最终留出验收样本分开。授权与登记缺一不可，报告中的 B 站案例只能启发自制负例。

| 指标 | 记录方式与通过判断 |
| --- | --- |
| 公式 | 所有请求数、接受数、拒绝数、已接受方程正确数分别列示；有限程序换算夹具全部通过。真实模型质量单独实测，禁止只报告成功样本。 |
| 原位位置 | 仅对有独立像素标注且实际呈现的接受样本计分；顶点/参考点/可见曲线最大误差除以短边。旧曲线必须 ≤2%，同时列错位与未定位数。 |
| 不确定性 | 无数学依据、多目标歧义等负例正确拒绝或降级；列误接受和拒绝原因，不能用高拒绝率掩盖正例不可用。 |
| 撤销/隔离 | 确定性竞态夹具中，撤销后旧结果显示、自动确认、保存和缓存写入均为 0；另做真实浏览器取消，不推为全平台零风险。 |
