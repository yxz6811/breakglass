## 视觉与布局

网站`learning-site/`采用介绍站暗色：背景`#080b0d`，面板`#10171b`，文字`#f2f5f7`，辅助`#a2adb3`，强调`#71ddff`，细边`#303a40`，卡片12/16px圆角。复用aperture裂隙标志和字标；不复制外部字体或引入远程依赖。共享基础控件由theme.css提供，局部CSS覆盖只影响网站，旧演示页及注入宿主不更改。

桌面240px侧栏、顶栏当前身份、内容40px边距；概览用四个真实数字卡与两块状态区域。≤1050px卡片两列，≤760px侧栏变可横向滚动导航、内容16px边距。导航/表单/操作44px最小触点，焦点清楚，核心操作有键盘入口，减少动效生效。窄屏横向导航可滚动，但整个页面不可产生横向溢出。

## 功能与页面对应

| 现有界面 | 网站入口与真实行为 | 数据依据 / 验收对应 |
| --- | --- | --- |
| BG-U08 学习概览 | 当前账号或本机范围的疑问数、个人易错数、有错答证据数、课程位置；最近作答及理解状态 | 空范围为真实零值；UI-A17/18，只依据最近一次实际作答，不生成掌握率 |
| BG-U09 观看进度 | source完整指纹/版本、秒数与总时长；重新选同一文件才可定位 | 私人watch元数据允许pending文件，仍无AI许可；UI-A17/27，不永久保存原视频 |
| BG-U10 疑问与易错 | 按范围、来源、疑问/个人标记/实际答错筛选；恢复、删除、选中导入；编辑标题/备注/类型/原因标签 | wrong须attempt；UI-A12/15/16/18/31，sidecar不覆盖数学，409保留输入 |
| BG-U11 场景与理解复练 | 保存条件恢复；七种数学模板、SVG/同状态粒子、参数/视角重置；可跳过知识诊断、预测、提示和独立变式 | 实际程序答案与提示凭据；UI-A09/10/14/18/33，不把观看或诊断单题称掌握 |
| BG-U12 账户与数据设置 | 本机开发注册/登录/退出、分范围导出/删除及访客缓存清除重试；试点显示运行来源并关闭自助注册/公网插件配对 | HttpOnly/CSRF/归属/epoch；UI-A15/16/19/24/35，生产Secure/审批复核。模型仍可留空 |
| BG-U13 本地视频工作台 | 选择/拖入、解码/指纹、许可；实时/片段/渐进分析、暂停/继续/缺口/缓存及独立手工条件；可选登记短音轨 | ≤64MiB/600s/1920×1080；UI-A25–27/32/34，未知素材不分析；视觉默认无音轨，显式短音轨≤30秒；不上传整文件 |
| BG-U07 插件个人保存 | 状态页导出最小JSON，网站先审核并勾选存本机，再选择导入当前账号 | 来源/AI标识/数学状态保持；拒绝未知/媒体/凭证字段；不共享跨站cookie；008可显式配对未来保存同步，旧记录仍选择导入 |

每项有加载、空态、失败、提交中、成功与不可用原因。保存/删除成功必须来自实际存储或服务响应；切换账号立即隔离旧数据，取消旧队列和分析。账号与本机范围清楚可选，登录不自动迁移访客记录。当前明确导入迁移数学记录，访客作答与观看位置继续留在本机；账号理解状态依据账号内真实复练，不把重新导入当新作答。删除确认显示明确范围，失败不清界面或假称成功。

## 学习程度与进度

播放进度仅为位置。理解状态使用最近一次程序验证的实际答案：待验证、需要复练、使用提示完成、最近一次独立正确。查看答案也按帮助使用记录，不能再称独立完成。曾答错的历史证据与最近一次状态分别可见；建议复练为简单间隔提示、可跳过，不作为掌握或教学效果保证。自由解释暂不自动评分，不保存无必要的长文本。

## 实施与发布边界

代码实现和测试证据逐项回填007。网站账号服务为loopback开发，不称正式云端或跨设备发布。真实视觉模型正确率/延迟/长课摘要、B站处理许可及真实平台采集、地区/监护/跨境、真实学生学习效果均独立待验收；模型替身只验证流程。受限文件仍可本地预览、私人观看记录及独立学生数学条件；许可门禁不能靠勾选替代。

## 009补齐验收（UI-A31–35）

| 编号 | UI / 状态 / 验收 |
