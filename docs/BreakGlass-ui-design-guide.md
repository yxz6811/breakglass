# BreakGlass 交互功能的 UI 设计建议

> 本分支：`ui`。文档基于 `p2@77423ab` 的界面元素逐项核对；`ui` 分支的控件 id、状态名与设计令牌一致，但 `extension/src/page/main.js` 的接线实现与 `p2` 不同。

> **令牌与动效数值以 [BreakGlass-visual-spec.md](./BreakGlass-visual-spec.md) 为准**；本文只解释每项交互「为什么这样设计」。
>
> 覆盖范围：所有**需要用户真实操作**的功能（按钮、输入、滑块、拖动、键盘路径、持续反馈）。
> 依据：`spec.md`（FR-001~FR-019、SC-001~006）、`docs/BreakGlass-frontend-execution-plan.md`（P-01~P-05、FE-06、§10）、`docs/BreakGlass-constitution.md`（§4/§6/§7）、`AGENTS.md`（§6 动效与可访问性、§7 状态完整性）、`demo/demo.css`（现有令牌）、`p2@77423ab` 的真实行为。
> 状态与文案的现状清单见 [`BreakGlass-ui-inventory.md`](./BreakGlass-ui-inventory.md)；待实现项见 [`BreakGlass-ui-todo.md`](./BreakGlass-ui-todo.md)。

## 0. 通用规范（先定这些，再看单项）

| 项 | 建议 |
| --- | --- |
| 设计令牌 | 沿用 `--panel rgba(14,29,49,.92)`、`--line rgba(157,190,226,.22)`、`--muted #9fb4cc`、`--accent #71ddff`、`--accent-strong #1bb6e8`；建议补 `--warn #ffd08a`（错误/回退强调）、`--radius-btn 9px`、`--ease-out cubic-bezier(.2,.8,.2,1)` |
| 层级 | 三级就够：**主操作**（渐变实底，全局唯一：破壁；失败态改为重试）、**次操作**（透明 + `--line` 描边）、**禁用**（`opacity .45` + `cursor: not-allowed` + **原因提示**） |
| 尺寸节奏 | 4px 基线；按钮 `min-height: 40px`、内边距 9/12（现为 36px 高，触控偏小）；面板内区块间距 24px；参数行间距 16px |
| 焦点环 | 统一 `outline: 2px solid var(--accent); outline-offset: 2px`，不靠颜色变化传达；覆盖层控制点用 `stroke` 加粗 + 外发光 |
| 动效 | 状态切换 160ms、按钮按压 80ms、曲线入场 200ms、等待进度 1500ms 线性；缓动统一 `--ease-out`；**全部在 `@media (prefers-reduced-motion: reduce)` 降级为无动画** |
| 硬约束 | 回退首帧 ≤100ms（曲线出现动画不得推迟首帧）；`#state-label` 最小高度 48px 防跳动；覆盖层保持 `position: absolute`；不改写播放器原生控件（FR-016） |

## 1. 播放 / 暂停（`#play-toggle`）

| 项 | 建议 |
| --- | --- |
| 布局 | 传输条左起第一个；图标（▶ / ⏸，16px）+ 文本并排 |
| 视觉 | 次按钮；播放中切换为「暂停」文案与暂停图标 |
| 状态 | hover 描边转 `--accent`；active 下压 1px；无禁用态（始终可用） |
| 动效 | 图标交叉淡入 120ms，不做位移 |
| 可访问性 | 用 `aria-label` 动态表达动作（「暂停视频」/「播放视频」），不用 `aria-pressed` |
| 依据 | FR-001 |

## 2. 定位目标时间（`#jump-target`）

| 项 | 建议 |
| --- | --- |
| 布局 | 与「目标时间」输入组成一个时间组，用 1px `--line` 分隔与其他传输控件区分 |
| 视觉 | 次按钮；**无视频元数据时改为禁用态**并给原因提示，而不是点击后才提示（AGENTS §7） |
| 状态 | 禁用：`opacity .45` + tooltip「正式视频素材尚未提供」；可用：hover accent |
| 动效 | 定位成功后视频舞台边框闪一次（accent 30% → 透明，200ms）作为确认 |
| 可访问性 | `aria-label="定位到目标时间 12.5 秒"` |
| 依据 | FR-001、FR-002 |

## 3. 目标时间输入（`#target-time`）

| 项 | 建议 |
| --- | --- |
| 布局 | 时间组中间；宽度 88px，`inputmode="decimal"`，右侧「秒」单位后缀 |
| 视觉 | 紧凑数字输入；失焦时格式化到 1 位小数 |
| 状态 | 与当前时间差 ≤0.2 秒时，输入右侧出现小徽标「✓ 已对齐目标帧」（accent） |
| 校验 | `min=0`；非法输入不提交、恢复原值并给出字段级提示（`aria-describedby`） |
| 动效 | 徽标出现 160ms 淡入 |
| 依据 | FR-001、FR-002 |

## 4. 破壁（`#wake-button`，全局主操作）

| 项 | 建议 |
| --- | --- |
| 布局 | 控制面板首要位置，全宽（现状保留）；`Alt+B` 徽标放右侧 |
| 视觉 | 渐变主按钮；**仅在可用时**做 1.6s 呼吸（`scale 1→1.01` + accent 8% 光晕），传达「现在可以按」 |
| 状态 | disabled：`opacity .45` + 按钮下方一行原因（未暂停 / 未在目标时间 / 尺寸不匹配 / 正在等待）；hover：亮度 +6%、上移 1px；active：回位并 `scale .99`（80ms） |
| 动效 | off 路径是同步的，不显示 loading；按下后直接进入 §6 的曲线入场 |
| 可访问性 | `aria-keyshortcuts="Alt+B"`；禁用时用 `aria-disabled` + `aria-describedby` 指向原因文案 |
| 依据 | FR-002、FR-003、SC-001 |

## 5. 等待态与取消（P2 核心新增）

| 项 | 建议 |
| --- | --- |
| 布局 | 状态区下方出现「等待条」：左 16px 环形 spinner，中间文案，右侧「取消等待」次按钮 |
| 视觉 | 等待条用 `--panel` 底 + `--line` 描边；spinner 用 accent 2px 圆弧（1s 旋转） |
| 关键动效 | **1.5 秒线性进度条**（accent 20% → 100%，1500ms）：让「要等多久」可预期，到点即回退 |
| 降级 | `prefers-reduced-motion` 下 spinner 与进度条改为静态文案 + 省略号 |
| 可访问性 | 状态区 `role="status" aria-live="polite"`（已有），等待条加 `aria-busy="true"`；进入等待时焦点移到「取消等待」（行为已有，需要可见焦点样式配合） |
| 文案 | 「正在等待外部结果…」+「超过 1.5 秒将改用预先准备的示例，可随时取消。」 |
| 依据 | FR-011、执行计划 §10「识别中有明确加载反馈」、P-03 |

## 6. 超时回退的呈现（P2）

| 项 | 建议 |
| --- | --- |
| 视觉 | 来源芯片切为「预先准备的示例 · 超时回退」，在 accent 描边基础上加**虚线**以区别于正常预制 |
| 动效 | **首帧立即绘制最终几何**（保证 ≤100ms），随后做一次 200ms 的不透明度/光晕强调；不要用 dash 描边动画推迟首帧 |
| 强调 | 回退瞬间来源芯片背景闪一次（accent 12% → 透明，300ms） |
| 可访问性 | 状态区朗读「已改用预先准备的示例（超时回退）」；原因不能只靠颜色 |
| 依据 | FR-009、SC-003、Constitution §6 |

## 7. 可恢复错误与重试 / 退出（P2）

| 项 | 建议 |
| --- | --- |
| 布局 | 状态区给出原因；动作行中「重试」变主按钮（渐变），「退出」为次按钮；重置与拖动保持禁用 |
| 视觉 | 状态区左侧加 4px `--warn` 竖条；**不要用纯红**，与暗色主题冲突 |
| 动效 | 错误出现时状态区 160ms 上移淡入；**不做抖动**（连续重试时抖动会显得嘈杂） |
| 可访问性 | 错误用 `aria-live="assertive"`（比 polite 更及时）；焦点移到「重试」（行为已有） |
| 依据 | FR-010、SC-005 |

## 8. 参数滑块（`h` 已有；`a`、`k` 待实现）

| 项 | 建议 |
| --- | --- |
| 布局 | 三个参数**常驻三行**（只有 3 个，折叠反而增加操作成本）；每行「名称 + 数值 + 滑块」 |
| 视觉 | 滑块 `accent-color: var(--accent)`、数值 `tabular-nums`（已有）；建议数值可点击直接输入 |
| 状态 | 仅 `interactive` 可用；禁用时给原因；拖动中数值实时更新，松手 120ms 内高亮一次 |
| 可访问性 | `<label for>` 关联（已有）；补 `aria-valuetext="0.8（范围 0.4 到 1.2）"` |
| 依据 | FR-005、FE-06、`data-model.md` |

## 9. 控制点拖动（覆盖层 `circle`）

| 项 | 建议 |
| --- | --- |
| 视觉 | 视觉半径 10px（现状）；hover / focus 时 `transform: scale(1.2)`（不改几何）+ 8px accent 光晕 |
| 热区 | 叠加一个透明 `r=18` 的辅助圆，视觉小、热区大（触控友好） |
| 光标 | `cursor: grab` / 拖动中 `grabbing` |
| 动效 | 拖动结束 120ms 内 `scale 1.2 → 1` 回弹 |
| 待决策 | 顶点拖动是否同时改 `h`、`k`（analysis §8.2）。建议 v1 只改 `h`，v2 支持顶点双参数并提示「按住 Shift 同时改两轴」 |
| 可访问性 | `tabindex=0`（已有）；建议支持方向键按 `step` 微调；`aria-label="控制点：水平位置 h"` |
| 依据 | FR-005、analysis §8.2 |

## 10. 重置（`#reset-button`）

| 项 | 建议 |
| --- | --- |
| 布局 | 动作行第一个；次按钮 |
| 关键反馈 | 点击后**保留覆盖层**（现状），数值与曲线用 160ms 缓动回到初值，让「恢复原样」可见 |
| 动效 | 数值先闪 accent 再归位；曲线不做位移 |
| 可访问性 | `aria-label="重置到本次结果的初始参数"` |
| 依据 | FR-006、`research.md` §10 |

## 11. 退出 / Esc（`#exit-button`）

| 项 | 建议 |
| --- | --- |
| 布局 | 动作行最后；次按钮（不是危险色，不销毁数据） |
| 动效 | 覆盖层 120ms 淡出 + `scale 1 → .98`；**不做位移** |
| 状态 | `interactive` / `waiting` / `recoverable-error` 均可用（现已补齐） |
| 可访问性 | `aria-keyshortcuts="Escape"`；退出后焦点回到「破壁」按钮（当前缺失，建议补） |
| 依据 | FR-007、FR-013 |

## 12. 键盘与焦点路径

| 项 | 建议 |
| --- | --- |
| Tab 顺序 | 播放 → 定位 → 目标时间 → 破壁 → 参数 a/h/k → 控制点 → 取消/重试 → 重置 → 退出 |
| 焦点管理 | 进入等待 → 取消；进入交互 → 第一个参数滑块；进入错误 → 重试；退出 → 破壁 |
| 快捷键 | `Alt+B` 破壁、`Esc` 退出/取消（均已有）；空格保留给播放器（已有） |
| 提示 | 面板底部保留一行快捷键说明（页脚已有） |
| 依据 | FR-017、AGENTS §6 |

## 13. 来源标识（持续反馈，非操作但必须常驻）

| 项 | 建议 |
| --- | --- |
| 位置 | 页头右侧芯片 `#source-label` + 面板底部 `#source-note`（现状） |
| 三级视觉 | `等待素材`（muted 描边）/ `预先准备的示例`（accent 描边）/ `预先准备的示例 · 超时回退`（accent + 虚线 + 一次性闪烁） |
| 动效 | 切换 160ms 交叉淡入，不做位移 |
| 可访问性 | 只让状态区朗读，芯片不加 `aria-live`，避免重复播报 |
| 依据 | FR-008、Constitution §4/§6、SC-002 |

## 14. 视频原生控件（不改写）

| 项 | 建议 |
| --- | --- |
| 原则 | FR-016 要求唤醒不得改写播放控制、退出后播放器仍可用，因此保持 `<video controls>` 原样 |
| 视觉 | 仅在布局上把原生控件与自定义传输条分组（`--line` 分隔），不做样式覆盖 |
| 依据 | FR-016、`contracts/extension-surface.md` |

## 15. 建议的关键动画时序（可直接交给实现）

| 场景 | 时长 | 缓动 | 备注 |
| --- | --- | --- | --- |
| 等待进度条 | 1500ms | linear | 到点触发回退 |
| 回退首帧 | ≤100ms | — | 立即绘制最终几何 |
| 曲线出现强调 | 200ms | ease-out | 只做透明度/光晕，不改几何 |
| 状态文案切换 | 160ms | ease-out | 不改变容器高度 |
| 按钮按压 | 80ms | ease-out | 仅 `scale/translateY` |
| 覆盖层退出 | 120ms | ease-out | 淡出 + 轻微缩小 |
| 控制点聚焦/悬停 | 120ms | ease-out | `scale 1.2`，不改几何 |
