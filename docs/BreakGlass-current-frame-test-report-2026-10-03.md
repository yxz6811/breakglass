# 曲线模式当前帧识别修复测试报告

日期：2026-10-03
范围：`extension/demo/index.html`、曲线页 `main.js`、当前帧适配器、唤醒缓存入口及对应前端测试。介绍站、几何实验和历史审计报告没有改动。

## 修复结果

曲线页原来的「破壁」按钮只有在 003 预读得到匹配点后才可用，因此用户视频暂停在预读采样点以外时无法操作。本次修复保留同一个按钮：

1. 用户视频在任意已解码、暂停且合法的时间点都可以点击「破壁」或按 `Alt+B`。
2. 页面直接从舞台视频截取当前帧 JPEG，向已有本机 `POST /read` 服务提交恰好一帧；不会上传整段视频，也不会把本地文件地址发送出去。
3. 响应必须绑定本次 `readingId`、视频身份、精确时间、源画幅和合法抛物线定义，才会进入原有 SVG 交互。
4. 识别失败、超时、取消、播放、定位、换片或页面卸载都会保留用户视频并拒绝迟到响应；支持重试当前新暂停帧。
5. 已验证的当前帧缓存直接进入原会话，不走 1.5 秒预制回退、fixture 或模拟器。003 的最多 8 帧预读和 300 秒预算保持不变。
