## 1. 产品体验与范围

插件是主要入口：学生在支持的第三方网课网站观看视频时，直接打开插件。插件根据已准备的分析，在当前讲解中的公式、图形或关键条件旁放置可点击的小点。点击后展开通俗解析、互动数学场景或个人学习标记；退出后继续原视频。网站保留第二种方式：学生自行选择本地视频，在网站工作台中预览、识别与探索；网站同时用于当前账号的观看记录、疑问、个人错题与复练。

界面应帮助学生观察变化、理解原因和建立知识联系。粒子表达服务于数学观察；学习辅助由学生主动展开，不能要求先答题或登录才能继续原视频。

- 首个支持网站及其播放器模式在 M0 可行性验证后冻结；用户讨论的 B 站列为候选，优先评估 UP 主提供授权源素材预处理、插件对应讲解时间的模式，详见风险规划 §3.3。本文不承诺任意网站、受保护视频或跨域播放器都可处理。
- 第一批数学对象沿用可验证的二次函数与直角三角形能力，再逐个增加已登记模板。
- 函数图像保持二维数学关系，可放入可旋转空间展示，并始终提供“正视二维”；不得把平面曲线伪装成新三维数学对象。
- 几何实验必须写明固定条件、可变条件与单位，数值和关系由程序校验。识别候选未核对时不开放会改变题意的实验。
- 未登录可使用本地学习、保存疑问与错题；跨设备和账号记录需要真实登录与同步能力，完整产品交付至少到 M3。
- 网站“上传视频”首版表示选择本机文件供浏览器解码，确认后仅发送获准的稀疏帧/必要文本；不能把选文件写成整文件已上传云端。整文件云上传仅为未来独立可选模式，不是首版完成条件。
- 宣传站、扩展演示、支持网站注入与账号学习网站分别显示能力状态，不能通过统一视觉把规划变成“已支持”。

## 2. 仓库实际能力与复用边界

| 证据 | 当前事实 | 对本规划的影响 |
| --- | --- | --- |
| `extension/manifest.json` | MV3；没有 `content_scripts`，`permissions` 与 `host_permissions` 均为空 | BG-U01/U02 第三方接入需新建平台适配和按需权限流程 |
| `extension/demo/index.html`、`src/page/main.js` | 自有视频舞台、SVG 覆盖层、参数控制、本地确定性提问、阅读状态、取消/重试/退出 | 复用交互和视觉模式；不能把自有页面运行当作第三方注入验收 |
| `extension/demo/geometry.html`、`src/page/geometry.js` | 当前帧保存、候选核对、确认快照、直角三角形实验、问答和可跳过理解题 | 复用条件核对、来源与恢复原题语义；真实模型效果仍独立验证 |
| `extension/src/geometry/content-rect.js` | 处理 `contain` 与 `object-position`；其他 `object-fit` 会拒绝 | 首版覆盖已验证模式；`cover`、裁切和复杂 CSS 变换需独立适配，否则显示不支持 |
| `extension/src/page/main.js` 的 `captureFrames()` | 自有源通过隐藏视频抽帧，不移动舞台视频播放头 | 新平台不得后台 seek 学生正在看的播放器；独立采样通路是否可用需实测 |
| `breakglass-reader/src/server.mjs` | 已有本地 `/read`、`/geometry/read`、`/geometry/ask` | 是旧切片契约，不包含账号或云端预处理；新增契约不能冒充这些接口已有字段 |
| `extension/src/ui/theme.css` | 冰面表面、深屏、基础控件、焦点、动效降级令牌 | 新学习界面继承令牌，注入页面需样式隔离，不把全局 `body`/`*` 规则加到宿主 |
| `site/index.html`、`site/modules/education.html` | 暗色介绍站，导航指向扩展演示；没有登录、个人学习页或网站视频导入工作台 | 宣传站可保留；BG-U08 至 U13 是待建学习区域，不声称现有导航已能上传识别或打开账号功能 |
| `site/background-gl.js`、`site/vendor/` | 本地 Three.js 的背景 Mesh/Shader 与降级效果 | 可评估包内资源复用；数学粒子模板、扩展 CSP 接线和确定性验证均尚未完成 |

复用必须保留旧切片控件 ID、`createWake` 契约、来源与状态机。新平台会话采用独立数据适配；新字段不得悄悄塞进旧 `CurveResult`。旧测试、截图和动效结果不能证明新平台、粒子数学或账号同步已通过。

## 3. 继承的视觉和交互基线

令牌仍以 `extension/src/ui/theme.css` 与 Visual Spec 1.6.0 为准，1.6.0 继承 1.5.0 的既有数值。学习网站新区域继承冰面主题；介绍站暗色背景不强制迁移。

| 角色 | 数值与使用规则 |
| --- | --- |
| 浅色表面 | 页面 `#F7FAFC`；冰面 `#EEF4F8/#C8DCE6`；面板 `linear-gradient(150deg, rgba(255,255,255,.94), rgba(200,220,230,.82))` |
| 文字与强调 | 主文字 `#14232F`、辅助 `#4E6474`、强调 `#0B6F91`；主按钮 `#0B6F91 → #1755BD` 与白字 |
| 深屏 | 视频和数学画板 `#0E1720`；文字 `#eef5ff`、辅助 `#9fb4cc`、图形/焦点 `#71ddff`；警示 `#ffd08a` |
| 警示 | 浅色表面 `#8A5A00`；原因文字与图标同时出现，不能仅靠颜色 |
| 排版 | Inter/system 字体栈；正文 16px/1.6，控件 14px，辅助 12–14px，H2 24px；时间与参数使用 tabular-nums |
| 间距 | 4px 基线；区块 24px、参数行 16px；学习网站容器最大 1320px，桌面边距 32px，≤720px 为 16px |
| 控件 | 普通按钮、表单、参数输入最小高度 44px；圆形 dock 桌面 48px、≤1050px 为 44px |
| 圆角 | 按钮/表单 9px、卡片 14px、舞台 13px、面板 20px、来源胶囊 999px；普通提示标签可用既有 10px |
| 焦点 | `outline: 2px solid var(--accent); outline-offset: 3px`；深屏控件用深屏强调色；不得仅改变颜色 |
| 禁用 | `.45` 透明度、`not-allowed` 与可读取的原因；等待、权限和数据未就绪分别解释 |
| 动效 | 按压 80ms；tooltip/图标/关闭 120ms；状态文案 160ms；入场强调 200ms；`cubic-bezier(.2,.8,.2,1)` |
| 状态与玻璃 | 状态区最小高 48px；顶栏模糊 18px、小按键 6px；小面积玻璃，折射默认关闭 |

热点默认发光轮廓；新热点进入当前有效时段时可做一次 200ms 柔和强调，随后静止。学生可主动启用缓慢呼吸提示；不使用快速闪烁或让整屏不断运动。脉动节奏需单独可访问性评估，不从旧演示按钮直接推导。

`prefers-reduced-motion: reduce` 关闭热点呼吸、粒子自动旋转、背景漂移、dock 放大和淡入，状态直接更新。学生主动调整参数仍立即得到数学反馈；减少动效不删除核心互动。低性能模式进一步减少粒子、模糊与像素密度，支持 SVG/线框。

新预处理 UI 不复用旧 1500ms 倒计时，也不把 100ms 回退、003 的 300s 阅读或当前单帧 30s 开发默认写成新能力承诺。新性能按首次可用热点、全部处理完成、点击到可交互分别实测后冻结。

## 6. 视频页面布局与操作闭环

桌面不挤压或改写宿主播放器。覆盖层仅热点命中区域接受指针事件，空白区域穿透；面板优先使用已验证的旁侧空间，空间不足改为可收起的浮层。宿主字幕、原生控制条和课程导航保留可操作。

```text
支持网站原页面                           BG-U04/U05 冰面面板
+------------------------------------+ +----------------------------+
| 原视频                            | | 抛物线平移     [来源] [关闭] |
|       · 图像热点                   | | 一句话解释 / 当前公式        |
|                 · 条件热点         | | [动手探索] [这里没懂]        |
|                                    | | 深屏数学画板 + 参数与读数    |
| 原站字幕及原生播放控制              | | [恢复原题] [返回视频]        |
+------------------------------------+ +----------------------------+
BG-U03 [已准备 2 处 · 后续处理中] [取消]   可选展开：预测/提示/解释理由
```

1. 学生主动启用当前网站；首次传输前说明实际提交的是字幕/代表帧/当前帧中的哪些数据、交给谁处理，确认后开始。
2. 热点可在播放时提示。点击后仅暂停这次选中的视频，冻结点击时间、视频版本和数学对象；不自动跳到更早的讲解时刻。
3. 先显示有效缓存解析，场景模板按需加载。选中对象用小范围轮廓关联，面板标明对应视频时间；其他热点不抢焦点。
4. “返回视频”关闭探索、恢复该会话暂停位置，并尝试继续播放；浏览器拒绝自动播放时显示“点击继续播放”。
5. 普通关闭只关闭面板，不额外跳转或强制播放；学生自行播放/seek 时原位探索退出，个人已保存快照仍保留。
6. 页面离开、换视频、关闭插件释放监听、任务和 GPU 资源；迟到结果不能再次弹出 UI。

注入根需局部样式隔离，层级相对宿主适配，不能使用全站最大 `z-index` 抢占其他弹窗。全屏节点、iframe/Shadow DOM 和原生控件遮挡分别验证；没有安全挂载点时转为热点列表/侧边入口并说明原位提示不可用。

### 6.1 网站视频导入的次级闭环

BG-U08 保持插件学习为主要入口，“上传视频”是次级动作；BG-U13 页面解释“选择后在本机预览，开始识别前会说明实际发送材料”。选择器与拖放等价且键盘可达；不能要求登录才选择文件或进行已允许的本地探索。

```text
BG-U13 网站上传/识别工作台
+--------------------------------------+----------------------------+
| [选择视频] 或拖入文件                  | 已选素材 / 本地来源        |
| 本机视频预览 + 播放/暂停/时间          | 本次发送的帧/文本及接收方  |
| 对应热点；探索后返回本机视频           | [开始识别] [取消] [重试]   |
+--------------------------------------+----------------------------+
U03 分段准备状态 | U04解析/U05互动 | U07本机保存/账号同步反馈
```

1. **选择与校验**：检测实际文件大小、容器/编码解码能力及读到的时长；扩展名/MIME只作候选信息。支持格式/编码、文件大小、时长、帧和资源上限在M0/M2真实试验后冻结；不编造当前支持清单或默认秒数。超限、零时长、无法读元数据、损坏/不支持编码分别给原因、可重新选择；合法预览不自动启动识别。
2. **本机预览**：浏览器生成临时源并本地解码，不发送完整文件。状态写“已在本机打开”，不写“上传成功”；文件名仅展示名称，不发送本地完整路径。换文件/退出释放临时URL、独立采样器与旧资源。
3. **材料与用途**：开始前按实际分段策略展示要发送的稀疏帧范围/数量或冻结上限、必要文本、处理方/地区、用途和保存范围；素材许可、儿童/地区/供应商/跨境门禁与插件一致。学生确认且条件满足后可在该范围自动分段，不逐帧重复弹窗；未准共享只关闭共享，不阻断合法私有分析。
4. **准备与探索**：通过独立本地解码/采样通路准备，不seek预览播放器。U03如实呈现部分/完整/无热点/片段失败，已校验点先可用；U04–U07提供同样解析、条件核对、参数场景、疑问/错题保存。任务完成不抢播放头；访客仅保存允许的本机结构记录，账号同步到M3才接通。
5. **取消与删除**：“取消识别”停止该任务和上游调用，保留仍获准的成功片段；“重试”仅重试失败片段并重新检查门禁/额度。“移除本机视频”释放源、停止相关任务并隐藏热点；“删除学习记录”明确是否同时删除结构分析/个人记录并复用U12真实删除语义，不能把释放临时源等同云端删除。删除/撤权后的旧响应不得复活记录。
6. **未来整文件云上传**：只列为独立可选模式，不是首版或M2必做项。实施前另冻素材与接收方许可、地区/监护/跨境、文件额度、传输取消、保留、删除和新端点契约；不能向旧reader `/read` 或几何端点发送整文件，不能沿用其预算。未实施时不出现可点击却无行为的“整文件上传”主操作。

### 6.2 插件获取方式与材料范围

M0 对比产品规划 §6.5 的主动当前画面/选区、当前标签页渐进辅助、端侧候选及作者知识层/官方接入，不在 UI 中声称已支持全部方式。U01 展示实际可用模式、素材/平台条件、当前捕获对象和是否需要传输材料；用户开启浏览器捕获与允许外部 AI 处理分别呈现，不能把一次截图权限当作云上传许可。

当前画面路径展示“分析当前画面/选区”，裁剪预览与候选校对后进入 U04/U05。标签页辅助展示持续的“本次辅助已开启/停止”状态，仅已取得且已校验的时段出现热点；关闭、撤权、换视频时停止流/请求/队列。端侧与云处理依实际运行位置标识，条件不足或模型无法识别时保留校对/输入入口。作者知识层显示素材和分析版本，原视频更新后重新校验。

截图/捕获缺少可信媒体时间或画面位置、受保护内容黑屏、浏览器权限拒绝或原播放声音受影响时，明确说明对应限制，使用独立解析侧栏或退出。UI-A01/05/07/08/19/21 在实施选定方式后加入权限拒绝、截图裁剪、捕获停止、时间/坐标误配和声音继续播放场景；技术权限不替代平台/素材许可。

## 7. 预处理状态、文案与竞态

预处理的后台状态不能自动暂停视频、移走播放头或弹开解析。当前画面没有点，与全片没有点必须分开说明。

| 状态 | BG-U03 文案示例 | 可用动作与结果 |
| --- | --- | --- |
| 未开始 | “开启后，可在这段讲解中查看互动提示。” | 开始；未授权传输时先展示实际用途 |
| 处理中 | “正在准备当前片段，视频可以继续观看。” | 取消；无总量时不显示虚假百分比或倒计时 |
| 部分就绪 | “已有 2 处可探索，后续片段仍在准备。” | 当前已校验点可点击；未处理处不标成无知识 |
| 完整 | “已准备完成，共 5 处可探索。” | 查看列表；完整范围必须与视频版本和处理覆盖一致 |
| 当前时段无点 | “当前画面没有可用提示。” | 看其他已准备时段；不虚构当前热点 |
| 已完成但无热点 | “这段视频暂未找到可用的数学互动。” | 继续观看、主动保存疑问；不能换成无关预设 |
| 不支持 | “此播放器暂不能读取画面，可继续原视频。” | 查看支持说明、关闭；若仅字幕可用，明确能力差异 |
| 失败/部分失败 | “这一片段未准备成功；已准备内容仍可使用。” | 重试失败片段、取消；区分网络/模型配置/校验拒绝 |
| 已取消 | “已停止后续准备，已准备的内容仍可使用。” | 显式继续准备；取消本身不清空成功片段 |
| 版本失效 | “视频已变化，旧提示暂时隐藏。” | 重新准备；旧结果不挂到新视频 |
| 迟到结果 | 无新弹窗，不切换当前内容 | 丢弃失效响应，调试记录可追踪原因 |

所有回调验证当前 `sourceKind + sourceId + videoVersion + taskId + contextEpoch`；场景解释同时验证 `mathObjectId + sceneRevision`；账号写入同时验证 `accountId + authEpoch`。平台来源与网站本地来源分别建命名空间，文件名/标题相同不合并；本地文件指纹、版本核对算法在新契约冻结，不能用文件名代替。字段名均为新领域建议，不修改旧契约签名。

取消只停止相应任务，退出探索只结束相应场景。切换到新对象后旧解释不能覆盖新面板；旧保存响应仅在原身份、记录修订及有效授权仍满足且记录未删除时更新原记录，不能把提示显示到另一账号或另一题上。删除或撤权增加相应失效代次，取消相关在途任务和重试/同步队列；删除前的迟到保存不能使记录复活。失败请求保留允许保留的草稿与当前视频，重试由学生触发并重新检查门禁。

## 8. 时空热点与播放器适配

每个热点绑定视频身份与版本、有效 `[start,end)` 时间区间、原帧尺寸、画面归一化区域 `x/y/width/height∈[0,1]`、数学对象 ID 与分析版本。时间按视频媒体时间，不按页面打开时间；数学坐标与画面位置分开存储。

- **位置映射**：先计算实际内容矩形，再将归一化区域映射到 CSS 像素；不把 letterbox 黑边算入教学画面。canvas 绘制尺寸随 DPR 调整，CSS 热点位置不乘两次 DPR。
- **seek/倍速**：seek 开始立即隐藏原位点并结束旧冻结上下文；seek 完成后按新媒体时间筛选。倍速只改变时间推进，不伸缩热点时间区间。
- **时间有效性**：代表帧无法证明图形在整段保持位置；必要时缩短区间或补关键帧轨迹。没有可靠定位的数据只进列表，不画猜测位置。
- **重叠**：两个热点的点击区域重叠时显示聚合入口“2 个知识点”，点击展开标题列表；不随机选择，不把全部点挪离对象。列表有与原对象对应的编号和选中反馈。
- **命中区**：视觉点保持小；点击与键盘入口目标至少 44×44px。狭小区域靠聚合和列表保持可用；不要把旧控制点 `r=18` 当作新热点已满足尺寸。
- **遮挡**：不压字幕或播放器控件；可在对象边缘放点并用短关联线指向目标。展开面板不能遮住学生正在比较的关键条件。
- **尺寸/滚动**：resize、滚动、容器变更、全屏、orientation、DPR 和 metadata 更新后重算；坐标不加位移过渡，避免热点追赶图形。
- **全屏**：仅对已验证的播放器全屏节点挂载。原生视频全屏无法承载覆盖层时明确暂停热点；网页全屏退出后恢复映射。Esc 优先保留浏览器/宿主退出全屏。
- **换视频/SPA**：监听已验证的媒体身份变化，销毁旧会话；URL 相同也要比对视频版本。一个页面多个视频先选课程主视频，不能误暂停广告或小窗。
- **受限画面**：CORS、DRM、跨域 iframe、裁切或复杂变换未适配时明示不支持；不绕过保护、不把黑屏采样呈现成成功。

## 9. 解析、互动场景与可选学习辅助

BG-U04 默认只展开“一句话解释 + 当前公式/条件 + 一个易错提醒”。详细推导、基础补充和对话由学生继续展开，避免首屏长篇解析。每条解析有对应数学对象和来源位置，学生能回到原讲解核对。

| 内容类别 | UI 标签 | 可触发的记录行为 |
| --- | --- | --- |
| 视频中老师明确讲述 | “视频讲解 · 02:15” | 可保存引用位置；字幕推断不能标成老师原话 |
| 根据当前知识生成的常见错误提醒 | “AI 学习提示” | 可标记为个人易错；不能自动进入个人错题 |
| 未确认的识别条件 | “识别候选 · 待核对” | 校对/确认/反馈；未核对不能呈现权威结论 |
| 学生主动表示没懂 | “我的疑问” | 保存疑问和备注；不推断已做错题 |
| 学生实际错答或手动收录 | “我的错题 · 作答记录”或“手动收录” | 进入错题本；保留收录来源与原始回答 |

BG-U05 显示“原讲解条件”和“当前实验条件”。参数变化即本地重算图形、读数与关系；不逐帧调用模型生成几何。恢复原题回到已确认快照；渲染模板不得更改数学定义、条件、单位或参数合法范围。

- 粒子场景初始呈现数学最终形状，强调动画不延迟可用图形；空间查看提供轴标、单位、正视和重置视角。
- 平面函数采用正视可读坐标；旋转只是观察视角。立体几何才使用对应三维模板、截面和关系约束。
- WebGL 不可用、上下文丢失或低性能时保留相同数学模型，转 SVG/线框并说明“已使用简洁图形”。原视频继续可用。
- 场景不支持时显示能做的解析和疑问保存，不返回看似匹配的演示模板。可选“打开示例”必须标明独立示例。

BG-U06 的预测、提示、解释理由与基础诊断均可跳过。提示从关键条件、下一步到完整解析逐层展开；记录提示使用，独立完成与依靠提示完成分别显示。模型对开放解释只能提供建议与理由；无法确定的回答显示“需要进一步核对”，不强行判错。

基础补充通过短判断找到可能缺少的知识，再返回同一个视频对象。混合变式在单点基本练习后由学生选择；复练先隐藏解析，提交/主动查看后再展开。任何学习检查都不能锁住“返回视频”。

```text
BG-U08 学习首页                 当前身份/同步状态 | BG-U12 设置
```

- **首页**：展示当前身份与数据范围；插件入口优先，次级“上传视频”明确进入U13本机选择。M2即可提供访客入口与允许的本地学习；未登录显示“本机记录”，M3登录后展示当前账号内容，不把公开热点缓存数量计入个人掌握度。
- **观看记录**：显示课程标题、站点、最近媒体时间和更新时间；继续观看优先回原站定位，受限时提供准确链接和时间说明。
- **场景恢复**：先核对入口、视频版本与模板版本。平台来源回原站；网站本地来源重开时要求用户重新选择文件并核对指纹/版本，未匹配前不套旧热点，异名同内容也不自动合并来源。允许独立恢复已保存且仍支持的数学快照，并说明原视频待重新选择/不可用；恢复场景不要求永久保存或云端存储原文件。
- **疑问与易错**：默认个人记录，按知识点/课程/类型筛选；“常见提示”单独区域，学生手动标记后才成为个人易错。
- **错题详情**：展示原条件、原答、收录方式、错误原因及确认状态；AI 错因建议可编辑/确认，不把未经核对标签当作学生确定的薄弱点。
- **复练**：答案默认隐藏；提供作答、逐层提示、跳过、查看解析与变式。安排按结果与提示使用调整，初版不宣称固定间隔是所有学生的最佳方案。
- **进步表达**：分别展示独立完成、使用提示、仍待核对和延后复练表现；观看时长、点击次数不能显示为知识已掌握。
- **列表完整性**：首屏加载、空记录、筛选无结果、分页加载失败、长标题/公式和已删除条目均有可恢复行为；回到列表保留筛选与位置。

### 11.1 中国大陆与海外首发的权利及身份 UI

地区名单、适用年龄、监护路径、供应商用途、留存和跨境方案由权利风险规划及实施契约分别冻结。选择“中国大陆/海外”不是通用合规开关；海外应落实具体国家/地区。尚未冻结或无法证明必要授权的路径保留允许的本地学习，云上传、账户存储和共享按实际门禁关闭并解释原因。

允许的正常流程是“启用 → 确认本次用途 → 自动分段准备 → 热点解析/互动”，同一授权范围内不逐帧弹窗。U01/U12 分别呈现本地分析、外部AI处理、个人结构保存、共享分析的可用范围；例如允许私有分析但不允许共享时，U03照常处理并标明“仅自己可用”，共享入口禁用。当前帧模式不能用来绕过处理权限；范围或供应商变化后重新核验。

以上逐用途门禁同时适用于插件入口和U13网站导入；“文件由用户选择”不自动证明版权/供应商/跨境许可，“未登录”不豁免儿童规则。两入口都保留已经允许的本地学习方式，不为使学生选择文件或探索手工模板强制账号。文件选中后尚未获准的云处理不发送材料。

## 12. 键盘、焦点与响应式

- 所有热点都可从等价列表到达；Tab 进入插件控件，Enter/空格激活当前按钮，参数可通过键盘和数值输入操作。空格不注册成全局插件快捷键。
- 打开非模态解析时焦点进入标题或首个操作，背景播放器仍可达；模态选择/登录窗才约束焦点范围。关闭后回触发点；点已消失则回热点列表/插件入口。
- 等待操作由用户触发时焦点进入取消；自动后台预处理仅播报状态，不抢焦点。错误聚焦重试只在当前用户动作相关时发生。
- Esc 顺序：浏览器/宿主全屏退出 → 顶层模态 → 当前插件探索关闭。旧曲线输入框 Esc 清草稿规则保留，不通过全局监听覆盖输入语义。
- `role=status`/`aria-live=polite` 汇总后台状态，当前失败用可读错误提示；逐帧参数和大量热点不连续朗读，读数可主动查询。
- 宿主有快捷键冲突时显示替代按钮并允许停用插件快捷键；旧演示 Alt+B 不默认成为所有第三方站点的独占快捷键。
- 桌面可用空间足够时旁侧面板；≤1050px 控件可换行、圆形按键44px；<720px 探索面板采用可关闭抽屉并保留视频返回入口，不能照搬旧310px固定宽。
- 网站在1440、1024、768、390px及200%缩放核对换行、溢出、焦点和主要动作；插件另在宿主播放器尺寸下验证，页面断点不能代替播放器适配。
- U13拖放区域有等价44px选择按钮；校验错误通过文件输入描述关联，换文件/移除后焦点回选择按钮。拖放不能是唯一导入入口；状态播报区分本地读取、材料提交和准备成功。

产品验收关联：BG-A01 ← UI-A01/07；BG-A02 ← UI-A02/03/08/20；BG-A03 ← UI-A04/05/07；BG-A04 ← UI-A06/09/10；BG-A05 ← UI-A12/13/14/18；BG-A06 ← UI-A14–17及UI-A27的账号部分；BG-A07 ← UI-A10/11/19；BG-A08 的学习效果另采集学生结果，UI-A13/18只能证明流程可用；BG-A09 ← UI-A21–24，与权利风险规划的地区准入检查联合执行；BG-A10 ← UI-A25–27，网站导入同时联合BG-A09门禁与BG-A06账号证据。

平台兼容只列实际通过的模式；真实账号同步需要真实服务与至少两端验证；数学测试需与目标对象的确定性结果比较。学习效果另以同学习时间下独立变式、延后复练和同类错误复发记录验证，不由 UI 截图判断。
