# BreakGlass（破壁）前端 Constitution

> 版本：1.4.0　日期：2026-10-02　状态：前端执行基线，待团队冻结
>
> 本文件只约束 BreakGlass 的前端与 Chrome 扩展实现。它补充根目录 `AGENTS.md`，不改变项目只负责前端的边界，也不代表其中能力已经实现。需求、计划、任务和代码都应引用本文件；团队冻结后，未完成的 P1 能力不能反向抬高 P0 的验收门槛。

## 1. 优先级与交付范围

### P0：单场景数学抛物线 vertical slice

P0 唯一交付门槛是一个可重复演示的数学场景：使用团队提供的录屏或固定机位视频，完成播放、暂停、目标帧定位、破壁入口、与视频内容对齐的 SVG 抛物线、参数调整、重置、退出，以及加载、错误、取消、超时和本地预制保底。

P0 不承诺任意视频、通用视觉识别、完整代码沙盒或纯本地识别。预制结果可以支撑演示，但必须明确标记数据来源。

### P1：独立增强 vertical slice

Python/Pyodide、本地 Web Worker、真实视觉识别适配属于独立 P1。每项都需要自己的开关、契约、安全预算和验收记录，不得阻塞或稀释 P0，也不得因为本文件自动扩展成完整代码沙盒。

### 开播前阅读：独立切片

2026-10-02 团队书面决定：片子可以播放时即开始阅读，在整段上稀疏抽帧，不从片头逐帧扫描。第一处结果算完且校验通过，就停在那一帧，破壁只取出已经存好的结果。整段阅读单独计时，截止 5 分钟。破壁点击不再阅读，也不加长 1.5 秒。

「下一个」只跳到已经校验过、时间更晚的下一处。定位没落定，破壁禁用。还在读时停在当前，时间不变，覆盖层不换，不许当场再算。没有下一处时按钮禁用。

换到的必须是这一帧自己的结果。尺寸对不上就拒绝，不用预先准备片子上的那条曲线顶上，来源不写识别成功。读失败或断网，回到 `breakglass-demo-9s.mp4`，并丢掉失败这支片子上的点。用来验收阅读的另一支片子，地址不得是这个文件。

点破壁到覆盖层出现，仍要求热缓存至少 20 次、P95 ≤ 100ms，并与第一处出现的耗时分开记。破壁后要有 `contentRect`，且 `maxRatio` ≤ 0.02。这些记录目前没有，该验收保持未通过。

模型密钥不进入扩展包。外部阅读服务不在本仓库实现。完整约束以 `.specify/memory/constitution.md` 1.6.0 原则 VII 为准。本切片未实现前，不得声称评委或用户已经能用自己的视频完成阅读。

以下内容不属于当前交付范围：用户注册或登录、云端同步、历史记录数据库、点赞分享、多语言、多对象识别、C++/Java/Go 等语言支持，以及其他不直接服务核心演示的 SaaS 功能。

## 2. 前端边界与技术路线

- 交付形态是 Chrome MV3 扩展加浏览器前端；P1 可选使用本地 WASM。严禁新增 Node.js、FastAPI、Docker 云端执行容器、业务后端、数据库或服务端鉴权。真实识别接口是外部依赖，只按已确认契约接入，浏览器代码不得放置服务端密钥。
- 技术路线只能选一条并写入执行计划：**Vanilla JS + 原生 CSS/SVG**，或 **Preact + 固定构建工具（可含 Tailwind）**。不得把 Vanilla JS、Preact 和 Tailwind 同时写成无条件技术不变量。没有既有工程约束时，P0 默认采用 Vanilla JS + 原生 CSS/SVG。
- P0 优先使用原生 SVG 绘制；P1 如引入 Pyodide 或绘图库，必须锁定精确版本、资源来源、完整性校验和离线资源策略。`Pyodide v0.25+` 或未锁定版本的 Function-Plot 不能作为可复现依赖声明。
- MV3 manifest 权限、content script、service worker、Worker/WASM 路径和 CSP 约束必须记录在执行计划中；扩展不得加载远程可执行代码。

## 3. Zero-Intrusion 与支持边界

- 视频控制、当前时间和源尺寸读取只能使用标准 HTML5 Video API（包括 `currentTime`、`videoWidth`、`videoHeight`、播放/暂停事件和元素实际显示矩形）。扩展注入、生命周期和消息通信可以使用 MV3 content script、service worker 和标准消息 API。
- 首版只承诺已验证的域名和页面结构：页面中存在可访问的目标 `<video>`，扩展可以在其上方挂载独立透明 overlay。跨域 iframe、权限不足的 iframe、Shadow DOM、DRM、无法访问的媒体和未验证播放器不纳入验收；标准 DOM 不能绕过同源限制。
- 只在 `<video>` 上方挂载独立 SVG/overlay。不得改写播放器控制条、拦截广告或 DRM、替换媒体源，或进行会破坏原网页的 DOM 变更。按下 ESC 或退出后，必须移除 overlay、监听器和消息通道，播放器立即回到原网页状态。

## 4. 确定性结果门禁

“Zero LLM hallucinations”不是可执行机制。LLM/Vision 只能生成候选结构化结果；结果进入绘图或执行层前必须通过固定 JSON Schema、白名单曲线或 AST 节点、语法限制、有限值检查、尺寸和参数范围检查，以及 `requestId`、`videoId`、时间和可选置信度校验。

字段缺失、解析失败、数值非有限、帧不匹配或低于约定置信度时，结果必须被拒绝并显示可恢复状态，不得进入执行层。真实识别和预制数据必须经过同一个 `CurveResult` 适配器，`source` 只允许 `vision` 或 `preset`；界面持续展示来源和回退原因，预制结果不得伪装成识别成功。

严禁把修改后的代码发给大模型并要求其预测输出或模拟逻辑。代码结果只能来自确定性本地执行器、断言和可记录的运行状态。

## 5. P1 Pyodide 与 Worker 安全

本节仅在 P1 开关启用时适用：

- 每次执行使用可重建的 Web Worker。超时、取消、异常或页面卸载时强制 `terminate`，并显示对应状态；不得让旧 Worker 继续占用页面。
- 默认安全预算为：单次执行 watchdog 2s、输入 ≤ 256KiB、输出 ≤ 64KiB、内存目标 ≤ 128MiB。浏览器不能保证跨平台的硬内存隔离；若运行时无法测量内存，必须记录限制，并在超时、OOM 或异常时 terminate。未冻结或未验证这些预算前，P1 不得宣称可执行任意 Python。
- 禁止网络访问、动态安装包和未列入白名单的包/模块；只加载随扩展打包或经过完整性校验的固定资源。
- Pyodide、WASM、Python 包和绘图库的首次加载、Worker 初始化和缓存命中分别计时，不能混入 P0 预制交互指标。

## 6. 每节点本地 Mock 与超时保底

每一个交互节点都必须读取静态 JSON 配置中的 `enableLocalMock`。配置至少包含 `enableLocalMock`、`fallbackAfterMs: 1500`、预制结果键和是否已预热的标记；预制 JSON 必须符合统一 `CurveResult` 契约，并与视频标识、目标时间、帧尺寸、图形区域和参数范围匹配。

`enableLocalMock` 是明确的构建或运行配置，不得在生产构建中意外开启。真实请求超过 1.5 秒时，前端自动取消或标记请求超时并接管预热缓存，不要求用户再次点击；这种“无感”只表示流程不中断，界面仍必须显示“本地预制/超时回退”和原因。真实请求的业务失败不得被静默改写为成功；无可用缓存时保留错误、重试和退出入口。

回退必须先校验当前 `requestId`、视频和帧位置，迟到的真实结果一律丢弃。P0 的目标是超时事件到首个可见 SVG 帧在冻结设备和热缓存条件下 P95 ≤ 100ms；该指标不含网络、扩展注入、视频首帧解码、Pyodide 初始化或开播前阅读。开播前阅读使用单独的 5 分钟截止。点破壁到覆盖层出现仍用热缓存 P95 ≤ 100ms，且至少 20 次，不得与第一处出现的耗时合并，也不得把 `fallbackAfterMs: 1500` 加长。这两项阅读验收记录目前没有。

## 7. 几何映射与固定机位范围

坐标实现必须区分原始帧像素、数学坐标和页面显示坐标：

1. 使用 `video.videoWidth` 和 `video.videoHeight` 作为源尺寸。
2. 使用视频元素实际显示矩形，结合 `object-fit`、`object-position` 和视频内容区域计算 letterbox/pillarbox 后的映射。
3. 固定 SVG `viewBox` 原点、缩放比例和坐标方向，并在窗口变化、全屏、页面缩放和设备像素比变化后重新计算。

验收至少覆盖 16:9、4:3、竖屏和带黑边样例，并按冻结的像素误差阈值检查叠加位置。首版支持范围锁定为录屏或固定机位课件；不支持手持晃动、强透视或动态实拍，也不要求前端自动判断视频是否符合该范围。

## 8. 可测性能口径

所有性能数据必须记录事件起点、终点、缓存状态、浏览器和测试机器，并报告 P50/P95。至少分别记录：

- 预制交互首次可见：用户触发预制路径到首个 SVG 帧绘制；
- 感知等待：请求发出到真实结果、错误或超时；
- 回退显现：超时事件到缓存 SVG 首帧；
- Pyodide 首次初始化和缓存初始化。

“200ms 冷启动”不再作为未定义的总指标。若保留该目标，必须明确只适用于热缓存预制路径，并在执行计划中写出设备、浏览器、网络和统计口径。

## 9. 模块交接

页面与结果规则只通过 `.specify/memory/constitution.md` 的「交接接口」通信。唯一唤醒工厂是 `createWake`。时钟、会话状态、`fail(code, message)` 和计时方法都以该节为准。不得再写 `createWakeController`、`onOutcome`、`begin` 或另一套 `schedule` 参数顺序。

## 10. 治理、冲突与修订

- 产品范围与模块交接以 `.specify/memory/constitution.md` 为治理源。本文件保留前端基线，不得另写一套工厂、时钟或会话状态。根目录 `AGENTS.md` 的前端职责边界始终生效。用户最新明确决定可以触发修订，但不能绕过修订流程直接形成隐含例外。
- 发现任务、需求、计划或代码违反本文件时，必须在进入实现或合并前标记，并说明影响。需求与 Constitution 冲突时先修订并递增版本号，再回写 Plan/Tasks；不得用低层文档静默覆盖高层约束。
- 例外必须记录原因、影响、责任人、有效期限、恢复条件，以及是否阻塞 P0；没有记录的例外不视为批准。
- 修改本文件必须递增版本号、更新日期并在末尾变更记录中说明。每次 Spec、Plan、Tasks 和代码审查都要执行一次合规检查。

## 11. P0 验收证据

- 目标视频可重复播放、暂停和定位；破壁入口只在合理状态可用。
- 预制曲线、参数、拖动、重置和退出可重复执行，来源始终可见。
- SVG 在四类宽高比和窗口变化后保持与视频内容区域对齐；键盘焦点和 ESC 路径可用。
- 加载、资源失败、识别失败、超时、取消和无缓存都有可操作反馈；旧请求不能覆盖新帧。
- 超时回退使用匹配的本地 JSON，且不冒充真实识别；按本文件的性能口径记录结果。

P1 只有在开关、契约、安全预算、精确依赖版本和测试证据齐备后才可标记完成；其余内容写为实验或外部依赖，不得声称已实现。
