## 1. 优先级与交付范围

### P0：单场景数学抛物线 vertical slice

P0 唯一交付门槛是一个可重复演示的数学场景：使用团队提供的录屏或固定机位视频，完成播放、暂停、目标帧定位、破壁入口、与视频内容对齐的 SVG 抛物线、参数调整、重置、退出，以及加载、错误、取消、超时和本地预制保底。

P0 不承诺任意视频、通用视觉识别、完整代码沙盒或纯本地识别。预制结果可以支撑演示，但必须明确标记数据来源。

旧001–005支持扩展内演示页及其HTTP静态页面，读取用户选择的本地文件与包内示例。006按第16节新增受控教学页的显式MV3注入及固定loopback请求桥；支持范围和验收以006记录为准，任意网站及B站仍未验证。零侵入的媒体边界与退出清理继续适用于所有入口。展示站效果与四图形本地探索也不证明视频识别链路。

### P1：独立增强 vertical slice

Python/Pyodide、本地 Web Worker、真实视觉识别适配属于独立 P1。每项都需要自己的开关、契约、安全预算和验收记录，不得阻塞或稀释 P0，也不得因为本文件自动扩展成完整代码沙盒。

### 开播前阅读：独立切片

2026-10-02 团队书面决定：片子可以播放时即开始阅读，在整段上稀疏抽帧，不从片头逐帧扫描。第一处结果算完且校验通过，就停在那一帧，003 的缓存破壁只取出已经存好的结果。整段阅读单独计时，截止 5 分钟。这条预读路径点击破壁不再阅读，也不加长 1.5 秒；用户于 2026-10-03 授权的当前帧按需请求另按下节执行。

「下一个」只跳到已经校验过、时间更晚的下一处。定位没落定，破壁禁用。还在读时停在当前，时间不变，覆盖层不换，不许当场再算。没有下一处时按钮禁用。

换到的必须是这一帧自己的结果。尺寸对不上就拒绝，不用预先准备片子上的那条曲线顶上，来源不写识别成功。读失败或断网时，用户选中的片子留在画面上，失败片子上的点丢掉，不自动换回 `breakglass-demo-9s.mp4`。这支示例片只在点「选择预设」时播放。用来验收阅读的另一支片子，地址不得是这个文件。

点破壁到覆盖层出现，仍要求热缓存至少 20 次、P95 ≤ 100ms，并与第一处出现的耗时分开记。破壁后要有 `contentRect`，且 `maxRatio` ≤ 0.02。这些记录目前没有，该验收保持未通过。

模型密钥不进入扩展包，也不提交到仓库。阅读服务的源码在 `breakglass-reader/`，不打进扩展包，不部署成云端后台。完整约束以 `.specify/memory/constitution.md` 2.2.0 原则 VII 为准。本切片未实现前，不得声称评委或用户已经能用自己的视频完成阅读。

账号、云端同步与必要学习记录数据库不属于旧 001–005 的验收条件，现已纳入第 13 节的新产品规划。点赞分享、多语言、C++/Java/Go 等语言及无关 SaaS 功能仍不在本次范围；新规划不代表这些服务已经实现。

### 当前帧曲线按需识别：独立增强

2026-10-03 用户要求自己的视频可在任意暂停帧请求识别画面曲线。本次以显式单帧操作实现，按 [当前帧曲线计划](./BreakGlass-current-frame-plan-2026-10-03.md) 和 Spec Constitution 2.2.0 原则 IX 执行。任意时刻表示不受 003 采样点限制，首版 reader 仍只支持一条完整抛物线，不承诺任意视频或所有曲线都能识别。

- 请求复用既有本地 `POST /read`，只发送当前一张缩小 JPEG 和必要身份、时间、时长、源尺寸及可空课程说明；暂停或加载文件本身不自动上传。模型密钥与结构化指令留在 reader，调用供应商须向用户说明。
- 严格校验 `origin: external`、请求编号、当次视频绑定、点与曲线编号、当前帧时间、源尺寸和完整 `CurveResult`。仅成功校验后的缓存结果交给 `createWake`，不新增后端、来源枚举或曲线会话状态。
- 单帧识别开发默认截止 30s，取消须传至 reader 与上游；该预算待真实预跑冻结，不是已测性能。它不改变 003 的 300s 预读或原唤醒的 1500ms 保底，识别等待与缓存绘制各自计时。
- 播放、定位、换片、地址变更、取消、退出、媒体错误和离开页面均使旧请求作废。视频源、时间与尺寸检查须结合请求 token 和媒体代次，不能因回到同一秒就接纳旧结果。显式当前帧操作不得被旧预读结果抢回另一帧。
- 空地址、无点、失败、超时或校验拒绝时保留视频，显示原因并允许显式重试；不套用 `demo-parabola` 或换回 9 秒片。界面按本次外部请求标明“当前帧识别”，点内仍沿用 `/read` 的 `source: preset` 缓存格式，不能伪装成包内识别样例。
- 真实模型、完整 MV3、四画幅 2% 对齐及像素呈现验收独立记录。Node 替身测试与本地成功演示不能替代这些证据；历史任务和报告不因新增入口改变。

### 当前帧直角三角形闭环：005 独立切片

以 [`specs/005-insitu-right-triangle/spec.md`](../specs/005-insitu-right-triangle/spec.md)、[实施计划](../specs/005-insitu-right-triangle/plan.md)、[任务](../specs/005-insitu-right-triangle/tasks.md) 和 [场景/动作契约](../specs/005-insitu-right-triangle/contracts/scene-actions.md) 记录。本次目标为暂停当前帧、提取并校对题目条件、受约束改边、确定性计算、对话动作、恢复原题、理解问题及返回视频；实际实施和验收状态以任务清单和 [几何验证记录](./BreakGlass-geometry-validation.md) 为准。部分实施不得计为完整验收通过。

- 首版一份直角三角形题：规范化 ∠A=90°、AB/AC 直角边、BC 斜边。数学条件来自题目标记、文字及用户确认，不从图片比例猜边长。原帧用于追溯，独立画板按条件重建。
- 显式触发后可向本地 reader 发送当前单帧 JPEG 与必要元数据；用途及供应商调用必须可见。问答只提交结构化题目和文字。接口及 `SceneResult` 独立，代理/浏览器双重校验，模型只产候选条件与受限动作，BC 用 `Math.hypot` 计算。
- 用户确认后保存原题快照；改边、批量动作、恢复均经过确定性校验。用请求、视频、帧与场景修订号拒绝旧结果。失败保留视频，提供校对、重试和退出，不用无关预设覆盖用户题目。
- 005 可扩展既有 `breakglass-reader/`，密钥仅在本地环境。单次输入上限 4MiB，开发默认识别 30s、问答 10s，真实预跑后冻结；这些不是已测结果。几何等待与画板更新独立计时，不修改既有 1500ms 保底。
- 001/003 的曲线接口与来源规则、004 的多图形提问规格继续保持独立。005 不继承 004 的不识别新图形条件。预设/手工流程、真实识别流程、学习理解各自验收，长期记忆提升另测。
- 自制教学示例及对应条件只证明演示/预设路径。加载示例不自动捕获、上传或识别；对应条件须在有效暂停题面上显式加载并校对确认，来源保持 `preset`。已知题面与文件名不计入真实识别或学习效果证据，素材来源见 [视频说明](../extension/assets/video/README.md)。

### 几何实验自动阅读：原则 XVIII

2026-10-06 用户要求几何实验跟曲线演示一样：对自己的视频自动识别画面里的几何图形，然后破壁。按 [006 规格](../specs/006-auto-geometry-lesson/spec.md)、[实施计划](../specs/006-auto-geometry-lesson/plan.md) 和 Spec Constitution 2.7.0 原则 XVIII 执行。替身页面和 `POST /geometry/lesson` 已落地，不代表真实识别已通过验收。

- 自己的视频可播放且已填阅读地址后自行稀疏阅读，最多 8 张、整段 5 分钟。第一处通过就停在那一帧，破壁只取已存结果。仅仅暂停不上传。失败保留这支片子，不换成预先准备的示例。
- 一帧只接受一个条件写清的直角三角形、圆或线段。像素只用于摆放，长度和半径来自画面标记，斜边由程序计算。破壁后一次只改一项允许条件。
- 使用独立结果和会话，不改 `CurveResult`、`createWake`、003 抛物线预读、005 显式单帧工作台或原则 IX 的当前帧抛物线。可在既有 `breakglass-reader/` 增加无状态阅读；密钥只在本地环境。不新增账号、数据库或另一套识别服务。
- 热缓存 20 次记录和真实模型正确率尚未产生，对应验收保持未通过。

## 2. 职责边界与技术路线

- 交付形态是 Chrome MV3 扩展加浏览器前端；P1 可选使用本地 WASM。旧切片保持既有本地无状态 reader 和前端边界；新产品规划允许第 13 节限定的身份与必要学习记录责任，具体服务形态与契约在实施时确定。006复用本地无状态reader新增单帧识别和短观察摘要端点，几何阅读另增 `POST /geometry/lesson`，二者都不新增账号/持久化服务、数据库或生产部署；云端代码执行容器仍不在范围。浏览器代码不得放置服务端密钥。
- 上条为既有前端基线；既有 reader 按原则 VII，005 的 Node 本地无状态识别/问答任务按原则 VIII，当前帧曲线复用 `/read` 按原则 IX，几何自动阅读按原则 XVIII，均与 `AGENTS.md` 第 0 节一并执行。旧切片不引入数据库或账号；新学习记录按原则 XI 分离规划。云端代码执行和整段视频上传仍不在范围。
- 技术路线只能选一条并写入执行计划：**Vanilla JS + 原生 CSS/SVG**，或 **Preact + 固定构建工具（可含 Tailwind）**。不得把 Vanilla JS、Preact 和 Tailwind 同时写成无条件技术不变量。没有既有工程约束时，P0 默认采用 Vanilla JS + 原生 CSS/SVG。
- P0 优先使用原生 SVG 绘制；P1 如引入 Pyodide 或绘图库，必须锁定精确版本、资源来源、完整性校验和离线资源策略。`Pyodide v0.25+` 或未锁定版本的 Function-Plot 不能作为可复现依赖声明。
- MV3 manifest 权限、content script、service worker、Worker/WASM 路径和 CSP 约束必须记录在执行计划中；扩展不得加载远程可执行代码。

## 3. Zero-Intrusion 与支持边界

- 视频控制、当前时间和源尺寸读取只能使用标准 HTML5 Video API（包括 `currentTime`、`videoWidth`、`videoHeight`、播放/暂停事件和元素实际显示矩形）。扩展注入、生命周期和消息通信可以使用 MV3 content script、service worker 和标准消息 API。
- 首版只承诺已验证的域名和页面结构：页面中存在可访问的目标 `<video>`，扩展可以在其上方挂载独立透明 overlay。跨域 iframe、权限不足的 iframe、Shadow DOM、DRM、无法访问的媒体和未验证播放器不纳入验收；标准 DOM 不能绕过同源限制。
- 只在 `<video>` 上方挂载独立 SVG/overlay。不得改写播放器控制条、拦截广告或 DRM、替换媒体源，或进行会破坏原网页的 DOM 变更。按下 ESC 或退出后，必须移除 overlay、监听器和消息通道，播放器立即回到原网页状态。
- 005 在扩展内采用原帧与独立数学画板并列的布局，按题目约束校验，不套用抛物线原位叠加的 2% 像素指标；任意网站注入仍需另行规格与验证。

## 4. 确定性结果门禁

“Zero LLM hallucinations”不是可执行机制。LLM/Vision 只能生成候选结构化结果；结果进入绘图或执行层前必须通过固定 JSON Schema、白名单曲线或 AST 节点、语法限制、有限值检查、尺寸和参数范围检查，以及 `requestId`、`videoId`、时间和可选置信度校验。

字段缺失、解析失败、数值非有限、帧不匹配或低于约定置信度时，结果必须被拒绝并显示可恢复状态，不得进入执行层。真实识别和预制数据必须经过同一个 `CurveResult` 适配器，`source` 只允许 `vision` 或 `preset`。既有 `/read` 的预读与当前帧结果使用 `origin: external` 和点内 `source: preset`、`fallback: null` 进入缓存通道；界面分别说明“这次阅读”或“当前帧识别”，不把它变成包内 `packaged-sample`。界面持续展示来源和回退原因，预制结果不得伪装成识别成功。

严禁把修改后的代码发给大模型并要求其预测输出或模拟逻辑。代码结果只能来自确定性本地执行器、断言和可记录的运行状态。

## 5. P1 Pyodide 与 Worker 安全

本节仅在 P1 开关启用时适用：

- 每次执行使用可重建的 Web Worker。超时、取消、异常或页面卸载时强制 `terminate`，并显示对应状态；不得让旧 Worker 继续占用页面。
- 默认安全预算为：单次执行 watchdog 2s、输入 ≤ 256KiB、输出 ≤ 64KiB、内存目标 ≤ 128MiB。浏览器不能保证跨平台的硬内存隔离；若运行时无法测量内存，必须记录限制，并在超时、OOM 或异常时 terminate。未冻结或未验证这些预算前，P1 不得宣称可执行任意 Python。
- 禁止网络访问、动态安装包和未列入白名单的包/模块；只加载随扩展打包或经过完整性校验的固定资源。
- Pyodide、WASM、Python 包和绘图库的首次加载、Worker 初始化和缓存命中分别计时，不能混入 P0 预制交互指标。

## 6. 每节点本地 Mock 与超时保底

每一个交互节点都必须读取静态 JSON 配置中的 `enableLocalMock`。配置至少包含 `enableLocalMock`、`fallbackAfterMs: 1500`、预制结果键和是否已预热的标记；预制 JSON 必须符合统一 `CurveResult` 契约，并与视频标识、目标时间、帧尺寸、图形区域和参数范围匹配。

`enableLocalMock` 是明确的构建或运行配置，不得在生产构建中意外开启。真实请求超过 1.5 秒时，前端自动取消或标记请求超时并接管预热缓存，不要求用户再次点击；这种“无感”只表示流程不中断，界面仍必须显示“本地预制/超时回退”和原因。真实请求的业务失败不得被静默改写为成功；无可用缓存时保留错误、重试和退出入口。

回退必须先校验当前 `requestId`、视频和帧位置，迟到的真实结果一律丢弃。P0 的目标是超时事件到首个可见 SVG 帧在冻结设备和热缓存条件下 P95 ≤ 100ms；该指标不含网络、扩展注入、视频首帧解码、Pyodide 初始化或开播前阅读。开播前阅读使用单独的 5 分钟截止。点破壁到覆盖层出现仍用热缓存 P95 ≤ 100ms，且至少 20 次，不得与第一处出现的耗时合并，也不得把 `fallbackAfterMs: 1500` 加长。这两项阅读验收记录目前没有。

## 7. 几何映射与固定机位范围

坐标实现必须区分原始帧像素、数学坐标和页面显示坐标：

1. 使用 `video.videoWidth` 和 `video.videoHeight` 作为源尺寸。
2. 使用视频元素实际显示矩形，结合 `object-fit`、`object-position` 和视频内容区域计算 letterbox/pillarbox 后的映射。
3. 固定 SVG `viewBox` 原点、缩放比例和坐标方向，并在窗口变化、全屏、页面缩放和设备像素比变化后重新计算。

验收至少覆盖 16:9、4:3、竖屏和带黑边样例，并按冻结的像素误差阈值检查叠加位置。首版支持范围锁定为录屏或固定机位课件；不支持手持晃动、强透视或动态实拍，也不要求前端自动判断视频是否符合该范围。

## 8. 可测性能口径

所有性能数据必须记录事件起点、终点、缓存状态、浏览器和测试机器，并报告 P50/P95。至少分别记录：

- 预制交互首次可见：用户触发预制路径到首个 SVG 帧绘制；
- 感知等待：请求发出到真实结果、错误或超时；
- 回退显现：超时事件到缓存 SVG 首帧；
- Pyodide 首次初始化和缓存初始化。

“200ms 冷启动”不再作为未定义的总指标。若保留该目标，必须明确只适用于热缓存预制路径，并在执行计划中写出设备、浏览器、网络和统计口径。

## 9. 模块交接

页面与结果规则只通过 `.specify/memory/constitution.md` 的「交接接口」通信。唯一唤醒工厂是 `createWake`。时钟、会话状态、`fail(code, message)` 和计时方法都以该节为准。不得再写 `createWakeController`、`onOutcome`、`begin` 或另一套 `schedule` 参数顺序。

原则 IX 的已校验单帧阅读缓存通过同一个 `createWake({ cachedReading: true, ... })` 的 `startCached({ paused, currentTime, frameSize })` 打开，返回形状与原 `start` 一致。只有严格 `true` 启用；规则层复核缓存的编号、视频、时间与源尺寸后装订会话。它不缩放画幅，不读取 Mock 开关，不启动 1500ms 看门狗或识别样例/演练替身；原 `start` 的 P0 配置和回退不变。精确签名、方法集合和门禁以 Spec Constitution 2.7.0 的交接接口为准。几何阅读不进入该工厂。

## 13. 插件沉浸学习与 UI 功能对齐

产品目标是学生在支持的网课页面直接使用插件，点击公式或图形附近的热点，获得通俗解析、易错提醒和可操作的数学场景。网站负责账号、观看记录、疑问、个人错题与复练。完整约束以 Spec Constitution 2.2.0 原则 XI 为准，执行文件为 [产品规划](./BreakGlass-immersive-learning-plan-2026-10-06.md) 和 [UI 规划](./BreakGlass-ui-plan-2026-10-06.md)。

- 首版逐站验证标准 Video API、采样来源与最小权限，保留原播放器；后台处理不 seek、暂停或替换正在观看的视频。不支持的域名、播放器或帧获取方式须明确说明，不绕过 DRM、同源或权限边界。
- 新模式通过允许获取的文本与稀疏代表帧渐进预处理，当前片段先可用。热点与视频身份、内容版本、秒级区间、源尺寸、归一化内容坐标及数学对象绑定，迟到结果不能覆盖当前帧。点击已就绪热点直接读取经校验缓存，深层问答独立等待、取消和重试。
- AI 输出候选结构，程序验证数学条件与计算数值，再用参数化模板绘制。函数保持其二维数学含义；空间几何与曲面有明确条件。粒子承担呈现，坐标轴、轮廓与辅助线保持清晰；信息不足可校对或显示原图解释，不猜长度或任意重建三维。
- 轻量发光热点仅提示可探索位置，减少动态效果时静止。沿用共享冰面、深屏、44px 控件和可见焦点；新增组件、网页内布局、全屏/窄屏、遮挡与键盘路径均按 UI 规划独立验收，不直接复制介绍站的开场动画。
- 预测、逐层提示、自我解释、间隔复练和易混变式可由学生主动展开。老师讲解要点、系统常见易错提醒、个人疑问/标记与实际错误答案分别呈现；系统提醒不自动计入个人错误。
- 新产品完整交付包含真实登录与当前账号观看、错题和复练记录。未登录可本地学习；登录后的本地历史合并须由学生选择。本机保存、Mock 登录、待同步和云端确认分别表达，不让失败显示成已同步。
- 身份、权威记录与归属校验由独立服务责任承担，方案/接口/数据保留在实施计划中冻结；不将旧 reader 改成账号数据库。账号切换与退出隔离缓存、停止旧队列并拒绝旧响应；记录最小化，可删除，结构记录不持久化原视频、原始帧、供应商原文或密钥；网站独立临时素材模式按第 15 节执行。公开可复用视频分析与私人记录分开，私人视频不进入共享缓存。
- `BG-F01`–`BG-F12` 与 `BG-U01`–`BG-U13` 一一追踪到入口、状态、动作、数据依赖和 UI 验收。产品规划负责功能与阶段，UI 规划负责行为，视觉规范负责共享令牌，版本化契约负责数据语义；任何范围改变同步这四项。

## 15. 插件优先的双入口与用户视频识别

按 Spec Constitution 2.2.0 原则 XIII，保留两种入口：插件直接在支持的网课页面使用，网站允许学生自行导入视频进行识别。插件是主入口，M1 优先完成真实站点闭环；M2 复用已有分析/数学组件补网站导入，M3 统一个人记录。网站不依赖先装插件，也不只承担记录管理；当前静态站和扩展选片不代表新网站入口已实现。
