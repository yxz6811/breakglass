# 009 学习深化与渐进处理验证 · 2026-10-07

009 本机学习闭环获得下列实际浏览器、账号 HTTP 和原生音轨证据。视觉模型与转写供应商均使用明确标识的传输替身；真实模型质量、B 站支持、正式云部署和学生学习效果没有据此通过验收。执行范围遵守 Constitution 2.5.0、[009需求](../specs/009-learning-completion/spec.md)与[独立契约](../specs/009-learning-completion/contracts.md)，不替代旧 P0/003/005 的未通过证据。

## 实际浏览器与学习流程

执行：`node scripts/verify-learning-completion.mjs`。脚本为本次验证启动独立空闲 loopback 端口及仓库外账户数据目录，不连接用户正在使用的 4174 站点、不读取 `.env`，只注入进程内视觉传输替身。运行环境是 Windows、Node v24.21.0、Chromium 151.0.7922.34。

[脱敏浏览器报告](test-evidence/learning-completion-2026-10-07/browser-summary.json)记录 **12 项通过**、零页面错误和零非预期控制台错误。最后一轮包含混合复练轮换与最新运行入口描述。HTTP 409 备注修订冲突与音轨配置空的 HTTP 503 是特意执行的拒绝路径，不被当作成功响应。

## 原生短音轨

[原生音轨报告](test-evidence/learning-completion-2026-10-07/native-audio-summary.json)记录 **4 项通过**：实际 FFmpeg 解码并通过有界 multipart 发送给显式传输替身；未许可素材门禁；无音轨视频明确失败；已登记文件变化后拒绝上传。

测试使用仓库外临时生成的自制纯音视频，实际裁剪得到1秒音轨。报告中的 **64.7782 ms** 是此次单次解码观测，不是 P50/P95、实时识别目标或供应商延迟。真实 FFmpeg 与真实 HTTP 得到验证；转写文字由替身提供，纯音不是语音样本，因此没有验证语音识别准确率、数学口述识别或声画关系融合。临时视频、WAV 和请求载荷未进入本证据目录。

## 缓存与生命周期边界

服务端根据登记素材、视频/分析版本、供应商配置非秘密指纹、字幕指纹、精确采样时刻及 JPEG 摘要生成私有缓存身份。缓存最多40条结构化结果记录、总计2MiB、有效期24小时；账号缓存绑定用户及学习数据删除 epoch，访客缓存仅保留于进程内私有 scope。磁盘不包含原帧、原视频、密钥、密码或会话令牌。

独立渐进任务最多20个片段/600秒素材、单片段30秒、默认4帧、单在途，任务截止30分钟；旧008片段接口每会话4次不变。失败停在未完成片段，学生主动继续才重试；不能自动续建任务绕过配额。暂停丢弃迟到响应并保留已就绪结果，取消清除暂存；删除、退出、撤权和清缓存使对应能力失效，防止旧结果再次写入。本机记录清除使用访客缓存独立端点，不清当前账号缓存。

这些边界有专门的缓存、HTTP 与生命周期测试。最终提交门禁同步核对会话自然到期和已提交删除epoch；即使能力在真实磁盘rename期间失效，也会在同一串行队列内原子恢复之前已提交的缓存、拒绝新候选。回归使用真实临时磁盘并在rename完成时确定性撤销能力，无真实等待；磁盘、内存及重启读取均确认新候选不存在，之前有效记录仍保留。

浏览器验收证明上述真实媒体与交互流程可运行，不证明模型内容正确，也不把本机账号当作已经上线的公网身份服务。
