## 1. 产品结论与当前事实

建议定位为“网课现场的数学理解与复练工作台”：学生发现没有理解的地方，能在同一视频旁核对条件、预测变化、动手观察、解释原因，再通过独立新题与隔时复练检验理解。后台摘要帮助定位讲解，不代替学生解题。

项目有可验证的差异化机会，但当前尚未证明稳定的市场竞争优势。技术演示、模型替身测试、真实学生学习收益属于不同证据。开源组件和粒子效果容易被复制；可靠的视频与数学对应、经过审校的错因内容、低操作成本和长期学习证据更值得积累。

## 2. 学习方法怎样进入产品

按任务和证据选用方法，不把所有方法同时塞进播放器。研究支持某种教学安排，不等于我们的实现已产生同样效果。

| 方法与依据 | 在项目中的具体安排 | 使用边界与优先级 |
| --- | --- | --- |
| 提取练习：[Dunlosky 等，2013](https://doi.org/10.1177/1529100612453266)；课堂测验元分析 [Yang 等，2021](https://doi.org/10.1037/bul0000309) | 可选“先独立试一次”；答案默认收起；只有实际提交形成作答证据 | 核心。不能把点开解析、预测选择或复述答案算独立正确 |
| 间隔学习：[Cepeda 等，2006](https://doi.org/10.1037/0033-2909.132.3.354) | 合并当前复习口径；依据错误、辅助与独立表现给可解释建议；用户可改时间/跳过 | 核心。1/3/7/14/28 天只是当前产品规则；最优间隔随保持目标变化 |
| 交错练习：[Rohrer 等，2020](https://doi.org/10.1037/edu0000367) | 学会单类基础后，混合易混策略；让学生判断应使用哪种关系 | 第二阶段。不是随机打乱；初学者可先做单类和例题 |
| 例题渐退：[Atkinson 等，2003](https://doi.org/10.1037/0022-0663.95.4.774) | 经程序/教师审校的完整例题→补一个关键步骤→独立变式 | 核心补齐。例题阅读和补步骤不能混成独立完整解题 |
| 自我解释：[Rittle-Johnson 等，2017](https://link.springer.com/article/10.1007/s11858-017-0834-z) | 每类模板可选回答“什么没变/为什么能用这个关系/错误说法哪里不成立” | 核心。即时学习有支持，长期/课堂证据更有限；文本不自动评分 |
| 图形与语言整合、具体到抽象：[IES 学习实践指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) | 图形、公式、条件、短解释紧邻；预测后调参数；对照变化前后 | 核心。2D 始终可用；3D 只在空间关系有帮助时展开 |
| 解释性反馈：[Wisniewski 等，2020](https://doi.org/10.3389/fpsyg.2019.03087) | 告知哪一条件/步骤不符，给可操作的下一步；提供例子与反例 | 核心。错误答案不能直接推断唯一错因，候选原因由学生确认 |
| 信心与表现校准：[Deslauriers 等，2019](https://doi.org/10.1073/pnas.1821936116) | 可选先报信心，再对照独立表现；学习概览分别展示感受与作答证据 | 后续。大学物理研究不能直接保证中学数学同等收益 |
| 关键词法：[Dunlosky 等，2013](https://doi.org/10.1177/1529100612453266)；位置法/记忆宫殿：[系统综述，2025](https://doi.org/10.1111/bjop.12799) | 可选公式条件/术语提示卡；学生自己建立线索 | 辅助。关键词法受材料和长期保持限制；位置法效果估计的证据质量有限。不能替代推导、应用或宣称提升一般理解 |
| 睡眠与休息：[Newbury 等，2021](https://doi.org/10.1037/bul0000348)；番茄钟研究 [Biwer 等，2023](https://doi.org/10.1111/bjep.12593) | 可选学习时段和休息提醒；不用疲劳时长做排名 | 后续。睡眠剥夺研究不是个体作息处方；不宣称固定25分钟是最佳节奏 |
| 摘要、划线、重看 | 用于导航、找条件和回到原讲解，再接实际提取与新题 | 保留辅助用途，不拿摘要阅读量当理解程度 |

不采用“视觉型/听觉型学生必须匹配某种教学”的强制分流；学习风格匹配缺乏足够支持，参见 [Pashler 等](https://doi.org/10.1111/j.1539-6053.2009.01038.x)。粒子、发光、徽章等须通过可用性验证；与学习任务无关的装饰可能干扰学习，参见 [无关趣味细节元分析](https://doi.org/10.1007/s10648-020-09522-4)。

AI 应提供可选择的逐级帮助。高中数学随机研究发现，直接提供生成式答案可能使辅助期间表现与之后无辅助表现脱节；教师设计的受限辅导缓解了该研究中的伤害，但不能据此声称必然提高独立考试成绩。[Bastani 等，2025](https://www.pnas.org/doi/10.1073/pnas.2422633122)。因此用户随时能看解析，但系统准确记录提示/看答案状态，并提供可选无 AI 延迟测验。

另一方面，大学物理课程的随机对照研究发现，按教学原则专门设计的 AI 辅导在其测量条件下提高了学习表现并减少用时。[Kestin 等，2025](https://www.nature.com/articles/s41598-025-97652-6)。两项研究的学生、任务与辅导设计不同；它们支持认真设计和检验帮助方式，不能直接推断本项目对中学数学或长期保持的收益。

## 3. 一条连续的学习流程

1. 观看：主动载入视频；获准材料由学生明确启用持续视觉。显示已分析时间和缺口，未许可素材保留本地预览/手工学习。
2. 发现：有效热点或等价文字列表指出当前对象；点击后核对公式、直角、边长和单位。模型不确定就校对，不猜条件。
3. 预测与观察：学生先选变化方向，再调参数，图形/公式/数值同步；预测错误只是观察，不自动记实际错题。
4. 理解：一句话解释后提供分层说明；需要时可看完整例题、补步骤或写自己的解释，均可跳过。
5. 验证：隐藏解析，独立回答程序判定的新题。用提示、看答案、未提交、独立作答分别记录。
6. 保存：主动保存疑问/个人易错；实际错误由作答证据支持，学生确认或修改原因标签。原数学、来源与答案不可被笔记编辑覆盖。
7. 复练：到期或主动选择时，根据已确认原因选审校过的变式，再交错易混关系。原视频位置、原题、探索与新题清楚区分。
8. 回顾：在同一工作台查看观看记录与学习证据；分别呈现近期独立正确、辅助正确、尚未验证、延后新题表现，不生成未经校准的掌握百分比。

所有环节在主 demo 内可达。学习辅助不能强制暂停网课或要求答题/登录后才继续；摘要可能透露答案的内容在作答区域默认收起。返回视频不自动 seek；只有学生选择“回到这个片段”才定位。

## 4. 先深做两条微课

| 微课 | 现场理解与独立验证 | 错因与延后复练 |
| --- | --- | --- |
| 抛物线水平平移 | 自制 `y=x²` 场景；先预测右移2；确认 `{a:1,h:0,k:0}`，将 h 调到2，观察 `y=(x−2)²` 与 `(2,0)`；解释括号符号；独立题 `y=2(x+3)²−1` 顶点为 `(-3,-1)` | 实际回答错误且学生确认后标记符号/坐标混淆；延后换数值并对照左右移。扩展表征转换题需新增独立 exercise 契约，不改变旧曲线返回类型 |
| 直角三角形与相似缩放 | 明确 `∠A=90°`、AB=3cm、AC=4cm；预测仅 AB 改6，程序算 `BC=√52≈7.211cm`；与两直角边同比扩大对照；独立题 AB=10、AC=12 得 `√244≈15.620cm` | 回答斜边也翻倍不能直接确诊；候选“仅改一边却按相似放大”须确认。变式区分单边变化与整体相似，含非直角反例提示适用条件 |

原题和新题使用不同 ID；学习记录明确是预设、手工、程序变式、AI 候选或用户校正。以既有自制素材建立完整手工基线，再对同批获准材料运行真实视觉，不能先把所有学科铺开。五个新增手工模板保持可用，内容深化在两条微课通过后逐个扩大。

## 5. 开源能力的取舍

仓库目前是 Vanilla JS、原生 SVG 与局部粒子渲染。先复用确定性数学和既有身份服务；没有评测收益时不迁移框架，不引入一整套 LMS。

| 开源项目 | 计划吸收的优点 | 本项目选择与许可边界 |
| --- | --- | --- |
| [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs) / MIT | 基于回忆历史的复习时机、可重放调度 | 隔离试验概念回忆卡。保留现有规则回退；FSRS 的保持率不能当数学掌握率，先冻结评分映射/时间/版本，再决定是否接入 |
| [JSXGraph](https://github.com/jsxgraph/jsxgraph) / MIT 或 LGPL 双许可 | 约束拖点、交点、多对象联动 | 与现有 SVG 做一条微课对照原型；仅收益明确时接入小模块，按 [MIT 文本](https://github.com/jsxgraph/jsxgraph/blob/main/LICENSE.MIT)履行声明 |
| [H5P Interactive Video](https://github.com/h5p/h5p-interactive-video) / MIT | 视频时间点互动、回答反馈和回看片段 | 借鉴交互设计；不是现成的任意网课扩展。复制代码前检查核心、编辑器、依赖和内容的分别许可 |

| [Anki](https://github.com/ankitects/anki) / 主要 AGPL-3.0 等 | 到期队列、逐次复习记录、可解释统计 | 借鉴流程，调度可另用独立 MIT 项目；不默认复制 Anki 整体源码到当前项目 |

## 6. 竞争力与验证方向

以下是官方已公开的功能，截至2026-10-07；官方介绍未确认某功能不代表对方没有该功能，宣传的学习效果不作为独立研究证据。

| 对照产品 | 已确认能力 | 对 BreakGlass 的含义 |
| --- | --- | --- |
| [Khanmigo](https://www.khanmigo.ai/learners)；[Google/Khan Academy 2026-08-27公告](https://blog.google/products-and-platforms/products/education/khan-academy-back-to-school/) | 引导式辅导；新增互动图示，拖动顶点/线段后讲解随之调整；教师可审改练习 | “AI＋互动数学”已经有人做；应验证具体视频场景对应与复练衔接，而非宣称互动独有 |
| [GeoGebra](https://www.geogebra.org/) | 动态函数/几何/3D、学习活动与 Classroom 进度反馈 | 数学交互深度是强项；我们的机会在现场转成可核对的任务、降低操作切换成本 |
| [Glasp](https://glasp.co/youtube-summary) | 视频旁转写/总结、时间戳跳转、基于转写问答、高亮与记录、浏览器扩展 | “插件＋视频摘要＋问答”已有直接同类；视觉数学对应与实际作答闭环需要独立证明 |
| [H5P Interactive Video](https://h5p.org/interactive-video) | 编排视频热点、题目、总结与回答反馈 | 热点本身不独有；未经预先编排的视频能否可靠产生学习任务才是难点 |
| [Anki](https://apps.ankiweb.net/) | 间隔复习、历史统计与同步 | 调度不是独有优势；错因、条件适用、独立迁移须做得比纯记忆卡更合适 |
| [小猿 AI 官方 FAQ](https://xykspt.yuanfudao.com/faq) | 拍照/作业解析、启发式追问、视频讲解与错题相关知识帮助 | 国内已有“AI讲解＋错题”能力；要验证学生是否更省操作、更理解当前讲师内容 |

值得验证的产品组合是：**当前视频位置 → 经校对的数学对象 → 预测/实验/解释 → 独立作答 → 学生确认的错因 → 原片段与延后变式**。本轮官方核对没有证明这一组合独家；组合本身也容易被模仿。

较可能形成积累的是获准课程的准确对应样本、经教师审校的错因与反例、明确的数据来源和失败体验、以及真实无辅助迁移结果。早期优先选择课程作者/教师提供的授权微课合作，小范围试用检验需求；不假设 B 站公开视频天然允许处理。地区差异或中文支持只是待验证条件，不能直接当市场护城河。
