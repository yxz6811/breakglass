## 1. 产品目标与使用场景

BreakGlass 的主要入口是浏览器插件。学生观看支持平台的网课时，视频中的公式、函数图像与几何对象可以出现对应时间、位置的轻量热点。学生点击后获得通俗解析，或打开与当前讲解对应的参数化数学场景，观察、操作、解释变化，再返回原视频继续学习。

网站保留第二种学习方式：用户选择或拖入自己的本地视频，在浏览器中预览、抽取代表帧，确认后提交获准帧/必要文本进行识别，并使用与插件相同的热点、解析和互动场景。插件在支持平台观看时直接使用的体验优先交付；网站首页的导入入口为次级入口。

网站与插件使用同一账号，集中呈现当前账号的观看记录、疑问、个人易错标记、实际错题和复练结果，并恢复原视频位置与已保存的数学场景。未登录时允许本地学习；两入口、账号与网站记录是完整产品目标的一部分，不能用游客缓存或 Mock 登录代替最终交付。

目标覆盖初中和高中数学，先深做二次函数与直角三角形。解释深度由课程和学生选择决定，不把年龄标签当成知识掌握判断。任何新增题型先冻结数学边界、交互语义和真实识别样例。

核心价值假设是：降低学生从“这里没懂”到“能操作、解释并用于新题”的成本。第三方视频原位入口、讲解与数学对象绑定、复习恢复学习现场构成差异化假设；不宣称功能独家或竞争优势已经得到市场验证。

首发目标为中国大陆及海外；海外国家与欧盟具体成员国尚待冻结，不能声称已经全球合规。首版使用自制或明确授权素材，逐地区确认账号年龄/有效监护、素材处理权利、平台条款、供应商/跨境与 AI 标识。未成年人优先访客本地探索，云功能条件不足时明确限制，不能隐式上传或公共同步。

本轮将插件优先的双入口（支持站点网课插件、网站用户视频导入）、分段预处理、时空热点、参数化呈现、受限账号与学习记录纳入产品规划。后续实施须有独立 Spec/Plan/Tasks、版本化契约、真实依赖与验收记录；此前仅交付文档；后续用户已授权按006实现持续视觉首切片，生产服务/账号/部署仍须对应契约与独立验收。

既有 `001`–`005` 及当前帧增强保留自己的来源、请求、状态和数据约束，不由新规划重新解释：

- `CurveResult`、`createWake` 和 `startCached` 保持原契约；几何 `SceneResult` 保持独立。新时间轴和学习记录通过明确适配接入，不向旧结果强塞账号或题型字段。
- 原唤醒 `1500ms` 保底继续有效；003 热缓存点击到覆盖层 `P95 ≤ 100ms`、至少 20 次的验收，以及其 `300s` 预读截止继续独立。
- 003 至多 8 张稀疏帧的旧额度保持；当前帧曲线与 005 识别 `30s`、005 问答 `10s` 为待真实预跑冻结的开发默认，单帧载荷和原 reader 上限不被新批量任务替换。
- 003 的第一处结果定位规则仅属于其既有本地流程。新第三方网课模式禁止后台结果主动拖动或暂停学生播放头。
- 真实模型、热缓存像素计时、四画幅/全屏对齐、MV3 安装及学习效果的历史未验收项继续未验收；新规划不能补写成通过。

首轮不承诺任意网站、所有曲线、任意视频恢复真实三维、整文件云接收、云端代码执行、教师管理平台、社交分享或与学习闭环无关的 SaaS 功能。整文件云上传保留为后续可选独立模式，首版网站导入不依赖它，不能借此修改旧 reader 的上传额度与无状态规则。

## 5. 学生端完整学习流程

### 5.1 插件主入口

1. 打开支持平台的课程，点击插件启用；首次说明站点权限、分析素材和外部模型用途。未支持页面明确提示；不假装已识别。
2. 插件绑定视频身份、源版本和媒体代次，尝试加载当前课程可用的已验证分析。无缓存时学生显式开启分析，优先当前知识片段。
3. 在 `BG-U03` 显示准备、当前片段可用、其余处理中、部分失败或已取消。学生继续正常观看；任务结果不能抢播放头。
4. 校验通过的热点只在有效时间和有效区域出现。多点拥挤时归组或使用侧栏列表，允许关闭；正文、字幕和播放器控件仍可使用。
5. 点击概念点打开 `BG-U04`：一句核心解释、必要条件、来源、易混原因；需要时展开步骤或继续提问。
6. 点击图形点打开 `BG-U05`：保留原帧参照，对识别候选先校对，再操作参数。图形、公式和结果来自同一个确定性数学状态。
7. 学生可以保存“这里没懂”、标记个人易错点，或把实际错误作答/手工选定题目收录到错题本。保存对象类型和同步状态明确可见。
8. 关闭探索回到同一视频位置；是否暂停由显式操作及站点能力决定，不能在后台完成时改变播放状态。
9. 登录后在网站查看当前账号记录，选择继续观看或恢复场景；站点需要重新登录、视频不可访问时保留学习记录并说明原因。
10. 复练先隐藏解析，允许提示、跳过和重答；答案、提示使用及理解反馈分别记录，不凭观看时长判定掌握。

### 5.2 网站导入入口

1. 在 BG-U08 选择次级“导入视频”，打开 BG-U13；说明支持格式/资源限制、素材处理依据和本地文件与云上传的区别。
2. 选择或拖入自制/已获许可视频，浏览器验证并解码预览，生成用户文件身份、内容版本和媒体代次；文件名/标题不能作为唯一身份。
3. 首版原文件留在浏览器，本地抽取稀疏代表帧；显示拟提交的帧/文本、接收方、用途和保存范围，满足地区/监护/跨境条件后显式确认。
4. 确认后只提交获准帧和必要文本，复用 BG-U03 的分段任务/取消与 BG-U04–BG-U07 的解析、校对、场景、标记和保存语义；不另建网站专属数学或错误来源枚举。
5. 文件无法解码、超出资源范围、无可用帧、条件不支持或识别失败时保留可理解原因；允许换文件、重试、停止上传和本地模板探索，不静默改为上传整文件。
6. M3 登录后与插件记录使用同一账号/记录模型，并保留来源类型。重访本地视频须重新选择且校验同一文件身份/版本，避免把另一同名文件绑定到旧热点。
7. 没有原文件时可以恢复已保存的数学结构与个人笔记，视频位置保留为参考；页面不能声称原视频可播放。关闭/换文件/退出清理临时帧、对象 URL 和旧任务。

两入口共用预处理候选、确定性数学、热点时间/区域、解析、场景快照和学习记录的版本化语义；媒体获取与原视频恢复由各自来源适配器负责。

## 6. 预处理与低等待架构

规划管线是“许可的素材获取 → 分段/代表帧 → 结构候选 → 确定性校验 → 版本化分析 → 热点与场景”。AI 负责提取公式、条件、对象类型、位置和解释候选；程序负责数学计算、参数范围、采样、身份和呈现门禁。

权利和数据处理条件满足的素材，学生启用并确认实际用途后，可以在授权范围内自动分段分析，不逐帧重复确认。没有公共复用许可时采用允许的私有分析/缓存，不关闭已有合法依据的分析能力；本地计算、外部上传、结构保存与共享各有独立条件。首轮用自制或明确授权课程验证这一完整流程，再扩展符合条件的平台。

### 6.1 素材获取边界

- 优先可合法访问且用途明确的课程字幕、已许可帧数据或用户提供素材。字幕和识别内容均是不可信输入，不能作为修改系统指令的依据。
- 第三方页面不通过后台 `seek` 同一个活动播放器批量抽帧，不抢占正在观看的视频播放头。独立采样源也必须确认权限、解码能力和资源预算。
- 无法安全获取任意帧时，降级为用户当前暂停帧分析，或从正常播放产生的当前帧渐进采样。明确显示“当前片段分析”，不承诺整课已预处理。
- 跨源画布污染、受保护媒体、站点限制或缺少可用字幕时，提供原因与允许的下一步；不绕过访问限制，也不把示例帧替代当前视频。
- 上传前列明帧数、分辨率、载荷、课程说明及供应商依赖；授权后可分段自动处理，停止上传/取消入口始终可见。已有旧路径继续自己的显式触发规则。
- 网站首版在浏览器中解码用户文件、稀疏抽帧，再提交经说明确认的获准帧/必要文本。“选择文件”不是“将整文件上传云端”；独立采样不能抢占预览中的活动播放头。

### 6.2 降低等待的措施

| 措施 | 目的 | 必须同时控制的条件 |
| --- | --- | --- |
| 当前片段优先、后续渐进就绪 | 缩短第一处可用等待 | 未完成部分不得显示成功；取消保留已合法校验结果 |
| 字幕辅助、画面变化检测、稀疏代表帧 | 减少重复模型调用 | 手写推导和条件变化不能仅按视觉相似去重 |
| 固定数学模板与本地参数重算 | 拖动时无需再次请求模型 | 参数域、单位、条件与解算器必须匹配 |
| 已验证公共分析复用 | 同一视频版本减少重复处理 | 缓存身份、内容版本、分析版本与校验版本一致 |
| 缓存短解析、按需展开 | 快速获得第一层帮助 | 深层解释与当前场景修订号绑定，迟到结果丢弃 |
| 延迟加载并预热场景 renderer | 缩短点击到可操作等待 | 包体、CSP、资源释放、内存预算和低性能降级独立验证 |

时间轴新增字段与批量额度属于待冻结契约，不把旧策略中的 `/preprocess` 等草案端点描述为可用服务。重试应有上限、去重与成本记录；保存、作答和同步应具备幂等语义。

### 6.3 B 站候选试点

B 站进入 M0 候选评估，首轮优先由合作数学 UP 主提供有权授权的原视频/课件，在平台外完成分析，再用插件将热点对应到原站讲解时间。素材、平台接入与商业使用条件分别确认，普通公开视频和付费观看均不自动放行全课采集/AI 上传。具体官方协议依据与三类接入处理见 [风险规划 §3.3](BreakGlass-rights-and-risk-plan-2026-10-06.md)。此处是候选方案，尚未完成真实 B 站安装、对齐或许可验证。

### 6.4 可选后续整文件云模式

如后续确需在服务端接收完整用户视频，作为独立模式冻结：素材处理依据、实际接收方/地区、支持格式/编解码、体积/时长/配额、分片/取消/重试、临时保留及删除期限、恶意媒体扫描/解码隔离、成本上限、供应商用途与失败语义。UI 明确展示“上传完整文件”，不得从帧上传自动切换；不走旧 reader，不默认永久云盘或整课共享。未完成这些契约与真实验收前，首版仍采用浏览器选片和帧/文本提交。

### 6.5 插件素材获取备选方式

以下为 M0 待验证的接入选择，不要求首版同时实现。它们解决素材取得、传输和等待的不同问题，素材/平台条款、儿童和供应商条件仍分别核对；截图、在本机分析或学生主动点击都不自动取得内容处理许可。

| 路线 | 学生体验与分析材料 | 收益与限制 |
| --- | --- | --- |
| 主动分析当前画面/选区 | 点插件 → 捕获当前可见画面 → 本地裁出教学区域 → 提取/校对条件 → 解析与互动 | 先验证单个知识点闭环，减少媒体原文件获取与重复模型调用；不宣称当前一帧能总结全课或可靠识别任意手写题面 |
| 本次观看的渐进辅助 | 学生主动开启当前标签页辅助，在许可范围内按画面变化稀疏取样，已校验部分逐步出现热点 | 接近观看时直接互动的目标；只处理本次获取的时段，未看到的后续内容不冒充提前已分析。任务/显示有持续可见的停止入口 |
| 端侧候选与按需云解析 | 本地 OCR/候选提取及确定性数学先运行；有依据且允许时再提交最少帧/条件获得更深解析 | 减少材料传输和拖动时模型调用；模型下载、设备内存/性能、公式/几何可靠性和无关遥测分别验收。端侧不支持时回校对/输入或允许的云路径，不能假定所有学生设备可运行 |
| 作者知识层/官方合作 | 老师提供有权授权的源素材预处理，或采用实际获准且可用的接口；插件按当前视频版本/时间加载解析与场景 | 提前准备有助于降低点击等待；知识层须对源版本/区域验证，官方 API 是否涵盖课程视频/字幕须实际确认，不能用账号数据接口冒充视频处理接口 |

技术试验优先“主动分析当前画面 + 可校对候选 + 确定性模板”；随后在获准平台/素材上比较当前标签页渐进辅助与作者预处理知识层。首轮保留粒子/SVG互动和个人易错标记，深层解释可渐进加载；不先承诺全课自动识别或固定毫秒耗时。网站本地视频导入作为第二入口，共用上述数学与分析管线。

Chrome 的 [当前页截图](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-captureVisibleTab) 可用 `activeTab` 等相应权限，但捕获的是可见页，须在本机核对/裁剪教学区域，并验证视口、DPR、滚动和媒体时间映射；不能把页面尺寸当源视频尺寸。截图接口存在调用限额，不用于高频逐帧采集。[标签页捕获](https://developer.chrome.com/docs/extensions/reference/api/tabCapture) 需要用户调用扩展及 `tabCapture` 权限；MV3 后台消费流的具体浏览器版本/上下文按 [官方采集说明](https://developer.chrome.com/docs/extensions/how-to/web-platform/screen-capture) 冻结。采集音频可能改变原播放输出，首版优先评估仅画面采样，涉及音频时单独验证声音继续播放和资源释放。

通用 [屏幕共享](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia) 由学生选择标签页/窗口，每次启动需用户激活与浏览器确认，不能静默持久授权。本项目关闭/撤权/换视频时主动停止流和相关队列，不依赖浏览器自动结束。受保护媒体黑屏或无法准确绑定时间/位置时说明不可用、转独立侧栏校对，不尝试解除媒体保护。上述仅为技术候选，尚未完成真实插件权限、捕获或端侧数学识别验收。

## 7. 数学场景与解释体系

### 7.1 模板顺序

| 顺序 | 模板 | 可操作关系 | 支持与验收限制 |
| --- | --- | --- | --- |
| 首轮 | 二次函数 `a(x-h)^2+k` | 开口、宽窄、平移、顶点、指定点读数 | 复用已有计算；禁止 `a=0` 被当抛物线；定义域与参数域有限 |
| 首轮 | 直角三角形 | 一条直角边变化、另一边与直角保持、勾股关系 | 复用 005 校对/解算/原题快照；截图像素不是实际边长 |
| 后续 | 直线、圆、正弦等 | 斜率/截距、圆心/半径、周期/振幅 | 现有本地探索不等于这些类型已获真实视频识别验收 |
| 后续 | 相似关系、标准立体与截面 | 对应比例、旋转观察、许可范围内切割 | 每个类型独立关系和参数契约；不一次承诺全几何 |

二维函数可呈现在三维空间中并旋转观察，但其数学对象仍为平面曲线；界面不得把视角变化说成从视频恢复真实三维。真实立体模板必须具有明确的三维数学定义。

### 7.2 粒子表示与确定性计算

推荐验证“固定版本 Three.js `Points` + 本地数学采样”的表示层；这是新产品架构规划，不是已安装或已验收的扩展依赖。`site/vendor/` 只提供现有展示实现参考，不能自动证明扩展包兼容。

粒子的位置由已确认公式/条件和程序产生；坐标轴、关键点、标签、关系线保持清晰。粒子数量、光晕和动态可调，低性能、减少动效、隐藏标签页或 WebGL 丢失时静态/SVG 降级。每次退出卸载监听、动画与 renderer 资源。

模型不自由生成作为数学事实的点云，不输出可执行脚本，不以自然语言替代解算。客户端与服务端分别验证新结构；缺条件、冲突、非有限值、越界、低可信或不支持时转为校对/不可用。

### 7.3 通俗解释与来源

每个解释包含“当前在讲什么、为什么成立、哪些条件必须保留、常见误解、怎样操作验证”。数值与关系引用当前确定性状态；老师明确讲述、知识推导补充、模型建议和用户修正分别标识。

解释默认简短，允许展开完整步骤、选择基础补充或更深入解释。教师原讲解与生成解析存在冲突时保留可追溯依据，允许学生报告错误；经校正的分析版本必须使受影响缓存和旧场景重新校验。

## 8. 疑问、易错点、错题与复练

| 对象 | 产生条件 | 保存含义 |
| --- | --- | --- |
| 自动易错提示 | 老师明确提醒或知识规则/模型提出建议 | 公共教学提示，须标来源；不说明这个学生实际犯过错误 |
| 疑问 | 学生选择“没懂”或提出问题 | 学生尚待理解的问题；不自动算错题 |
| 个人易错标记 | 学生主动标记，或确认系统的错误类型建议 | 个人需要留意的知识点；可更改或撤销 |
| 个人错题 | 学生实际作答错误，或明确手工收录并标记来源 | 原题、原答案、确认条件和错误原因可复查；不能由模型单方面认定 |

错题详情保留题目/视频来源、时间、已确认条件、原作答、反馈、原因标签及原场景快照。数学题可判定部分由程序或经校验的标准答案评估，开放解释仅给辅助反馈，允许学生确认或修正原因。

复练包含原题重答与明确标为“变式”的新题。使用提示与独立正确分开，间隔随表现调整，不把固定复习天数描述为普遍最优。基础达到条件后才混合容易混淆的题型；新变式也必须通过关系和答案校验。

BG-F07 为可选增强：操作前预测变化、逐层提示、补全关键步骤、用一句话解释为什么、短知识回忆。安排在学生主动打开或知识片段结束时，可跳过，不频繁中断观看，也不将跳过当成错误。

## 9. 账号、数据与同步规划

### 9.1 最小数据模型（建议，尚无新 API）

| 对象 | 最小字段建议 | 保存边界 |

| 同步状态 | 本地操作 ID、账号绑定、记录修订、待同步/已同步/失败、冲突信息 | 本地待同步不写成云端已保存；换账号停止旧队列 |

字段、保留周期、分页、排序、删除、冲突、错误码、鉴权与幂等机制在实施契约中冻结。此表不声称已有数据库或端点。

### 9.2 隔离与恢复规则

- 登录、权限检查和当前账号记录筛选由服务端保证。仅靠前端过滤、隐藏导航或浏览器存储不能证明账号隔离。
- 不自创鉴权协议；采用经过评估的身份方案，凭证处理、失效与退出行为有明确契约。浏览器不持有供应商密钥，不从第三方课程网站读取其登录凭证。
- 游客数据默认只在本地；登录后迁移须明确展示待迁移内容并由用户选择。退出或换账号清空旧账号可见状态、取消请求、冻结旧队列，不上传给新账号。
- 公共缓存仅复用已获许可的公共课程分析；私有/付费/受限视频按访问范围隔离，未经允许不跨账号复用。缓存命中不能绕过原课程访问权限。
- 缓存键包含课程规范身份、源版本、数学类型/分析/校验版本。视频更新、校对修订或解释纠错触发失效/重新验证；旧答案可留历史但不能覆盖当前场景。
- 网络断开时允许本地操作，清楚显示待同步；恢复后按所属账号幂等重试。冲突保留可解释的两份修改或依据已冻结规则合并，不静默丢失作答。
- 视频下架、课程权限失效或链接不可恢复时，网站说明限制；可恢复已保存结构场景与个人笔记，不提供未经授权的视频副本。
- 网站本地文件关闭后不假定仍有文件访问权。学生重新选择文件并校验唯一身份/内容版本后才能恢复对应视频热点；错选同名文件拒绝绑定，缺文件仍可恢复结构场景。两个入口的同名课程不自动合并；明确许可且内容身份匹配后才建立关联。

## 10. 授权、隐私与安全

站点支持清单与权限清单一一对应。优先采用运行时按站点授权和适度权限，不为省适配成本默认索取所有站点权限；活动页脚本与消息验证源和视频代次。

分析材料、用途、是否调用外部供应商与未知保留依赖在启用前说明；提供停止上传、取消任务、关闭本页、撤销站点授权和删除学习数据入口。账号保存范围与旧 reader 的无状态请求分别管理，不能借新账户功能让旧上传开始留帧日志。

只持久化学习闭环需要的结构数据与主动提交内容；日志记录稳定 ID、载荷大小、耗时和结果码，避免图像、字幕全文、凭证、私有地址、完整问答或上游原文。学生相关数据与供应商处理边界在试用前明确。

模型输出/字幕/网页文字都是不可信数据；按类型验证、转义显示，不接收远程代码、HTML 或 shader 执行。扩展依赖固定版本、许可与完整性，MV3 CSP 与本地打包资源独立验证。

用户文件是不可信媒体：首版冻结类型/格式、体积/时长/分辨率、抽帧和浏览器资源限制，不只看文件扩展名；解码失败停止处理并释放资源。只对用户选择的文件使用临时对象 URL，换片/取消/关闭及时作废；不能以选文件动作取得任意目录或永久读取权限。网站导入与插件适用同一素材、地区/儿童/跨境和私有缓存门禁。

| 当前片段/全任务耗时 | 任务接受 → 对应范围完成或明确部分失败 | 分段范围、帧预算、吞吐、并发、取消截止与成本上限 |
| 点击到可操作 | 热点点击 → 首次可见且参数操作生效 | 首次/缓存 renderer、设备、包体、像素呈现与事件口径 |
| 本地互动质量 | 连续参数操作期间采样 | 目标设备、帧率分布、粒子上限、资源上限与 SVG 降级条件 |
| 保存与同步 | 保存动作 → 本地确认 / 服务端确认分别计时 | 离线语义、网络、账号、幂等与失败重试 |
| 网站导入准备 | 选文件 → 可解码预览 / 代表帧准备分别计时 | 文件属性、浏览器/设备、身份指纹成本、抽帧/内存与格式限制；不计为整文件上传耗时 |

新指标的目标秒数、帧数、粒子数、上行体积和成本尚未实测冻结；不能写成现已达标。旧 `1500ms/100ms/300s/30s` 继续按原口径报告。

## 13. 实施文档与对齐完成标准

- [UI 规划](BreakGlass-ui-plan-2026-10-06.md) 提供每个 F 对应的 U、状态、动作、数据与 UI 验收；遗漏的错误/降级/同步状态应在实施前补齐。
- [风险规划](BreakGlass-rights-and-risk-plan-2026-10-06.md) 提供 BG-R01–R11 的触发、影响、方案、UI 阻断/降级、责任与地区发布门槛；与 BG-A09/UI-A21–A24 一起验证。公开 URL、教育用途和学生观看权限不自动授权运营方云上传、持久化或共享。
- 新切片独立建立 Spec/Plan/Tasks 与契约，再按 UI 矩阵逐项实现。旧 `001`–`005` 只补准确引用和兼容边界，不改写历史完成记录。
- 支持站点、预处理资源、数学模板和账户数据依赖有明确状态：待确认、Mock、已接通、未验收或已验收。主入口不能保留假成功和无行为按钮。
