# 从 OpenMAIC 可以学什么

- 记录日期：2026-10-02。
- 对照对象：[THU-MAIC/OpenMAIC](https://github.com/THU-MAIC/OpenMAIC)（清华大学 THU-MAIC，Open Multi-Agent Interactive Classroom）。
- 本文地位：学习笔记。它不修改 [`BreakGlass-constitution.md`](./BreakGlass-constitution.md)，不扩大 P0 验收范围，也不把其中任何能力写成已实现功能。
- 资料状态：依据 2026-10-02 可公开访问的仓库说明、更新日志和讨论记录。上游文档之后可能变化。

## 1. 结论

值得学的是 OpenMAIC 把“观看”做成“动手调节”的交互结构，以及覆盖层生命周期、结构化编辑和离线资源这几件工程做法。

不值得搬的是它的产品形态：多智能体课堂、一键生成整门课、语音、测验判分、Next.js 服务和数据库。BreakGlass 仍然是 Chrome MV3 扩展里的单场景抛物线原位交互。

2026-10-02 另有一项书面决定，记在 Spec Constitution 1.6.0 原则 VII，不由本笔记批准：片子可播放时稀疏阅读整段，第一处通过就停在那一帧，破壁只取已存结果。这只借用「先读材料，再给出可检查的条目」。它不把本笔记第 4 节排除的整门课、语音和直接生成页面放进交付。该切片当时尚未实现，热缓存 20 次和 2% 对齐也还没有记录。

## 2. 两边各自在做什么

OpenMAIC 把主题或文档变成一场互动课堂。公开说明里的主路径是两段生成：先出课堂大纲，再把每个条目做成幻灯片、测验、HTML 交互模拟或项目制学习。课堂上有 AI 教师和 AI 同学，可以语音讲解、在白板上画图，并和用户讨论。工程上它是 Next.js 应用，大模型来自云端或本地兼容接口，持久化可以留在浏览器，也可以选用 PostgreSQL。当前仓库协议是 MIT。

BreakGlass 的 P0 是另一件事：在已验证的抛物线视频上，于暂停帧挂一层原生 SVG，让用户拖动预先准备好的曲线、重置并退出。结果必须标明来源。真实视觉识别和 Pyodide 属于独立 P1。扩展不建业务后端，也不加载远程可执行代码。

两边重合的学习判断只有一条：改参数并立刻看见形状变化，比只看一条固定曲线更能建立直觉。OpenMAIC 在 [讨论 #423](https://github.com/THU-MAIC/OpenMAIC/discussions/423) 里把这件事写成深度交互，并在 2026-04-20 的 v0.2.0 里落地为可调参数的模拟场景。BreakGlass 的拖拽控制点已经站在同一判断上，范围锁在一条抛物线。

## 3. 值得学的内容

### 3.1 交互层只接收结构化动作

OpenMAIC 的模拟场景跑在隔离 iframe 里。教师侧动作通过固定的 `postMessage` 约定完成：高亮某个元素、把控件设到指定状态、按步骤带学生看界面。监听协议写进每种场景的生成约束，而不是临时拼一段脚本。2026-07-21 的 v0.3.1 里，“Edit with AI”进一步改成校验过的 JSON Patch，用来修改已有幻灯片元素。

这对 BreakGlass 的对应物是已经存在的 `CurveResult`：进入绘图前必须通过固定结构、有限数值、视频标识、时间和 `requestId` 检查。以后如果接入视觉识别或模型候选，改动应落成对这条契约的白名单补丁，例如开口系数、顶点和平移，而不是另生成一块 HTML 或 SVG 字符串。

v0.2.0 同时去掉了更早的“先建科学模型，再生成页面”校验，改成只靠分类型提示词。讨论 #423 的维护者说明里写了：他们当时认为提示词足够，没有再加独立校验层。这一步不能学。Constitution 要求候选结果先过确定性门禁，才能进入绘图或执行层。

### 3.2 同一帧上的讲解可以是一串预制动作

OpenMAIC 的白板是 SVG 动作，而不是一张画完的静态图。公开说明里的动作包括描线、文字、图形、图表、聚光灯和激光笔。v0.3.1 还把播放导航做到动作一级：讲解按动作推进，不只靠一条时间轴。

抛物线演示可以借用这个粒度，但动作来源保持为本地预制 JSON。例如在目标帧上依次点出顶点、画出对称轴，再把开口系数从初始值收到另一个允许值，参数数字和曲线一起变。这些动作仍然标明“预先准备的示例”，不引入 AI 教师、语音或网络请求。它服务的是现在这条演示，不是新的课程生成器。

### 3.3 覆盖层要有稳定宿主，清理不能误伤新的一层

交互场景后来暴露出和原位覆盖层同类的问题，记录在保持 iframe 存活的修复里（`#619` / `#629`）：

- 交互层如果挂在会反复卸载的子树里，一切场景或模式切换都会让浏览器丢掉文档并重跑。
- 他们把 iframe 放到舞台根上的稳定宿主，按场景编号复用；内容哈希不变就不重建。
- 隐藏使用 `visibility`。`display: none` 会让层被拆掉。
- 进入全屏时，覆盖层必须跟着全屏元素走，否则会看不见；重新挂载则可能重载一次。这个取舍被明确写进了修复说明。
- 每次挂载带有所有权令牌。过期的清理回调只有在自己仍是所有者时才能隐藏层，避免关掉后打开的那一层。

BreakGlass 的 SVG 叠在 `<video>` 上方，已经用 `requestId` 丢掉过期结果。还可以对照检查三件事：覆盖层的宿主是否独立于会重绘的控件树；全屏、窗口缩放和设备像素比变化后是否按 Constitution 第 7 节重算内容区域；快速连点唤醒或退出时，旧的清理是否可能拆掉新打开的层。

### 3.4 离线播放不能依赖当时能访问的外链

OpenMAIC 导出课堂或资源包时，会把交互场景引用的 KaTeX、Three.js、字体和图片内联进 HTML。导出时抓不到的资源会留下记录，而不是假装已经离线。早于该能力导出的课堂仍指向公网 CDN，必须重新导出。

BreakGlass 的 P0 已经没有运行时依赖，演示不访问公网脚本。若 P1 引入 Pyodide 或绘图库，应沿用同一原则：锁定版本、随扩展打包、做完整性校验，并单独记录加载耗时。未打包的 CDN 地址不能算离线演示。

### 3.5 一种交互只服务一个概念

v0.2.0 把交互拆成五种类型，每种有自己的生成约束，而不再用一条通用 HTML 提示词覆盖所有科目：

| 类型 | 他们用来做什么 |
| --- | --- |
| `simulation` | 物理或化学过程，参数可调 |
| `visualization3d` | 分子、解剖、天体等三维结构 |
| `game` | 带挑战的练习 |
| `code` | 浏览器内写代码并运行 |
| `diagram` | 流程图、思维导图、层级 |

对当前 P0 有用的只有 `simulation` 的约束方式：一个场景只讲一个关系，参数有界，拖动后立刻重绘，界面上能看见当前数值。三维、游戏、通用编程和思维导图都不进入这条抛物线交付。

### 3.6 生成之前先有可检查的结构

经典流水线是先大纲、后场景。用户可以在生成前改大纲。专业模式里，幻灯片元素也可以直接拖拽、缩放和撤销，而不是每次都整页重生成。

BreakGlass 没有课程大纲。可迁移的习惯是：预制结果、目标时间和几何区域先作为可检查的 JSON 存在，交互层只渲染通过校验的那一份。缺字段、对不上当前帧或数值非法时，界面进入可恢复的失败，不把残缺结果画上去。这一点规格和 Constitution 里已经要求，这里只是用外部项目再确认一次。

## 4. 明确不采纳的内容

下列能力停留在 OpenMAIC 自己的产品里。把它们写进 BreakGlass 会越过前端边界，或把 P0 从一条抛物线拉成通用课堂。

| 内容 | 不采纳的原因 |
| --- | --- |
| 多智能体教师、同学、圆桌讨论、自由问答 | 需要持续的模型编排，不是原位曲线演示 |
| 一键生成大纲、幻灯片、测验和 PBL | 会引入课程生成服务，超出当前交付 |
| 语音合成、语音识别、音色克隆 | 依赖外部或本地语音服务，与抛物线验收无关 |
| 大模型直接生成 HTML 并放进 iframe | MV3 禁止加载远程可执行代码；也绕过 `CurveResult` 门禁 |
| 去掉科学模型校验、只相信提示词 | 与确定性结果门禁冲突 |
| Next.js 服务、PostgreSQL、访问码、账号 | Constitution 禁止新增业务后端、数据库和账号体系 |
| OpenClaw、飞书、Slack、Telegram 入口 | 与扩展内演示页无关 |
| 3D、游戏、通用在线编程、思维导图 | 不服务单场景抛物线 |
| 可编辑 PPTX、整课 MP4 导出 | 当前交付物是扩展内可重复演示，不是课件文件 |

## 5. 若以后要落地，最小的一步是什么

优先考虑给现有预制抛物线增加一组本地讲解动作：顶点聚光、对称轴、开口系数的分步变化。动作写在预制 JSON 中，仍经 `CurveResult` 校验，界面继续标明预先准备的示例。

这一步做之前，应先改规格和任务，确认它没有抬高 P0 门槛，也没有把预制动作说成识别或 AI 讲解。覆盖层全屏与过期清理可以作为同一轮的对照检查，不单独立项成新平台。

Pyodide、真实识别和其他场景类型继续保持 P1 或范围外，不因为本笔记而开工。
