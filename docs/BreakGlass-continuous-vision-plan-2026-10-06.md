## 1. 主流程与“实时”的准确含义

学生开启本次视觉学习 → 检查来源/采集方式/实际处理范围 → 检测画面变化 → 抽取当前有效画面 → 视觉模型产生候选 → Schema 和确定性数学校验 → 在对应帧显示候选热点与解析 → 学生核对条件后互动 → 后台归纳已分析的画面 → 学生主动保存疑问或个人易错点。

“持续识别”是会话开启后的持续观察和按需推理，不是把每秒 30/60 帧全部上传，也不承诺模型逐帧返回。首版采用变化触发与有界间隔，上一帧分析未结束时不排队发送旧帧；每次重新采最新画面。识别和摘要各最多一个请求，摘要不阻塞当前画面的识别。模型生成时间、传输和渲染分开测量，不能用短动画或 SVG 速度代替 AI 延迟。

“后台总结”是学生继续观看时，对**已经合法取得且校验通过的视觉观察**做异步归纳。首版不自动获取视频文件、隐藏标签页画面、音频或全课字幕；没有这些输入就不能声称看懂了老师全部讲解或总结了整段课程。后台任务不主动 pause/seek 原播放器；只有学生点击热点进入实验才可暂停并保留返回位置。

## 2. 数据与工程流程

1. 来源登记：`sourceKind / sourceId / videoVersion / analysisVersion` 和当前会话 ID；材料及平台权利来自实际依据，页面声明、公开视频、浏览器权限和单个勾选框均不能代替它。首个可重复试验使用固定受控教学站和仓库自制素材。
2. 获取画面：优先已获准且可读的 HTML video 当前画面；跨域 taint、嵌入播放器、原生全屏或保护画面需要独立验证。可替换为用户显式开启的标签页截图/选区或屏幕共享，须准确标明具体采集方式。没有可靠媒体时间或坐标就使用独立侧栏，不伪造贴合位置。首切片不绕过这些限制。
3. 端侧预筛：尺寸上限、画面变化检测、重复帧跳过、稳定窗口、可见性检查和单请求背压。开发默认最短识别间隔 1500ms；它仅是请求频率下限，既不是生成时间保证，也不替换旧 P0 的 1500ms 保底。先小样本测召回与漏点，再冻结参数。
4. 模型候选：独立 `/learning/read` 单帧接口，仅支持登记的抛物线/直角三角形。没有明确条件返回不支持或待校对；不从图像比例猜边长。不执行模型输出，不让模型提供的数值答案代替程序计算。原始帧仅在本次请求中使用，不落数据库/日志/笔记。
5. 时间绑定：请求 ID、会话代次、视频版本、帧时间、播放状态和区域映射一起核对。跳转/换源/退出使在途请求失效；播放继续造成旧帧时，结果保留为“第 X 秒的候选”，不把旧位置贴到当前帧。点击历史点后是否跳转由学生决定。
6. 数学确认：持续显示 AI 候选、人工校正和程序计算的不同来源；确认当前题意后才开放数学实验。函数仍表达二维关系；粒子/三维展示是后续 renderer，不能把平面函数解释成三维曲面。
7. 后台归纳：独立 `/learning/summarize` 接收最多 20 条短结构观察，不再次上传画面/整课转写。按新增有效观察触发，重复内容合并；首条有效观察可给局部摘要；后续新增 3 条语义观察再更新，待实测调整。输入保留观察时间，输出只总结该输入窗口；摘要窗口与整段课程覆盖状态分别显示。
8. 保存与退出：分析/总结默认会话内私有、内存有界；只有学生明确保存才进入本机疑问或个人易错记录。实际答错只能来自学生题目作答证据。停止、页面隐藏、换视频、失权、删除和服务失败清理对应任务/队列并拒绝迟到结果。网站文件入口后续复用这一管线；真实账号同步独立实现。

## 6. 视觉模型与视频读取的组合增强方案

该方案回应用户“视觉模型加读取视频的组合”的讨论，尚未冻结启用音频/字幕/整文件的新实现。推荐以实时局部响应与后台上下文两路协作，复用F02/F04/F07及U03/U04/U06；保持插件优先，网站本地文件作为合法完整素材入口。

| 流程 | 输入与用途 | 关键限制 |
| --- | --- | --- |
| 实时视觉路径 | 当前可见获准画面，识别数学对象/条件/位置，生成候选热点和局部解析 | 最新帧、单在途、条件校对；不等待整课预处理 |
| 后台视频理解路径 | 获准取得的视频片段、音轨转写或字幕，梳理讲解/推导和上下文 | 分段处理、窗口/覆盖可追溯；仅有画面时继续显示无音频缺口 |
| 时间轴融合 | 同一sourceId/videoVersion上的图像、语音/文本时间戳与经核对数学对象 | 区分播放器媒体时间/采集墙钟/字幕偏移；不能按标题合并不同版本 |

视频读取并不是与视觉模型互斥的另一种智能；解码/抽帧/转写负责取得输入，模型负责理解。例如部分视频模型支持文件输入、时间戳问答和总结，但文件需要上传与处理，无法据此承诺比稀疏抽帧更快；是否支持具体网址/编码/音频及输入尺寸须逐供应商实际验证。[官方视频理解说明](https://ai.google.dev/gemini-api/docs/video-understanding)

- 音画不同步：统一媒体时间/版本，按实际字幕偏移和倍速校验；时间不可靠只提供侧栏上下文。验收口头改条件、字幕延迟、跳转和不同剪辑版本（BG-VR03/04）。
- 数学语音误识别：保留“-号/指数/根号/角名/单位”的不确定性，与图像和程序约束交叉核对；冲突要求学生确认，不让音轨覆盖明确题面（BG-VR02/05）。
- 重复调用与等待：分段识别一次复用结构，实时路径优先，后台有界并发与额度；已有有效上下文可辅助但不代替当前画面。整文件不成为开始学习的前置条件（BG-VR01/06/07）。
- 权利/隐私扩大：音频有教师/学生声音、整课内容与新增供应商处理范围；采集、转写、上传、存储/共享分别判断。B站可播放的链接不等于插件可下载或模型能直接读取；未确认时不启用对应路径（BG-VR09/10）。
- 覆盖与误归因：AI归纳/教师原话/字幕/程序计算分别标记，能回溯所用片段；没有音轨或未处理整段不写“全课讲解完整总结”（BG-VR04/06/12）。

浏览器工程依据：activeTab仅为显式调用后的临时技术访问，不是内容许可；MV3 worker通常存在闲置/请求限制，不能把后台任务理解为永久运行；canvas读跨域污染画面会报SecurityError。相关问题需真实设备验证。[Chrome activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)、[worker生命周期](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)、[Canvas画面导出](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/toDataURL)
