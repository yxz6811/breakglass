| 产品功能 / UI | 本轮真实操作 | 状态与验收 |

## 问题与已落实措施

| 风险 / 触发 | 解决方式 / 剩余边界 |
| --- | --- |
| 插件跨站cookie无法或不宜直接复用 | 显式一次码换records/watch最小scope令牌，token仅worker storage.session；服务内存hash绑定父网站会话和extension origin。新增host仅127.0.0.1:4174 |
| 断网时显示同步成功、反复重发 | 本机持久先完成；single lane/10秒中止、100条队列、失败位retryRequired；账号确认前显示未确认；显式retry先/me校验owner与epoch |
| 换号/退出/撤销/删除后旧记录复活 | 令牌与父会话/账号/epoch绑定，后端提交前重验；服务重启失效；本机队列遇401/403/409清理，不自动刷新epoch重放 |
| AI失败使观看记录也失效 | 独立watch-begin/token与最小watch元数据，须显式学习层、配对同步和实际播放；不依赖read成功 |
| 单帧缺上下文，逐帧处理太慢或贵 | 选择≤30秒短窗4帧，最多8帧；登记作者字幕补语义；与实时read共享背压槽，上游30秒、网站25秒全流程；≤4次context/session，仍需真实供应商测量 |
| 字幕和视频不匹配或模型误以为听过讲解 | 只服务端登记字幕SHA，按来源/时间选cue，不接受外部任意cue/URL；覆盖由程序生成。字幕空隙只显示frames；明确作者文本、稀疏覆盖、无音轨 |
| 取消后seek/CSS迟到重新打开候选 | request/decoder AbortSignal与generation guard；来源/账号/可见性检查；停止清除总结/候选，取消销毁prepared overlay；destroy移除监听及隐藏视频资源 |
| 模型猜数学条件或生成任意代码 | 严格已有两模板schema/时间白名单/有限参数/候选校对；执行与答案由数学程序，模板之外明确不可用 |
| 花哨动画替代理解，提前暴露答案 | SVG始终保留；粒子只观察同平面数学。复练图不提前标出BC计算值；先预测、渐进提示、实际作答与独立变式证据，真实学习效果仍待学生实验 |
| 变式覆盖原错题、解释笔记误算掌握 | 独立record id/manual来源及原id追溯；旧条件不变，提示使用与独立正确分开；自我解释主动保存为疑问，未评分不生成attempt |
| 登记ID被误当公众服务媒体许可证明 | 本机gateway校验登记ID与结构，浏览器诚实流程校验完整文件SHA；不能证明恶意远程客户端提交JPEG的来源。公众上线前必须另验服务端素材核验或可信采集凭据、真实授权与撤权链，当前不开放公网 |

版权/儿童数据/监护/跨境/地区发布继续按[风险方案](BreakGlass-rights-and-risk-plan-2026-10-06.md)及原则XII；本轮只落实受控开发路径，不作法律许可或全球覆盖结论。B站公开视频处理许可仍待确认，不采集上传。
