## 1. 首版可实施边界

AI 视频分析保留为核心能力。素材权利、平台和数据流条件满足后，学生开启学习层即可按已告知范围自动分段处理课程文本/代表帧，识别数学对象、生成解析并显示经校验的热点，无需逐帧授权。分析、外部上传、结果保存与共享分开判定；共享未获许可时不共享，已有合法依据的私有分析仍可使用。许可条款只需覆盖实际启用用途；法定例外的适用另作具体判断，不假定所有课程都必须取得同一种合同。

保留插件与网站导入两入口，插件优先。网站 BG-F12/BG-U13 首版选择/拖入本地文件、浏览器解码预览与稀疏抽帧，说明确认后提交获准帧/必要文本。选文件不等于整文件云上传；两入口共用处理/数学/记录语义和地区、儿童、跨境、版权门禁，用户勾选不能替代实际处理依据。

- 首轮试验优先使用自制课程或明确书面授权素材；确认视频、课件、题目、配图、字幕、教师肖像/声音及所用第三方素材的权利链。
- 第三方网课仅在逐平台确认技术获取方式、平台条款及素材处理权利后接入。能观看、付过课程费用、存在公开视频 URL 或学生点击同意，均不自动证明运营方可以上传、存储或共享分析。
- 不抓取全课媒体，不绕过 DRM、登录、付费、地域、广告或其他访问控制，不复制站点登录凭证，不替学生获取无权访问内容。
- 默认保存视频引用、秒级位置、数学结构、学生主动提交的笔记/答案和原创解释；不默认保存教师原题完整截图、长字幕、原视频或可还原全课的内容集合。
- 未成年人优先使用访客本地探索；符合当地条件的儿童云账户须有有效监护流程。默认不公开、不跨账号共享个人学习数据，不以一个年龄勾选框完成全部合规。
- 某地区或材料未确认时，停用受影响的云处理/持久化/共享，清楚显示限制；仍可使用自制模板与本地手工条件探索。降级不是第三方材料已获使用许可的结论。

## 2. 已核对法源与适用判断

本节概括官方文本；后文的保守默认、权限设计与功能限制是本项目拟采用的产品措施，不是法律规定必然要求同一种实现。

### 2.1 中国大陆

《著作权法》保护作品的具体表达，并规定复制、信息网络传播等权利。第 24 条的个人学习、适当引用和学校教学/科研等例外各有条件；教学例外并不自动覆盖面向公众的商业插件、批量云处理或共享资料库。是否适用须结合用途、数量、表达复制、正常使用和权利人利益判断；首版不依赖宽泛的“教育用途”判断获取许可。[国家版权局现行《著作权法》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)

《个人信息保护法》第 28 条将不满 14 周岁未成年人的个人信息列为敏感个人信息，第 31 条要求取得父母或其他监护人同意，并制定专门处理规则。账号身份、观看/作答/疑问记录等需按实际可识别性评估；不能因为内容是数学就认为不是个人信息。[《个人信息保护法》第 28–31 条](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)

个人信息向境外提供需核对法定机制、告知、单独同意及影响评估等适用要求；不能仅凭用户点击“同意 AI”完成。2024 年跨境规定包含特定豁免/数量条件，是否适用取决于真实数据、规模和主体，应与 PIPL 一起判断。[PIPL 第 38–39、55 条](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)、[网信办跨境规定官方说明](https://www.cac.gov.cn/2024-03/22/c_1712776611649184.htm)

2023 年《生成式人工智能服务管理暂行办法》适用于利用生成式 AI 向境内公众提供生成内容的服务；不向境内公众提供此类服务的研发/应用有其范围排除。不能因项目用于教育或仅调用第三方 API 就认定排除，也不能认定所有插件都一律需要同一种备案/许可；具体属性、服务角色和手续在上线前核对。[网信办正式文本第 2、17、22–23 条](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)

2025 年《人工智能生成合成内容标识办法》自 2025-09-01 施行，按其第 2 条及相关规定情形适用；包括显式/隐式标识、导出和传播等要求。一个“AI 辅助”胶囊不当然完成全部适用标识义务，须核对生成文本、图像/虚拟场景、文件及本项目角色。[网信办正式文本](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)

### 2.2 美国示例

美国 fair use 综合衡量用途/性质（包括商业或非营利教育）、原作品性质、使用数量与实质性、对潜在市场/价值的影响。教育用途不保证成立，商业用途也不是自动失败；不能把“改成 AI 解析”直接当成 fair use。本项目具体输入、输出、缓存和收费安排需逐项评估。[美国版权局四因素说明](https://www.copyright.gov/fair-use/)

COPPA 对面向 13 岁以下儿童并处理个人信息的商业在线服务，以及其他有实际知情的相关服务等适用。2025 年规则修订的一般合规期限为 2026-04-22；截至本次规划该日期已过。须按现行规则核对可验证家长同意、用途、第三方披露、保留与安全，不能沿用过期方案或仅以“13 岁以上”勾选绕过。[FTC COPPA 指引](https://www.ftc.gov/business-guidance/resources/complying-coppa-frequently-asked-questions)、[2025 正式规则及期限](https://www.govinfo.gov/content/pkg/FR-2025-04-22/html/2025-05904.htm)

### 2.3 欧盟示例

GDPR 下处理个人信息须确定合法基础、目的与最小化等条件；第 8 条涉及基于同意直接向儿童提供信息社会服务的特定场景，默认年龄为 16，成员国可降低至不低于 13。并非所有处理都统一适用“16 岁”或统一靠家长同意解决，需按成员国、场景和基础判断。[EDPB 合法处理与儿童说明](https://www.edpb.europa.eu/sme/be-compliant/process-personal-data-lawfully_en)

向 EEA 外转移个人信息还需核对 GDPR 第五章机制；地区服务器选择之外，境外模型调用、远程支持和分处理者访问也要进入数据流清单。[EDPB 国际数据转移指引](https://www.edpb.europa.eu/sme/be-compliant/international-data-transfers_en)

欧盟 AI Act 对相应系统/角色有透明度要求。按 2026-10-06 查到的欧委会现行说明，透明度义务从 2026-08-02 适用；此前上市系统的 Article 50(2) 标记/检测义务有特定过渡至 2026-12-02。上线日期、系统角色与具体条款仍须重新核对，不能将所有输出标识义务统一推迟。[欧委会实施日期说明](https://ai-act-service-desk.ec.europa.eu/en/ai-act/faq/when-does-enforcement-start)、[Article 50 官方文本](https://ai-act-service-desk.ec.europa.eu/en/ai-act/article-50)

若将来扩展为招生、考试评分、决定学习层级等用途，应重新评估教育相关高风险条款。当前自主探索辅导不能简单等同于所有教育高风险系统，也不能据此永久排除。[AI Act 附件 III 教育分类](https://ai-act-service-desk.ec.europa.eu/en/ai-act/annex-3)、[欧委会教育用途示例](https://ai-act-service-desk.ec.europa.eu/en/education-and-vocational-training)

## 3. 素材授权登记与处理流程

### 3.1 最小授权登记

| 字段 | 内容与限制 |
| --- | --- |
| 素材身份 | 来源类型（平台视频/用户文件）、唯一源 ID/内容版本、许可引用；平台链接去令牌，文件名不能作为身份或权利证明，不保存绝对本地路径 |
| 权利方与授权依据 | 权利方、授权代理关系、合同/许可引用、登记审核人；原件受限保存 |
| 涵盖内容 | 视频、字幕、课件、原题、图像、肖像/声音分别确认；不默认全部涵盖 |
| 许可用途 | 网页显示、抽帧、字幕提取、AI 供应商处理、结构保存、派生解释、缓存复用分别记录 |
| 范围 | 地区、有效期、用户/课程访问范围、商业使用、可否公开/跨账号、数量/保留限制 |
| 第三方处理 | 许可的供应商/分处理者、地区、是否允许保留/训练/人工审查 |
| 署名与撤销 | 作者/课程标识要求、撤回/过期联系人、投诉与删除流程 |
| 状态 | 待核对、允许的具体用途、受限、过期、撤销；未知不能默认允许 |

不要把学员的“我有观看权限”声明替代平台/权利人对运营方处理的许可；用户自行上传也仍需告知范围、限制和权利投诉机制。

### 3.2 每次处理的门禁

1. 查地区开关、首站点适配状态、材料身份和许可范围；未知来源进入待确认，不进入共享分析。
2. 展示本次材料、用途、上传对象和保存范围，分别取得适用的用户/监护许可；不把登录与不必要上传绑定。
3. 确定允许处理模式：本地手工模板、许可当前帧、许可分段素材、许可共享派生分析；不是一项总开关。
4. 服务端再次校验许可、账号/课程访问范围、地区与任务代次；前端按钮禁用不等于后端已阻断。
5. 限帧/限量提交、去重、取消和记录稳定审计事件；不记录原帧、长字幕、密钥或私有地址。
6. 保存允许的结构与原创解释；授权过期/撤销、源版本或校对变更时使相关派生分析和共享缓存失效。

### 3.3 B 站候选接入路径

用户询问 B 站视频适用性，现将 B 站列为 M0 候选，尚未完成平台许可或播放器适配。2026-10-06 核对的 [B 站用户协议](https://www.bilibili.com/blackboard/protocal/licence.html) 标注更新于 2025-04-30、生效于 2025-05-07；第 5.6(3) 条限制未经事先明确书面许可通过自动程序获取平台服务、内容或数据，第 1.2 条另有限制商业使用的约定。插件抽帧、字幕获取、页面交互等具体方式须据此核对，不能把公开视频或 UP 主内容授权等同平台采集许可，也不据此直接断言所有学习插件一律违法。

首轮优先与数学 UP 主合作，由有权授权的提供方直接给出原视频/课件供预处理。学生仍在 B 站观看，插件根据已获许可的分析对应讲解时间显示热点；这减少从平台采集媒体的依赖，页面时间读取、覆盖层挂载和商业发布的具体平台条件仍需冻结。UP 主授权还须核对第三方题目/图片等权利链，广告推广的授权功能不自动构成本项目 AI 处理许可。

| 情况 | 首轮处理方式 |
| --- | --- |
| 自有或合作 UP 主的合法源素材 | 按许可范围进行 AI 预处理、校验、私有/获准共享分析；B 站页面接入独立核验 |
| 普通公开视频，未确认处理依据 | 不默认全课自动采集或上传；可用允许的本地模板/笔记；单帧或个人学习例外按具体用途评估，手动操作不自动取得许可 |
| 付费、访问受限或独占课程 | 核对课程及平台实际许可，不以购买/登录替代分析许可，不绕过访问控制 |

### 3.4 网站用户视频导入与可选整文件模式

网站支持自制或有处理依据的许可素材；盗录付费课、受限制下载的本地副本或“我有这个文件”不自动证明 AI 上传、保存与共享依据。提示用途与权利声明、处理范围限制、投诉下架和实际验证共同工作，不用一个免责勾选框代替平台及运营责任。

首版原文件不离开浏览器；只有明确告知并确认的必要帧/文本发给真实接收方。浏览器校验格式/解码与资源预算，取消/换片使旧代次作废并清理临时帧/对象 URL；本地输入同样按不可信媒体处理。两个入口共用地区和供应商处理规则，不能把“网站上传”作为绕过儿童/跨境条件的通道。

整文件云上传是后续可选独立模式。必须先冻结素材依据、实际接收方/地区、格式/编解码、体积/时长/配额、临时保留/删除与失败期限、扫描及受限解码隔离、分片/取消/重试和成本预算；UI 明示完整文件上传，不走旧 reader、不默认永久云盘/全课共享，首版不依赖它。

观看/错题恢复保留来源类型、唯一 ID/内容版本；本地片须重新选择并校验，不能用同名文件重绑。删除学习记录、删除派生缓存、清理临时媒体与删除用户设备原文件是不同操作；本产品不删除用户设备原文件。无原片时仍可恢复获准保存的结构场景与个人笔记，并明确视频不可用。

本入口复用 BG-R01/03/04/05/06/09/10，使用 BG-A10 与 UI-A25–A27 验证正常/异常/取消、来源隔离、真实上传范围、两入口记录/恢复/删除；扩展演示页本地选片和静态介绍站不能代替该验收。

### 3.5 插件捕获与端侧分析的条件

插件可按产品规划 §6.5 评估用户主动当前画面/选区、开启本次标签页辅助、端侧候选和作者知识层/官方接入。浏览器截图/共享授权仅用于技术访问，仍按真实来源、用途和平台规则判断处理依据。原材料在本机或只向云端发送结构条件可减少传输范围，不能直接据此保证版权、匿名化或全地区豁免。

捕获页面先在本机裁剪无关个人信息，区域和时间不可靠则不显示原位点；受保护内容黑屏提示不支持。停止共享、撤权或源更换应结束流、请求与队列，音频路径须验证不影响原课声音。端侧模型首次下载、遥测、内存/耗电、候选准确性和服务地区需要实际记录，不将“本地模式”当作天然无传输承诺；无声称固定耗时或任意题面准确的宣传。

这些措施复用 BG-R01/R02/R03/R05/R06/R09/R10 及 UI-A01/05/07/08/19/21。M0 冻结具体接入方式，M1 用合法素材验证插件闭环，M2 按已验证方式扩展渐进处理；未确定平台条件的路径不自动向全体用户开放。

## 4. 风险与具体应对

### BG-R01 版权与原内容复制

| 项 | 规划 |
| --- | --- |
| 触发 / 影响 | 两入口抽帧、抄长字幕、保存原题/课件；用户导入未获处理依据的文件、输出近似完整讲解或公开题库；可能涉及复制/传播/改编与课程市场替代，导致下架、索赔或合作中断 |
| 具体方案 | 自制/书面授权起步；权利登记按用途拆分；个人记录默认结构/位置/原创笔记，引用最小化并保留必要来源；过度复现输出不进入公共缓存 |
| UI / 阻断降级 | F11/F12 / U01/U13 标来源与许可范围，U04 显示教师来源和生成解析，U07 明示保存对象；授权未知禁止云上传/共享，提供独立本地模板 |
| 责任 / 验收 | 产品/版权负责人核验来源，内容负责人审查复现程度，工程落实许可门禁；BG-A02/A04/A06 检查未授权、过期、重复截图与输出保存 |

数学概念、事实、方法与教师具体文字、题目编排、图片/视频表达要区分。独立绘制公式关系和原创解释仍要检查是否复用了受保护表达，不可宣称“AI 改写后无版权问题”。美国版权局也区分思想/方法与其具体表达；其他地区按当地法律审查。[美国版权局说明](https://www.copyright.gov/circs/circ33.pdf)

## 5. 下架、撤销与数据删除流程

1. 在 U04/U12 及网站支持入口提供版权/隐私/解析错误投诉；公开处理流程和实际可履行的响应时限，避免收集无关证明。
2. 对可定位的涉嫌未授权内容先停止新增处理/共享并标为待核对；保留最少的许可与事件记录，不用保存原媒体作为通用审计方案。
3. 版权负责人核对材料和权利范围；误报、许可有效或需下架的结论有依据与版本，不由模型自动裁决。
4. 撤销/过期时取消相关在途任务、重试/同步队列，拒绝后续命中和撤销前迟到写入，使共享派生分析、索引、CDN/浏览器可用缓存失效；按约定删除受影响的原内容与派生记录。
5. 个人账号删除/监护撤回时按冻结的目的/保留义务处理主库、队列、分析关联与备份；告知完成/预计完成状态和依法需保留的最小记录，不承诺无法保证的即时全网删除。
6. 学生原创笔记/答案能否继续保留，与受撤销素材的受限表达分别判断；保留时移除失效原内容并标明无法恢复原课，不偷偷再上传重建。
7. 两入口撤权/删除都取消旧任务与同步，按源身份清理允许范围内的派生缓存；网站清理浏览器临时帧/对象 URL，不删除用户设备原文件。若后续采用完整云上传，实际接收方的分片/临时副本/备份删除按独立期限验收。
