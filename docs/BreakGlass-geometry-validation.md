# BreakGlass 当前帧几何验证记录

记录日期：2026-10-03。对应 [005 规格](../specs/005-insitu-right-triangle/spec.md)、[任务清单](../specs/005-insitu-right-triangle/tasks.md)、[场景与动作契约](../specs/005-insitu-right-triangle/contracts/scene-actions.md) 与 [BreakGlass Constitution 1.7.1](./BreakGlass-constitution.md)。

当前实现提供独立直角三角形工作台、确定性计算和本地 reader 的单帧识别及受限问答接口。25 项任务中 19 项完成可独立验证的实现与检查；真实模型与完整产品验收仍缺证据，005 保持部分完成。自动化使用模型替身，本地指令解析不是 AI；这份记录不能证明任意视频识别或长期学习效果。

## 验证环境

在 Windows、Node.js 24.21.0 下检查。工作台沿用原生 JavaScript、CSS 和 SVG，没有新增运行时依赖。网页预览使用本机支持 Range 的 HTTP 服务，通过 Codex 内置浏览器操作；浏览器工具没有提供可核实的版本号，未将它记作确定版本的 Chrome 扩展验收。

当前工作树和已有发布工作树的 reader 目录没有 `.env`，进程的 `READER_BASE_URL`、`READER_API_KEY`、`READER_MODEL` 也均未配置。没有发送真实用户视频或帧给供应商。识别 30000ms、问答 10000ms 仍是开发默认，不能当成实测性能承诺。

仓库既有媒体测试需要 ffmpeg。本轮在临时目录准备经发行包 SHA256 校验的 imageio-ffmpeg 0.6.0 Windows 可执行文件，仅对测试进程补充 PATH；没有修改系统 PATH 或提交二进制依赖。

## 浏览器流程

使用临时生成的 640×480、8 秒合成视频，画面明确写有 `SYNTHETIC TEST - not real recognition`。视频中的 3/4 条件和预设模式只用于流程检查，没有模型识别。这支合成视频和临时服务脚本没有加入仓库。

| 操作 | 实际观察 |
| --- | --- |
| 保存当前暂停帧 | 分别在 0 秒和 4 秒保存单张 JPEG；原帧独立显示，不将像素当边长 |
| 候选校对 | 未勾选直角/数值核对时拒绝确认并定位错误；确认预设后 BC=5、修订 1 |
| 数值修改 | AB=6、AC=4 时显示 BC=7.211；再固定 AB=6、修改 AC=8 时 BC=10；恢复原题回到 3/4/5 且修订递增 |
| 非法输入 | AB=0 时保留有效模型与修订，显示字段原因；没有宣称条件已改变 |
| 本地受限指令 | “把 AB 改成 6，AC 不变，BC 是多少？”执行后为 6/4/7.211，与数值输入一致，持续标明不调用模型 |
| 实际 reader 无配置 | 识别及模型问答收到明确的未配置错误，结束等待；保留原视频及已确认条件，不自动回退为预设成功 |
| SVG 键盘与鼠标 | 连续两次方向键使 AB=3.2，焦点保持 AB；窄屏实际拖动使 AB≈3.983、AC=4、BC≈5.645，固定边和直角保持 |
| 窄屏及长标签 | 390×844 视口，页面客户宽和滚动宽均为 375；16 字中文标签在画板下方完整换行，图内使用 A/B/C，数值不重叠 |
| 桌面 | 1280×900 视口，页面客户宽和滚动宽均为 1265，无横向溢出；原帧和重建模型分栏可读 |
| 理解题 | 选择错误答案后给原因并允许重试；重新选择固定 AC 和直角后显示本次回答正确，不宣称长期记忆提升 |
| 返回与 ESC | 返回按钮请求回到保存的 4 秒处并继续同一视频；第一次成功读取为 4.23607 秒、`paused=false`、视频源相同，题目会话和操作已清空；ESC 也退出并保留原视频 |
| 退出再入 | 清除旧场景的画板无障碍描述、问答反馈、解释和原题摘要；问题输入保留。修复后页面测试及网页复测验证再入预设是 3/4/5，不残留上题 7.211 的回答 |

返回后的 4.23607 秒已经包含继续播放及浏览器工具读取延迟，不能用它计算 seek 定位偏差；页面测试验证请求回到保存时间，真实 seek 完成事件的 ≤0.1 秒偏差仍需单独量测。双 rAF 或 DOM 读取也不作为实际像素呈现时刻。

原帧预览与按条件重建的模型分开显示。模型修改后的几何形状不能记作与原视频仍然一比一重合。理解题只检验本次回答；用户答错或跳过时仍能退出或继续视频。
